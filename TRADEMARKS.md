# 名前とロゴ / Name and logo

## コードと名前は別に扱います / Code and name are handled separately

ソースコードは MIT と Apache-2.0 のどちらかで使えます。製品名「kieMonoBench」とアプリのアイコンは、そのどちらのライセンスにも入りません。Apache-2.0 の第 6 条も、名前と商標の使用を許していません。

The source code is available under MIT or Apache-2.0. The product name "kieMonoBench" and the application icon are not covered by either licence. Section 6 of Apache-2.0 also grants no permission to use names or trademarks.

アイコンのファイルは次のとおりです。

The icon files are:

- `crates/kmb-ui/assets/icon.png`
- `crates/kmb-ui/assets/icon.ico`

## してよいこと / What you may do

- 名前でこのソフトを指すこと(記事・動画・授業・比べた表など)
  Refer to this software by its name (articles, videos, classes, comparisons)
- 手を加えていない版を、名前とアイコンのまま配ること
  Redistribute an unmodified build with its name and icon
- 自分で手を加えた版を、自分だけで使うこと
  Use a modified build for yourself
- 「kieMonoBench を元にした」「kieMonoBench の文書を読める」のように、元や互換を事実として書くこと
  State facts such as "based on kieMonoBench" or "opens kieMonoBench documents"

## 手を加えた版を配る時 / Distributing a modified build

手を加えた版を配る時は、名前とアイコンを替えてください。公式の版と取り違えられないようにするためです。替えた後も、元が kieMonoBench であることは書いてかまいません。コードのライセンスの表記は、これまでどおり残してください。

If you distribute a modified build, please change the name and the icon so that it cannot be mistaken for the official build. You may still say that it is based on kieMonoBench. Keep the licence notices of the code as they are.
