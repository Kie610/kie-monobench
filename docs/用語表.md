# 用語表(画面の言葉)

画面のボタン・メニュー・タブ・まとまり・欄・選択肢の名前を決める表。新しい画面を作る時と言葉を直す時は、まずこの表を引く。表に無い語を足した時は、この表に行を足す。方針の正本は policy.md(画面の構成・使い勝手の原則)。

## 決め方

1. ボタン・メニュー・欄の名前(短い語)は、日本語の CAD・CAM で広く通じる語を基本にする。
2. 直訳くさい・分かりにくい語は、分かりやすい語か、短く普通の日本語にする。加工は日本の現場の言葉(切込み・仕上げ代・主軸回転数など)を優先する。
3. 商標と製品の名前は画面に使わない。加工する機械の名前や読み書きするファイルの形式のように、相手を示すだけの名前は使ってよい。
4. 長い説明文(吹き出し・案内・エラーの文)は自分で書く。
5. 独自にするのはアイコン・配色・部品の見た目。

根拠: メニューの命令の語と階層は米国の判例で著作権の対象外とされた(確定度 C は policy.md の記載まで)。短い語句や機能の一般名は日本でも著作物になりにくいとされる(確定度 A、法律の専門家には確かめていない)。長い説明文は著作物になり得るので写さない。出所の混同は、アイコン・配色・見た目と製品名を独自にしておくことで避ける。

## 書き方の決まり

- ボタンとラベルは一言にする。括弧の補足は単位(「切削送り(mm/min)」)と、同じ名前が並ぶ時の区別(「放射状(3D)」)だけにする。説明は括弧に入れず吹き出しに書く。
- 同じ物は画面のどこでも同じ語で呼ぶ(例: 「削除」「名前変更」「キャンセル」「OK」は窓・右クリック・パネルで共通)。
- 説明文は、文脈を知らない人にも押すと何が起こるか分かるように、短く書く。内部の名前(crate・状態の番号・英語の識別子)を出さない。
- 表記: 片仮名の語どうしの間は空けない(ターゲットボディ・ローリングボール)。英字・数字と日本語の間は半角の空白を入れる(3D 作成・X 距離)。区切りは「/」で並べる(移動/コピー・固定/固定解除)。
- 名前を変えたら、吹き出しの中の「」で引いた名前、試験の期待の文字列、利用者の設定に残る名前(リボンのピンとタブの並び。`crates/kmb-ui/src/layout.rs` の `RENAMED_WORDS`)も一緒に直す。

## 使わない語(検査で止める)

同じ物を画面ごとに違う語で呼ばないよう、下の語が画面の字(ソースの文字列そのもの)に入ると `cargo xtask verify` の点検「言葉の揺れ」(`xtask/src/words.rs`)が落とす。文の中の語(「固定を外すと最新にできます」)とテストの字は数えない。「当てた言葉」の前の名前は、「向き」「寸法」のように別の所では正しい語も多いので、紛れない物だけをここに足す。

| 使わない語 | 使う語 | 理由 |
|---|---|---|
| 消す | 削除 | 共通のボタン。右クリック・窓・パネルで同じ語にする |
| やめる | キャンセル | 共通のボタン |
| 確定 | OK | 共通のボタン(下の帯の Enter の案内も) |
| 名前を変える | 名前変更 | 共通のボタン |
| 固定を外す | 固定解除 | 「固定/固定解除」にそろえる |
| 新しいボディ | 新規ボディ | 演算の選択肢 |
| 残す厚さ | 残し量 | 加工の欄 |

## 列の見方

- 前・今: 当てる前の名前と今の名前。理由が「—」の物は、広く通じる語に合わせただけの物。

## 当てた言葉

前の名前 → 今の名前。画面の名前を当てた物だけ。変えないと決めた語(作業空間の「設計」「加工」、長穴、補助線、多角形、領域、機械、フェイス、穴あけ、V ビット、ブーリアン、演算 など)は下の「変えない語」に書いた。
