# 滑らかな横顔を線分と円弧にまとめる

- 意図: ボディの横顔を写した時に、丸い壁や丸めた縁が細かく割れず、閉じた輪郭になってほしい。
- 仕分け: A・直す(滑らかにつながる直線と円弧を、全体の当てはめに失敗すると線分だけへ分けていた)。
- 日付: 2026-11-02

## 作った物

シルエットの滑らかな区間を、許容内に収まる長い線分・円弧ごとにまとめる。閉じた点列の継ぎ目が円弧の途中にあっても、両側を合わせて1本の円弧として確かめる。

再現したフィレット付き箱は28本の線分から、直線4本と円弧4本へ、長円は33本の線分から、直線2本と半円弧2本へまとまる。再現例は細かい線分の時も閉じており、円弧にまとまらない点を直した。

## 決めたこと

- 許容は `section.rs` の `SECTION_TOL`、0.03 mmを共用し、広げていない。点だけでなく弦の中点も確かめ、長い直線を大きく膨らむ円弧にしない。
- 元のボディの辺を使える部分は、その参照のまま残す。シルエットの参照番号は同じ区間の細かい近似から引き、型と双方向の距離が許容内の時だけ引き継ぐ。短い線の番号を長い線や別の場所の線へ再利用しない。線分から円弧へ型が変わった保存済みの写しは、参照切れとして知らせて位置を残す。
- 円柱を真横から見た外形は矩形、軸方向から見た外形は円として確かめる。円すいと切頭円すいの軸方向の外形、通常の箱の外形も確かめる。

## 試し方

円柱・円すい・フィレット付き箱・長円・通常の箱の網から参照を作り、個数、閉じた領域が1つできること、面積を確かめる。フィレット付き箱と長円では、出来た線の点が解析的な外形から0.03 mmの許容内にあることも確かめる。保存済みの直線の写しが同じ側に残ることと、元の辺の参照が保たれることを試験に含めた。
