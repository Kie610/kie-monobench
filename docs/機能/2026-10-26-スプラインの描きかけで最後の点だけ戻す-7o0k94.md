# スプラインの描きかけで最後の点だけ戻す

- 日付: 2026-10-26
- 意図: スプラインを描いている途中で置く所を間違えて取り消すと、描きかけの点ではなくスケッチ全体の前の変更が戻ってしまう。
- 仕分け: A・作る(JC は描きかけの点を一覧で持つが、取り消しは文書の変更だけを戻していた)

## 作った物

- 編集器に `FeatureEditor::undo_step` を足した(既定は何もしない)。画面の取り消し(Ctrl+Z・右クリックの「元に戻す」・コマンド欄)は、中央のビューを持つ編集器に先に聞き、受けたら文書は戻さない(`crates/kmb-ui/src/workspace/edits.rs` の `editor_undo_step`)。
- スケッチの編集器は、通る点・制御点のスプラインの道具で点を置いていれば、最後の点を 1 つ戻す(`crates/kmb-ui-sketch/src/lib.rs`)。道具はそのまま続き、置き直せる。描きかけが無ければいつもの取り消し。

## 決めたこと

- 戻すのはスプラインの点だけ。ほかの道具の描きかけは今までどおり Esc で 1 段ずつ戻す。
- 試験: `kmb-ui-sketch` の `undo_while_drawing_a_spline_takes_back_only_the_last_point`。
