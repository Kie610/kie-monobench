# ツールバーの並びを画板に合わせる

- 日付: 2026-10-23

## 作った物

画板「JC の画面」(2026-10-21 に Kie と決めた)の並びを、設計・加工・スケッチのツールバーに入れた。アイコンの 2 層(`2026-10-23-アイコンの2層と役の色-f7l2ks.md`)の続き。

- 設計のソリッド: 前に出すボタンを画板の通りにした。作成は スケッチを作成・3D スケッチを追加・押し出し・回転・穴(面に文字・ねじ・スイープ・ロフトは ▾ へ)。修正は プレス/プル・フィレット・面取り・シェル・ブーリアン・ボディを分割・移動/コピー・パラメータ。パターンは ミラー・矩形状・円形状。検査は 計測・断面解析・体積を計測。挿入は STEP を読み込む・SVG を挿入(画板の後に足したキャンバスも前のまま)。
- 設計に「書き出し」のまとまりを置いた。STEP を前に出し、STL・3MF・DXF・SVG・ボディごと・今のビューの DXF は ▾ の一覧。STL・STEP・今のビューの DXF の操作は作業空間 `io` から `cad` に移した(ファイルのメニューにはそのまま出る)。
- 加工のフライス: まとまりを 2D → 3D → 穴の順にした。前に出すのは セットアップ、負荷制御粗取り・ポケット・フェイス、3D 粗取り・走査線・スキャロップ・等高線、穴あけ、シミュレーション・計測、G-code を書き出す・加工指示書を書き出す、工具ライブラリ・機械の設定。固定具を置く・輪郭・ピン穴・穴から加工を作る・G-code を見る・G-code で確かめる・断面解析・手動 NC・加工のパターン・名前を付けて書き出す・工具の順・加工指示書(HTML)は ▾ へ。ボア・円形は 2D のまとまりへ移した。戦略の並び(`order`)を 2D・3D・穴の順に振り直した。
- スケッチ: 作成の前は 線分・長方形・円・長穴・ミラー(円弧は ▾)、修正の前は トリム・フィレット・オフセット。拘束は前に 水平/垂直・一致・平行・等しい、残りの 8 つ(接線・直交・固定・中点・同心円・同一直線上・対称・曲率)は右に 2 段の小さなボタン(`ToolGroup::small`)、線上・円周上・ポリゴン・自動拘束は ▾。
- 水平と垂直を 1 つの道具「水平/垂直」にした。線分の横と縦の長さを比べ、近い方(同じなら水平)を付ける。右クリックの「水平にする」「垂直にする」は前のまま。
- スケッチのまとまりの基調の色(描く=青・直す=緑・拘束=桃でアイコンと名前を 1 色に塗っていた)をやめ、アイコンは役の色の 2 層、名前は他のまとまりと同じ色にした(役の色は見出しに使わない決まり)。3D スケッチの帯も同じ。`ToolGroup::tint` と、そのための引数を外した。
- 画板の 3 枚(設計・加工・スケッチ)をリポジトリのデータ `crates/jc-ui/board/toolbar.json` に起こした(まとまりの順、前に出す大きなボタンと 2 段の小さなボタン、その絵の土台と変わる部分の道筋と役、▾ の一覧)。比べ方は `jc_ui::board`、試験は jc-ui の `toolbar_tests.rs`(設計・加工)と jc-ui-sketch の `the_sketch_toolbar_follows_the_board`。画板の「新」の印の道具は JC に無いうちは比べず、▾ の何かを選んだ時だけ使える道具(画板の薄い物)も比べない。
- まだ入っていない差は `crates/jc-ui/board/known-diffs.txt` に理由と書く。今は 0 件。差が直ったのに表に残っていても試験が落ちる。`cargo xtask verify` の点検「画板の並び」(`xtask/src/board.rs`)が分かれ目の版と比べ、画板のデータを直す時のほかに差の行が増えたら落とす。AGENTS.md の 5 節に点検の名前を足した。

## 決めたこと

- 並びは画板から起こしたデータを正にし、画板を直したらデータも直す(2026-10-22 の調べで、画板の決めがコードに入らないまま検査が全部通っていたため。Kie「やってください」2026-10-23)。データは画板の HTML(Main・Machining・Sketch の .dc.html)の `Btn` の部品から機械的に起こした。
- 挿入の「キャンバス…」は画板の後に別の作業で足した物だが、前に出したままにする。加工の 3D は画板の「スキャロップ」でなく「スキャロップ(3D)」の名前のままにする(Kie 2026-10-23「両方aで」)。画板のデータの方を直し、項目の `decided` に書いた。
- 並べ替えは各モジュールの宣言(`Place::Toolbar`・`Place::Menu`・`Action::before`・記述子と戦略の `order`)で行い、画面には操作の名前を書かない。STEP の読み込みを挿入の先頭にするため、組み立て(jc-bundle)のモジュールの順でスケッチより前に置いた。
- テーマの `sketch_draw`・`sketch_modify` は帯では使わなくなったが、テーマのファイルの鍵として残した(古いテーマのファイルを読めなくしない)。

## 試し方

設計・加工・スケッチの帯を 1280 幅で開き、前に出るボタンが上の通りか見る。スケッチで斜めの線分を描き、拘束の「水平/垂直」を押して縦に近い線を押すと垂直、横に近い線を押すと水平が付く。拘束の小さなボタンに指を置くと名前が出る。
