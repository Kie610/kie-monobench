# ツールバーの日英

- 日付: 2026-10-27
- 決定: 表示の言語

## 作った物

- 分野 `toolbar`(作業空間の箱・タブ・まとまりの名前・画面が持つボタン(計測・断面解析・プレス/プル・パラメータ・工具ライブラリ・機械の設定・シーンの設定・外観・キャンバス内レンダリング)・ピンの右クリック・畳んだまとまり・選択のまとまり)を日本語と英語で書いた。
- 分野 `action`(操作の名前と説明)と `feature`(欄で足す機能の名前と説明)に、5 つの作業空間のツールバーとファイルのメニューに出る物をみな日本語と英語で書いた。簡体中国語・繁体中国語・韓国語は頭の注記だけのファイル。
- 操作は画面が操作の一覧を受け取る所で今の言語にするので、ツールバー・ファイルのメニュー・コマンド検索・右クリックのどこでも同じ名前になる。

## 決めたこと

- 操作の文言の ID は操作の ID から作る(`cad.extrude` → `action-cad-extrude`、説明は `-tip`)。機能は種類から版を外して作る(`solid.hole@1` → `feature-solid-hole`)。名乗りの型(`Action`・`Descriptor`)に欄は足さない。
- 日本語はモジュールが付けた名前をそのまま出し、`ja/action.ftl`・`ja/feature.ftl` は訳す人の元の文として同じ字を持つ。食い違えば kmb-ui の試験が落とす。訳の無い操作(後から足したモジュールの物)は、どの言語でもモジュールの名前で出す。
- まとまりとタブの名前はピンとタブの順の鍵でもあるので、鍵は日本語のまま持ち、出す時だけ訳す(`ribbon::group_id`・`ribbon::tab_id`)。表に無い名前は訳さずに出す。
- 使えない理由の文(`disabled`)は知らせと誤りの文の抜き出しで扱う。スケッチの道具は スケッチの抜き出しで扱う。

## 試し方

- 台本 `apps/kmb-app/tests/ui/表示の言語でツールバーが替わる.jcs`: English にすると設計と加工のツールバーとファイルのメニューの操作が英語になり、日本語に戻すと戻る。
- 試験 `every_toolbar_command_has_texts_matching_its_module`(ID が揃い、日本語がモジュールと同じ)と `the_toolbar_follows_the_display_language`(English で漢字と仮名が残らない)。
