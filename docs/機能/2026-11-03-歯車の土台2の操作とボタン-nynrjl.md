# 歯車の操作とツールバーのボタン(歯車の土台 2)

- 決定: 歯車
- 日付: 2026-11-03

## 作った物

- 操作「歯車」(`cad.gear`)と「歯車の輪郭」(`cad.gear_outline`)。crate kmb-cad-gear の `commands.rs`。設計の「作成 ▾」の一覧に並ぶ(前のボタンには出さない。ピンで前に出せる)。絵は道具の歯車 `gears`。
- 押すと、平面(原点の XY・YZ・ZX の四角・作業平面・ボディの平らな面)→ 中心の順にクリックで決める。平らな面を選んでから押すと中心から始まる。中心は数字で `x, y` も打てる。
- 「歯車」は歯車の輪郭(`cad.gear@1`)とそれを押し出す歯車のボディ(`cad.gear_body@1`)を 1 回の取り消し単位で足す。「歯車の輪郭」は輪郭だけを足す(レーザーや 2D 輪郭の加工、押し出しにそのまま使う)。
- 足した後は「作っている途中」になり、編集パネルは輪郭の欄(種類・モジュール・歯数・圧力角…)を出す。OK か Enter で決め、Esc で足す前に戻す。ボディの歯の幅は、ボディをダブルクリックして直す。
- 引数(画面・CLI・MCP・コマンド欄が同じ宣言を通る): `plane`・`face`・`feature`(平面。省くと選んでいる平らな面、無ければ原点の XY 平面)、`point`(中心、世界座標の mm)、`kind`・`module`(mm)・`teeth`・`pressure_angle`(deg)・`bore`(mm)、「歯車」だけ `width`(mm、既定 10)。歯数 3 未満・モジュール 0 以下・歯の幅 0 以下・まだ形を作れない種類は誤り。
- 歯車の輪郭の種類に、続けて足す種類として歯車のボディを宣言した(`Descriptor::companion`)。CLI・MCP の機能の追加で歯車の輪郭を足すと、ボディも一緒に足す。
- 編集パネルの種類の一覧には、今形を作れる種類だけを出す(`kinds::available` が偽の種類は一覧から隠す)。種類が足されると一覧に出る。
- 表示の言葉: action.ftl・feature.ftl の ja と en に操作 2 つと機能 2 つの名前と説明を足した。

## 決めたこと

- 「輪郭だけ」は欄の切り替えでなく、別の操作「歯車の輪郭」にした。作っている途中の輪郭の欄からボディを消す変更が無く、足す前に決める方が取り消しの単位も分かりやすいため。
- 足した後に直すのは輪郭の方(種類と歯の形が先に決まる)。

## 試し方

設計で「作成 ▾」→「歯車」を押し、XY 平面の四角 → 中心をクリックする。輪郭とボディがタイムラインに並び、編集パネルで歯数を変えて OK を押すと形が作り直される。Ctrl+Z を 2 回押すと、欄の直しと、輪郭とボディを足したことが順に戻る。試験は `crates/kmb-ui/tests/gear_button.rs`(MCP の ui_* の道具だけで操作する)と `crates/kmb-cad-gear/src/commands_tests.rs`。
