# 面の外観の色を 3MF にも残す

- 日付: 2026-10-25
- 元の項目: 10-14 E1l(3D プリンター向けの面の区別)
- 意図: 3D プリンターで出す人が、書き出すと面の区別が消え、色や設定を面ごとにやり直す
- 仕分け: D・意図だけ取り込む。元の「面の印」は JC に使い道が無いので持ち込まず、JC で面に付けた外観の色を 3MF に残す。

## 作った物

- 3MF の書き出し(`io.export_3mf`)で、面の外観を付けた面の三角形に、その色を Core 仕様の三角形の `pid`・`p1` で書く。色は同じ `basematerials` に並べ、同じ名前と色は 1 つにする。ほかの三角形は今までどおりボディの色(`object` の `pindex`)。
- 面は外観の区画の面の名前と網の `face_names` で引く(画面で面を塗るのと同じ)。網に無い面の名前(形を直して消えた面)は書かず、ほかの面に付け替えない。
- スライサー独自の色の書き方は今までどおり書かない。
- 試験: kmb-io-stl `a_face_with_its_own_appearance_writes_its_triangles_in_that_color`、kmb-mcp `a_face_appearance_is_kept_in_the_3mf`(直す前は落ちる)。
