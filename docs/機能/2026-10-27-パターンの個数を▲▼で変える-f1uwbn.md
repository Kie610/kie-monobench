# パターンの個数を ▲▼ で変える

- 日付: 2026-10-27
- 意図: パターンの個数を 1 つずつ増やして形を見比べたいのに、毎回数を打ち直すしかない。
- 仕分け: A・作る(打つ途中に形が付いて来る所はあり、1 つずつ増やす口が無かった)

## 作った物

- 欄の記述子に刻み(`kmb_core::Step`。`Field::step(by, min)`)を足した。刻みのある欄は、編集パネルで欄の右に ▲▼ を上下に重ねて出す(`crates/kmb-ui/src/design/feature_ui.rs` の `step_buttons`)。
- 付けた欄: 矩形状パターンの個数・個数 2、円形状パターンの個数、加工のパターンの X の数・Y の数・数。
- ボタンの名前は「<欄の名前> ▲」「<欄の名前> ▼」で、台本と MCP の `ui_click` から押せる。

## 決めたこと

- ▲▼ が変えるのは数だけの値。式(パラメータの名前や `n * 2`)の値は数に置き換えず、ボタンを押せなくして吹き出しで理由を出す(式を黙って壊さない)。
- 下限(個数は 1)より下には下げない。
- 試験: kmb-core の `step_changes_plain_numbers_only`、人の手順の台本 `パターンの個数を▲▼で変える.jcs`。
