# スケッチの線を変えて外れた領域を、線の近い領域から選び直す

- 日付: 2026-10-25
- 元の項目: 他のソフトの更新 2026-10-20 f27
- 意図: スケッチの線を直した人が、押し出しの領域が外れて作り直しになる。
- 仕分け: D・意図だけ取り込む(元の「いちばん近い輪郭へ黙って付け替える」は哲学 3 に反するので作らない。外れた時は今までどおり理由つきで止め、選び直しの手順で近い候補を選んだ形で見せて人が決める。台帳 J3)

## 作った物

- `crates/jc-cad/src/regions.rs` の `repick_handle`: 覚えている領域の名前がスケッチに無い時、囲む区間の名前が近い候補(同じ区間を 2、同じ線を 1 と数えて多い物)を選んだ形で始め、手順の説明に「スケッチの線が変わり、前の領域がありません。線の近い領域(…)を選んでおいたので、違えばクリックで直す」と出す。押し出し・回転など、領域を選び直す機能はみなこの手順を使う
- 決めるまで機能は止まったまま(黙って付け替えない)。Enter で決めると直る
- 試験 `crates/jc-ui/src/design/extrude_tests.rs` の `a_lost_region_is_offered_again_from_its_nearest_lines_and_not_swapped_silently`(直す前は選んだ形が空で失敗、直した後は通過)

## 作らなかった物

- 候補を形の重心や面積の近さで並べること。区間の名前で足りない時(線を全部描き直した時など)は、今までどおり何も選ばずに始まる
