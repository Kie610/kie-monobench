# ロフトの端を点にして尖りを作る

- 意図: ピラミッドや円すいの先の尖りを、ロフトで点を選んで作れず、小さな輪郭で代用して先が丸まる。
- 仕分け: B 土台から作る(ロフトの断面がスケッチの輪郭だけで、点の断面を受ける型も口も無い)。
- 日付: 2026-10-26

## 作った物

`solid.loft@1` の断面の行に「輪郭」「点」の選択を追加した。最初か最後の片方に点を置き、四角すい、円すい、涙形の先などを作れる。点は作業点、スケッチの点、ボディの頂点を参照する。`cad.loft` の断面の選択にも点の候補を出し、同じ宣言を使うコマンドからも指定できる。編集パネルの「端の点を選び直す」(`cad.loft_point`)も既存のクリック選択を使い、作業点・スケッチの点・頂点を選び直せる。

点へ縮む曲面の端を、その点と同じ制御点の列にして縫う。小さい輪郭で代用せず、先に平らな蓋も付けない。ガイドレールは輪郭と端の点の両方を通る必要がある。点の途中への挿入、両端の点、隣の輪郭と同じ平面の点、穴のある輪郭から点へのロフトは理由を出して止まる。

## 決めたこと

- 点の側には端面を作らず、側面は輪郭の区間の名前を使う。点を最初に置く場合も、最初の輪郭の区間から名付ける。
- 断面のデータは、輪郭なら `profile`、点なら `kind: point` と `point` の参照を持つ。参照の形は作業点が `kind: datum` と `datum`、スケッチの点が `kind: sketch` と `sketch`・`point`、頂点が `kind: vertex` と `feature`・`vertex`。保存のない欄は輪郭として読み、既存の断面の書き戻しに新しい欄は出さない。機能の版と文書全体の形式は据え置く。
- カーネルには点へつなぐ入口だけを追加した。対応しない実装は既定の「対応していません」を返す。道具の作り方は既存のロフトに省略可能な点を持たせ、写しやミラーでも点と輪郭を一緒に動かす。
- 新規ボディの頂点を借りた場合、参照元のボディを残す。
- 断面の行には条件付きの頂点の選ぶ欄を置かない。共通の行整理が、使っていない選ぶ欄も空とみなして輪郭や点の行を消すため、通常の欄と、点を選び直す操作に分ける。コアの行整理の処理は変えない。
- レールが許容差の内側で端の点の近くを通っても、尖りの位置は選んだ点に固定する。レールの補正で端の断面まで動かすと、参照する点から先がずれるため。
- 三角の平らな曲面が平面として認識されず、側面へのスケッチと縁の面取りが使えなかった。境の列が点へ縮む曲面に限り、正の重みを持つ制御点がすべて同じ平面に載ることを確かめる。許容差は既存の平面判定と同じ 0.000000001 mm。通常の輪郭どうしのロフトの判定は変えない。

## 試し方

四角すい・円すい・涙形の体積が底面積×高さ÷3に合い、閉じた立体で余分な端面が無いことを確かめる。ガイドレールあり・なし、点が最初・最後の両方、高さの変更、複数の輪郭から点まで、保存の読み戻しを試験にした。側面へのスケッチと縁の面取りは、底面の幅を変えても同じ面の名前に付いて来ることを確かめる。
