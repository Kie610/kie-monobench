# パターンの外れた写しの知らせと、ロフトの断面の確かめ

- 元の項目: 他のソフトの更新 2026-10-24 k2・k4
- 意図: パターンの一部が本体の外に並んで何も削っていないのに気付かない(k2)。AI や台本が同じ断面を何度も、または大量に渡すと、ロフトが長く固まる(k4)。
- 仕分け: A・作る(k2。パターンは写しを `apply_recipe` で当てるだけで、当たったかを見ていなかった。crates/kmb-cad-pattern/src/lib.rs の `repeat`・ミラー)。k4 は C・JC に合わせて作る: ロフトの `sections` を確かめずにカーネルへ渡していた。押し出しの領域は名前で選んで合わせるので同じ害は無い。
- 日付: 2026-10-25

## 作った物

- パターン(直線・円形・パスに沿う・点に沿う、`repeat` を通る物)とミラーで、切り取りの写しごとに体積が減ったかを見て、減らなかった数を注意で出す(「2 個の写しが本体に当たっていません(切り取りの写し 5 個のうち。…)」)。結合の写しは見ない(離れた所に足すのは使い方としてある)。体積を測れないカーネルでは数えない。
- ロフト: 同じ断面(同じスケッチの同じ領域)が 2 度入ったら「ロフトの断面 1 と 3 が同じです」で止める。断面は 50 個まで(`MAX_SECTIONS`)。
- 試験: crates/kmb-solid/src/pattern_tests.rs の `pattern_copies_that_miss_the_body_are_counted`、sweep_loft_tests.rs の `a_loft_joins_a_square_to_a_circle_and_refuses_sections_on_one_plane` に 2 つの場合を足した。
