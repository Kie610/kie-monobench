# 歯車の輪郭

- 決定: 歯車
- 日付: 2026-11-03

## 作った物

- 機能 `cad.gear@1`「歯車の輪郭」(crate kmb-cad-gear、層 cad)。平面の座標かスケッチの単独の点に中心を置き、モジュール・歯数・圧力角・転位係数・歯先の丸み・歯底の丸み・軸の穴の径から外歯の平歯車の輪郭を作る。欄はどれも式を受け、パラメータの表で変えると作り直す。
- 出力は閉じた領域 `profile`(歯の輪の外形と軸の穴)、線 `curves`、参照の円 `reference`(ピッチ円・基礎円・歯先円・歯底円。加工はなぞらない)、諸元 `gear`。文字と同じ形なので、押し出し・2D 輪郭の加工・ポケット・レーザーにそのまま使える。
- 歯面は基礎円のインボリュートを二円弧で近似する。許す隔たりは 0.002 mm かモジュールの 0.1% の小さい方。基礎円が歯底円より外の時は、半径の向きの線で歯底までつなぐ。歯底の丸みは歯底円とその線(か歯面)の両方に接し、歯溝の真ん中を越える大きさは縮めて注意を出す。歯先の丸みも同じ。
- 区間の名前は歯の番号と歯面から決まる: `t<i>:r<k>`・`t<i>:l<k>`(右・左の歯面の k 番目の円弧)、`t<i>:rfillet`(歯底の丸み)、`t<i>:rneck`(基礎円より内の線)、`t<i>:rround`(歯先の丸み)、`t<i>:tip`、`t<i>:root`(i 枚目と次の歯の間)、`bore`。押し出すと面の名前の元になる。歯数を減らして消えた歯の面を指す後ろの機能は参照切れで止まる。
- 歯数が切り下げの起きる数(圧力角 20 deg・転位なしで 17 枚未満)なら注意を出し、形は切り下げなしで作る。歯先がとがる転位・歯底円の半径が 0 以下・軸の穴が歯底円以上は誤り。
- kmb-interchange に諸元の型を置いた: `GearSpec`(出力 `gear`。種類・歯形・モジュールと歯直角か・圧力角・歯数・転位係数・ピッチ円の半径・軸の点と向きと基準の向き・1 枚目の歯の向き・歯の幅・ねじれ角と向き・円錐の角・鎖のピッチ・条数)、カムの `CamSpec`(出力 `cam`。従節の動き方と先の形・基礎円・ローラー・変位の線図と運動の法則 4 つ)、自在継手とクラッチの `CouplingSpec`(出力 `coupling`)。種類の列挙 `GearKind` は作る予定の 16 種を全部持つ。まだ形を作れない種類を選ぶと「まだ作れません」の誤りになる。
- 種類の形は kmb-cad-gear の `kinds.rs` の 1 か所で並べ、種類ごとに `kinds/` の 1 ファイルに置く。歯の曲線の計算(`tooth.rs`)は文書にもカーネルにも触らない純関数。

## 決めたこと

- 歯車は「歯車の輪郭」と「歯車のボディ」の 2 つの機能で作る。輪郭の機能は立体を作らない。
- 諸元の角度はラジアン、長さは mm。かみ合う 2 つの回転の比は歯数の逆比、ベルト車・ロープ車はピッチ円の径の逆比で決める。
- 歯車の位相・かみ合わせ・連動の避ける形を docs/避ける形.md の「組立と動き」に書いた。

## 足した言葉

用語表.md「歯車」: 歯車の輪郭、種類・モジュール・歯数・圧力角・転位係数・歯先の丸み・歯底の丸み・軸の穴の径・中心の点のスケッチ・中心 x・中心 y・回す角、種類の選択肢 16 種、ピッチ円・基礎円・歯先円・歯底円、ねじれ角。

## 試し方

CLI か MCP で機能を足す(例 `{"module": "1.5 mm", "teeth": "14", "bore": "6 mm"}`)。押し出しの輪郭に選ぶと、厚さ × 輪郭の面積の歯車になる。パラメータで歯数を変えると歯の数が変わる。
