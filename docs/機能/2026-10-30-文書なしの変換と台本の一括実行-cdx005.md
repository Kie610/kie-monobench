# 文書なしの変換と台本の一括実行

- 日付: 2026-10-30

## 作った物

CLI の `convert <入力> <出力> [--arg 鍵=値]` で、STEP のボディや DXF・SVG の輪郭を一時の文書へ読み、拡張子に対応する形式で書き出す。読み書きはモジュールの役割とファイルの宣言から探し、引数は操作の宣言で確かめる。

`run <台本> [--document <元の文書>] [--save <文書>] [--export <ファイル>]` で、コマンド欄と同じ文書の命令を順に流す。元の文書を省くと空の文書から始める。`add_param`・`set_param`・`set_value`・`run`・`undo`・`redo`・`actions`・`status`・`echo` と、再計算を待つ引数なしの `wait` を使える。空行と `#` の行は飛ばし、引用符で空白を含む値を書ける。最初の誤りで止め、台本の行番号と元の誤りの種類を出す。すべて成功してから書き出しと保存を行う。

## 決めたこと

操作の ID を渡す `run <文書> <操作ID>` は同じ使い方で残す。台本のボタン・マウスの命令は、画面がない CLI では「使えない」として断り、黙って飛ばさない。文書の変更は既存の Headless の口を使い、CLI だけの変更の口は作らない。通せない入出力の組は終了番号 4、宣言しない引数は 1、再計算の誤りは 2、ファイルの誤りは 5 とする。
