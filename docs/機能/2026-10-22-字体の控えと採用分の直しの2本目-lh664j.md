# 字体の控えと 2026-10-22 採用分の 2 本目(12 件)

- 日付: 2026-10-22

## 作った物

2026-10-22 に Kie が採用した直しの 2 本目と、10/21 に採用した字体の控え。

- 字体の控えと ⌀ の □: 画面の字体は日本語の字体 1 つ(游ゴシック・IPA など)と egui の既定の字体だけで、どれにも ⌀(U+2300)が無いため □ になっていた(根本の原因。試験で前を再現)。日本語の字体の後ろに控えの字体(Windows は Segoe UI Symbol・Microsoft YaHei・Malgun Gothic、macOS は Apple Symbols、Linux は DejaVu Sans と Noto CJK)を重ね、縦の寸法を日本語の字体と同じに揃えて基準線を合わせる。控えは大きなファイルがあるので、起動では裏のスレッドで読んで後から足す(最初の画面を待たせない。u12)。記録に「⌀: どの字体」を書く。Linux の Fedora の Noto CJK の道も足した。画面の直径の記号は、計測・スケッチの寸法・ブラウザの工具の札と同じ Ø(U+00D8。どの日本語の字体にもある)に揃えた(工具の絵と穴の加工の名前)。
- Esc 2 回でスケッチを終える: 戻す物が何も無い時(道具は選ぶ道具、選び・領域・拘束の選びが空)に 0.4 秒以内に 2 回押すと「スケッチを終了」と同じにする。1 段ずつ戻す途中の Esc は数えない。下の帯の案内に「Esc 2 回 スケッチを終了」。
- シェルの接線チェーン: 選んだ面に接して(2° 以内で)つながる面も開ける。網の同じ位置の頂点の法線で隣の面を見つける。欄の無い古い文書は切、画面から作ると入。全部の面を開けることになる時は「本体が残りません」と理由を出して断る。
- 先頭の小数のカンマ: 式の `,5` を 0.5 と読む。前が値の終わり(数・名前・閉じかっこ)なら引数の区切りのまま(`max(1,5)`)。
- 今の視点の DXF・SVG に表示中のスケッチ: 止めていないスケッチの線を、ボディの線と同じく隠れの判定をして書く。画面は目を閉じたスケッチを `exclude` に入れる。
- screenshot を画面のスレッドの外で: 網にして描く仕事を裏のスレッドで行い、窓を固めない。
- 動かしている要求の一覧: 受けてまだ答えていない要求を、接続をまたいで 1 つの一覧に持つ。`status` の `running` と、下の帯の札のツールチップに出す。
- 開始画面の最近のファイルの有無と縮小図を裏のスレッドで: 毎フレームのファイルの更新時刻の確かめ(ディスクを読む)をやめ、3 秒ごとに裏で確かめる。
- 窓を作業域に収める(Windows): 最初の画面の後、見える枠(DWM の枠)が今のモニターの作業域(タスクバーを除く)からはみ出していれば中へ戻す。eframe はモニター全体にしか収めない。
- 最初の画面で前面に(Windows): 最初の画面の後に 1 回だけ SetForegroundWindow。
- M は「移動/コピー」(Kie 2026-10-22 決定): 設計の M を移動/コピーを始めるキーにし、計測は I だけにした。キーの割り当ての行は役割(`role::kind::COPY_BODY`)で働きを探す(機能の名前を書かない)。
- 面・辺・頂点を選ぶと機能の選びを外す(「面を選んで Delete で機能が消える」誤りの対策、Kie 2026-10-22 決定): ビューで形を選んだら、ブラウザやタイムラインで選んでいた機能の選びを外す。続けて Delete を押しても、前に選んだ機能を消さない。

## 決めたこと

- 直径の記号は Ø に揃える。⌀ は控えの字体が描けるようになったが、字の形が周りの日本語の字体と違い、控えの字体の無い環境では □ に戻るため。控えは ⌀ 以外の足りない字(中国語の漢字など)のためにも残す。
- Esc 2 回は「戻す物が無い時の 2 回」だけにして、Esc は 1 段ずつ戻す決まり(AGENTS.md 5 節)と両立させる。
- 道具のボタンを前回使った変種に替える(Kie 2026-10-22 決定): 作らず記録だけにした。毎回同じ既定の種類で始める。
- シェルの接線チェーンは既定で入。前の面だけを開けると、開けた縁が丸めの面に接して終わり SMLib が殻を作れない(試験で確認)ので、つながる面も開けるのが既定として自然。

- 控えの字体の比べ(2026-10-22、PC の取り込みで試験が飛んだのを受けて): (1) OS に入っている記号の字体を控えにする(Windows は Segoe UI Symbol。Windows 7 以降に標準で入り、技術の記号の区画を持つ)、(2) ⌀ を持つ字体を同梱する(DejaVu Sans など。fonts.rs の「同梱しない(ライセンスと容量)」の決まりを変えることになる)、(3) ⌀ を画面で使わず Ø に置き換える(済み。ただし利用者が打った名前や読み込んだ名前の ⌀ は残る)。(1) と (3) を採り、(2) は (1) が足りないと分かった時の次の手とした。試験はその PC に入っている字体(起動と同じ探し方)で確かめ、Windows では Segoe UI Symbol が見つかって ⌀ を描くことまで見る(PC の取り込みの検査で確かめる)。
