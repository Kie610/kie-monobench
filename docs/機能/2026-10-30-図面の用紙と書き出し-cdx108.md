# 図面の用紙と表題欄、PDF・DXF・SVG の書き出し

- 日付: 2026-10-30

## 作った物

`kmb-drawing` に用紙と表題欄の設定、`drawing.export_pdf`・`drawing.export_dxf`・`drawing.export_svg` を足した。用紙は A0〜A4 と自由な大きさ、縦と横、とじ代を持つ。枠の余白は A0・A1 が20 mm、ほかが10 mm、とじ代を入れた左側は20 mm。各辺の真ん中に中心の印を描く。

表題欄は右下に置き、図名・図番・尺度・投影法・日付・作った人・材料・用紙の番号・単位を、固定の文字か文書から取る値で出す。値は `drawing.set_title` で設定する。文書の名前は属性の図名、空なら保存したファイルの名前を使う。日本語を入れる時は `font` に書体のファイルを指定し、使う字の輪郭だけを文書へ埋める。描く時にフォントのファイルを読まない。

SVG は用紙の実寸の mm、線の太さ、破線の並び、偶奇の塗りを持つ。DXF は R12 で、外形・隠れ・中心・切断・ハッチ・寸法・文字・枠の画層を分け、画層の色を用紙に指定できる。一点鎖線と二点鎖線も書く。PDF は用紙ごとに一ページにし、複数の用紙も一度に書き出す。文字は線と輪郭で、フォントを埋め込まない。書き出しは共通のファイルの結果として返し、保存側の壊れない書き込みを通る。

## 決めたこと

- 用紙の定義は図面区画の版1を使い、知らない項目を残して読む。寸法や注記を含む用紙の共通の絵を各形式へ直し、形式ごとにモデルから線を作り直さない。
- 日付は書き出しの `date` の YYYY-MM-DD を使う。時計は読まず、省いた時は日付と作成日時を入れない。同じ入力から同じバイト列を作る。
- PDF の円弧は三次の曲線に直し、用紙の上の誤差を0.005 mm未満にする。ハッチは輪と穴を保って線に展開し、その判断を各形式で共有する。塗りの穴は偶奇の規則で残す。
- 表題欄の欄名と英数字は一本線、日本語は保存した輪郭で描く。書体のパスは保存しない。文書の属性を直して字形が足りなくなった時は、表題欄の書体を指定し直す理由を出す。
- PDF のページの目録と xref はバイトの位置から作る。圧縮と外部の依存は足さない。コアの公開の型と画面は変えない。

## 試し方

`drawing.set_paper` で A4 縦や A3 横を指定し、`drawing.set_title` で項目を設定する。`drawing.export_pdf` は用紙を省くと全ページ、DXF と SVG は用紙を一つ指定する。日付を入れる時だけ `date` を渡す。
