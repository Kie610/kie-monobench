# 3D のビューと確かめる窓の日英

- 日付: 2026-10-27
- 決定: 表示の言語

## 作った物

- 分野 `view`(左上の案内の見出しと数、右上の等角と全画面のボタン、下の帯(オービット・画面移動・ズーム・全体表示・正面・表示)と吹き出し、オービットの右クリック、表示のメニュー(パネル・表示スタイル・投影・目安・効果)、ブラウザを隠した時のつまみ、計算に失敗した時の帯、加工の確かめの凡例、重なった面の候補)を日本語と英語で書いた。設定の窓の表示スタイル・投影・効果も同じ ID を使う。
- 分野 `review`(注意・エラーを確かめる窓の見出し・ボタン・写す文の「元の文」と、右下の角の数の札と吹き出し)を日本語と英語で書いた。簡体中国語・繁体中国語・韓国語は頭の注記だけのファイル。

## 決めたこと

- 表示スタイル・投影・光の名前は描く側の crate(kmb-ui-view3d・kmb-render)の日本語の名前を使わず、画面の側で種類から ID を引く。等角のボタンも表の名前でなく ID で出す。
- 「正面」を使えない理由は今の言語の文で返す(コマンドの一覧の使えない理由も同じ文)。
- 確かめる窓の知らせの文そのものと直し方の例、左下の格子の間隔の札、軸の玉の名前は残し、知らせと誤りの文の抜き出しで扱う。

## 試し方

- 台本 `apps/kmb-app/tests/ui/表示の言語で3Dのビューが替わる.jcs`。
- 試験 `the_view_and_review_follow_the_display_language`(English で下の帯・等角・全画面・表示のメニュー・確かめる窓・つまみが英語、日本語に戻すと元の字)。
