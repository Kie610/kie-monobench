# 辺を拾う道を 1 つにし、文書の拡張子を 1 か所にそろえる

- 日付: 2026-10-24
- 決定: 辺を選ぶやり方を 1 つにそろえる、文書の拡張子は公開まで json

## 作った物

- 辺を拾うのは、GPU の有無によらず CPU の 1 本(`view3d::edge_at`)にした(policy.md「辺を拾う」)。前は GPU があれば番号の絵で拾い、PC によって拾う辺が変わる恐れがあった。GPU の番号の絵(管・絵・読み戻し・WGSL の入口)は外した。
- 隠れの判定は、マウスの点 1 か所の深さでなく、近い辺の候補ごとに辺の上のいちばん近い点で面の箱の木を引いて見る。近い順に見て、手前の面より奥でない最初の辺を拾う。真上から見た貫通穴の上と下の縁のように画面で重なる辺は、手前の縁を拾う。
- 文書の拡張子を `kmb_core::DOCUMENT_EXTENSION`(保存)と `DOCUMENT_EXTENSIONS`(開く・一覧・リンク。拡張子を替える時は前の物を残す)に集めた。公開までは `json`(製品名が決まってから決め直す)。名前を付けて保存・開く窓の絞り込み・リンクで挿入・新規デザイン・プロジェクトの一覧が使う。

## 点検

- 「文書の拡張子」(8-5): ソースの文字列に `"json"` や `….json` を書いた所を数える。文書でない JSON(設定・控え・索引・工具ライブラリ・テンプレートなど)は xtask/src/layers.rs の `JSON_NAME_KNOWN` に数で置き、増えたら落とす。
- 「前の機能を書き換えない」(8-3): 機能を足す変更(`Edit::Insert`)とほかの機能を直す変更(`Edit::SetData`)を同じ関数で組む所を落とす。今の物は `REWRITE_KNOWN` に理由つきで置く(剛性グループの `new_group` は F19 で直して外した)。
- 「他製品の名前」に出典の名前(百科事典・論文の置き場・質問の場・動画・販売店など)を足した(8-4)。

## 試し方

- 試験 `kmb-ui` の `edges_hidden_below_are_not_picked_from_above`(真上から見て下の面の辺を拾わない。線だけの表示では拾える)と既存の `edges_hidden_behind_the_body_are_not_picked` ほか。速さは `edge_pick_speed`(`--ignored`)。点検は xtask の `json_extension_names_are_found_in_literals_only`・`insert_and_rewrite_in_one_function_is_found`・`sources_are_found_but_not_inside_words`。
- 消した試験: `kmb-ui` の `gpu_edge_ids_pick_the_same_edges_as_the_cpu`(比べる相手の番号の絵を外した。xtask/removed-tests.toml)。
