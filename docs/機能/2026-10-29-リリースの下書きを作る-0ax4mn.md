# リリースの下書きを作る

- 日付: 2026-10-29

## 作った物

タグで配る物を組み立てる CI(`.github/workflows/release.yml`)が、配る物の名前を「kie-monobench-<版>-<OS>-<arch>」(Windows は zip、Linux は tar.gz)にそろえ、`README.md`・`README.en.md` も同梱し、ハッシュの一覧を `SHA256SUMS.txt` にする。タグの回は同じ回で GitHub のリリースを下書きで作り、`.github/release-notes.md` のひな型に版を埋めた本文と配る物を載せる(docs/verify.md の 15 節)。

## 決めたこと

- 名前と中身は手で出した最初の版と同じ形にし、受け取る人から見て版ごとに変わらないようにする。
- CI は下書きまで。公開は落とし直してハッシュを確かめ、新しくできること・直したことの節を埋めてから手で行う。
- 版の番号はワークスペースの 1 か所(`Cargo.toml` の `[workspace.package] version`)で上げ、タグはそれに `v` を付けた物にする。
