# 角丸と面取りの形を先に見せる

- 日付: 2026-10-25
- 元の項目: 2026-10-20 s6
- 意図: スケッチで角を丸める半径を打っても、押して作るまで形が見えず何度もやり直す
- 仕分け: A・作る(crates/kmb-ui-sketch/src/view/act/modify.rs の角の丸めと more_tools.rs の面取りは、角を押した時に初めて作り、指している間は打った値の字だけを出していた)

## 作った物

- 角の丸め・面取りの道具で角の点を指している間、今の半径・距離(打っている値、無ければ寸法の値の欄か既定)で作った後の角の形を、作り直す 2 本の線と足す円弧・線で差し色の太線で見せる。打ち直すたびに変わり、押すと同じ形ができる(押した時と同じ計算を写しのスケッチで行う。`view/draw.rs` の `corner_preview`)。
- 作れない値(辺より長い半径など)の時は何も見せない(押すと今までどおり理由を出す)。

## 試し方

- `kmb-ui-sketch` の `the_rounded_corner_is_previewed_with_the_typed_radius`(長方形の角で 3 と 1 を打つと、円弧の弦が半径の √2 倍に変わる)。
