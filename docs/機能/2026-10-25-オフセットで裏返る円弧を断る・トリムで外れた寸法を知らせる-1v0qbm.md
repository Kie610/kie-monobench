# オフセットで裏返る円弧を断る・トリムで外れた寸法を知らせる

- 日付: 2026-10-25
- 元の項目: 2026-10-20夜 E18・2026-10-20 s2
- 意図: スケッチの線を内側へ大きくずらす人が、円弧が裏返った(反対側へ膨らむ)形に気づかず残してしまう(E18)。寸法を付けた線をトリムすると、その寸法が黙って消え、決めたはずの寸法が無くなったことに気づかない(s2)
- 仕分け: A・作る(E18。crates/kmb-sketch/src/offset.rs のオフセットは線分の裏返りだけを断り、円弧の開きを見ていなかった)。s2 は C・JC に合わせて作る(JC のトリムは形を動かさず、片に付け替えられない寸法を外す。`replace_curve` が長さの寸法などを外し、知らせていなかった。外したことを下の帯で知らせる)

## 作った物

- オフセットで、ずらした円弧の中ほどが元と反対の側へ移る(開きが半周をまたぐ)時は作らずに断る。線分の裏返りと同じ扱い。
- 断った理由を `Sketch::offset_corners_why` が返し、画面のオフセットの道具と右クリックのオフセットが「オフセットできませんでした(内へずらしすぎて円弧が裏返ります…)」のように理由をそのまま出す。前は「円弧の半径が 0 以下になる時など」と決め打ちの文だった。理由は 3 つ(半径が 0 以下・線分が裏返る・円弧が裏返る)。
- トリム・破断の後に、前にあって今は無い寸法(`Sketch::dims_dropped_since`)を下の帯に「トリムで寸法 N 個を外しました: d3, d4(…)」と出す。拘束の番号は使い回さないので、番号で比べて確かめられる。

## 試し方

- `kmb-sketch` の `an_offset_that_flips_an_arc_is_refused_with_a_reason`(上の辺にこぶのある長方形を 2.2 mm 内へずらすと断る。1 mm なら作る)。
- `kmb-ui-sketch` の `trimming_a_dimensioned_line_says_which_dimension_went`(長さ 25 を打った線を切ると知らせが出る)。
