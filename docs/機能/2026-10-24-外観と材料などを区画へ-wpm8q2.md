# コアの外観・材料・構成表・アニメーションを区画へ・保存形式の版 5

- 日付: 2026-10-24

## 作った物

コア(jc-core)に残っていた個々の機能のデータ(アニメーションの段と動き、外観、物理材料と外観の表、構成表、光源とデカールの型)を、コアの外へ移した(AGENTS.md 2 節の 1「コアに個々の機能の知識を置かない」)。使う人から見える振る舞いは変えない。

- 文書の中身は、それを扱うモジュールが名乗る区画に置く。
  - `asm.animation`(組立 jc-asm): ストーリーボードの段。型は jc-interchange の `animation::Storyboard`。
  - `config.table`(構成表 jc-config): 構成表。型は jc-interchange の `configuration::Configurations`。
  - `cad.materials`(CAD jc-cad): ボディに付けた物理材料。型は jc-look の `material::BodyMaterials`。
  - `render.appearances`(レンダリング jc-io-render): ボディ・部品・面の外観と「このデザイン内」の外観。型は jc-look の `appearance::Appearances`。部品の外観は部品の番号 → 外観の名前で持つ(コアの部品の木から外観の欄を外した)。
- 物理材料と外観の表・木目、文書の外観の型、光源とデカールの出力の型は、新しい小部品 jc-look(層 core)に置いた。描き手(jc-render、層 inspect)と解析(jc-fea、層 analysis)も引くので、jc-interchange(この 2 つの層からは使えない)ではなくコアの層の小部品にした。
- アニメーションの段と動き(`Drive`・`joint_poses` など)は jc-interchange の `animation` へ。引いて動かす物の動き `Dof` だけは、拡張点の `Drag` が持つのでコアに残した(`jc_core::Dof`)。
- 専用の変更をやめ、汎用の区画の変更(`Op::SetSection`・`Edit::SetSection`)に寄せた: `Op/Edit::SetAnimation`・`SetAppearances`・`SetConfigurations`・`Op::SetBodyMaterial`・`Op/Edit::SetBodyAppearance`・`Edit::ActivateConfiguration`。構成表の行を当てる操作は、パラメータの式の変更 `Edit::SetParamExpr`(新しく足した汎用の変更)・抑制・区画の変更を並べる。
- 文書から読む口: `DocumentData::material_of`・`appearance_of`・`resolve_appearance`・`face_appearance`・`appearance_users`・`design_appearances` をやめ、jc-look の `material::of`・`material_of`・`appearance::of`・`appearance_of` と `Appearances` の `resolve`・`face`・`users`・`design_names` で読む。
- 保存形式を版 5 にした。版 4 の上の階の `animation`・`configurations`・`body_materials`・`body_appearances`・`appearances`・部品の `appearance` は、読む時に上の区画(区画の版 1)へ移す。

## 決めたこと

- 外観と材料は別の区画にした(物理材料と外観は別の物。材料は質量と加工のストックにも効く)。
- 区画の中身が読めない(型に合わない・新しい版)時は、読む側はログに残して空として扱う(モーション スタディ・接触セットと同じ)。書く変更は新しい版の区画を上書きせず誤りにする。
- 消した部品の外観は区画に残る(取り消しで部品が戻ると外観も戻る)。使っている所の一覧(`users`・`design_names`)は今ある部品だけを数える。

## 試し方

`cargo xtask verify --all`。jc-core の `version_4_tables_move_into_sections`(版 4 の上の階が区画へ移る形)、jc-interchange の `a_version_4_document_reads_through_the_sections`(版 4 の文書を区画の型で読み、保存し直しても同じ)と `steps_are_saved_undone_and_checked`、jc-interchange の構成表の試験、画面の材料・外観・アニメーション・構成表の試験。
