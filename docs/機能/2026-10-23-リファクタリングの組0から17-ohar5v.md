# リファクタリング 組 0〜17: 大きいファイルを分け、写しを 1 つにし、経緯のコメントを今の働きに直す

- 日付: 2026-10-23

## 作った物

思想からの乖離・資料の古さ・写し・大きすぎるファイル・フォルダの整頓・コメントを、コアから末端へ 18 組に分けて直した。使う人から見える振る舞いは変えていない。断片やコードを探す時に効く置き場所の変更は次のとおり。

- 画面(組 11〜15): jc-ui の画面のファイルを作業空間ごとのフォルダに分けた(`design/`・`assembly/`・`animation/`・`render/`・`machining/`・`simulation/`・`files/`)。Workspace の振る舞いは lib.rs から話題ごとのファイルへ、通しの試験 tests.rs は作業空間ごとへ分けた。ホームの頁は `files/home_ui.rs`、3D のビュー(jc-ui-view3d)の view3d.rs は話題ごとの子へ分け、WGSL を別ファイルにした。スケッチの画面(jc-ui-sketch)は段ごとに分けた。版の形の再計算は jc-session へ移した(組 15)。
- コアとカーネル(組 1・2): jc-core の大きいファイルを中身ごとの子に分けた。カーネルの lib.rs から面の名前の決め方(SMLib)と切れどうしのブーリアン(truck)を子のファイルへ出した。
- 保存と入口(組 3): jc-session が測る計算を出し直すのをやめ、`Headless` を分けた。
- 機能(組 4〜10): スケッチの平面の向きの計算、組立の動かす機能 3 つの出力、加工の段取り・出力・経路の計算、解析、入出力・絵・測るの写しを 1 つにまとめ、大きいファイルを子へ分けた。
- 動作確認のためだけの機能 jc-demo-features を消した(Kie 2026-10-23。試験 2 件 `value_contract`・`scale_contract` も消した。xtask/removed-tests.toml)。CLI の説明と README の例は種類の一覧 `jc types` の案内に替えた。
- 道具と検査(組 16): 控えの読み書きを譲り合わせ、xtask の大きいファイルを分けた。写真の道具 `write_screens` は部品の名前の完全一致で押し、押せなければ止める(部分一致で「表示」が「全体表示」にも当たっていた)。
- 資料(組 0・17): AGENTS.md・.claude/rules/(コメントの決まりは .claude/rules/code.md)・verify.md・地図.md・用語表.md・plan.md の古い所を直し、測った記録は docs/history/ へ移した。

## 決めたこと

- コメントは今の働きと理由を書き、経緯と言葉の無い内部の番号を書かない(.claude/rules/code.md)。番号は言葉と一緒なら添えてよい(docs/機能/ か外の issue で引ける物だけ)。

## 試し方

`cargo xtask verify --all`(振る舞いを変えていないので、前からの試験が通ることで確かめる)。
