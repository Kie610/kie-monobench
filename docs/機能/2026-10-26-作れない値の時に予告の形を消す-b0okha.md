# 作れない値の時に予告の形を消す

- 日付: 2026-10-26
- 意図: 欄に形が作れない値(深さ 0、ボディより大きい穴など)を打ったのに、前の形が出たままで、打った値で作れないことが形から分からない
- 仕分け: D・意図だけ取り込む(打つ途中も形が付いて来る(`TYPING_PREVIEW_DELAY`)と同じ道で、失敗した時の見せ方だけを変える)

## 作った物

- 編集パネルで直している機能が、欄の値で計算に失敗したら、前に計算できた形を出し続けず、今の計算の形を出す(直している機能の形は消え、その機能より前の形が見える。下流の機能も計算できないので出ない)。`kmb-ui` の `Workspace::hold_scene` で、直している機能を出し続ける対象から外す。
- 編集パネルの外で失敗した時(パラメータの表で値を変えた時など)は、前と同じく前の形を出し続け、ビューの上に知らせを出す。
- 打ちかけで計算できない字(式の途中・知らない名前など)は値として入れないので、形は前のまま(打つ途中も形が付いて来る と同じ)。

## 試し方

- `kmb-ui` の `a_value_that_cannot_make_the_shape_clears_the_preview_while_editing`: 基準部品のポケットを直し、深さを 0 mm にすると、前の形を出し続けず形が替わる。直す前はこの試験が落ちた(前の形のまま)。
