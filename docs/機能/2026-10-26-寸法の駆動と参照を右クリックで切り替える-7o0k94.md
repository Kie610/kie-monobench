# 寸法の駆動と参照を右クリックで切り替える

- 日付: 2026-10-26
- 意図: 寸法を形を決める寸法と測るだけの寸法(参照)で切り替えたいが、図の上の右クリックからはできず、編集パネルの一覧を探す手間がある。
- 仕分け: A・作る(JC は編集パネルの「参照にする/駆動にする」だけで切り替えていた)

## 作った物

- 寸法の札を右クリックしたメニューに「参照にする」(駆動の寸法の時)・「駆動にする」(参照の寸法の時)を出す(`crates/kmb-ui-sketch/src/menu.rs` の `Ask::Driving`)。切り替えは編集パネルのボタンと同じ `Sketch::set_driving` を通り、駆動に戻す時は今の形で測った値から始める。できなければ寸法の誤りの欄に理由を出す。

## 決めたこと

- 寸法でない拘束(水平・一致など)の右クリックには出さない。
- 試験: `kmb-ui-sketch` の `a_dimension_is_switched_between_driving_and_reference_from_its_label`。前後の写真は寸法の見本の画面で撮った。
