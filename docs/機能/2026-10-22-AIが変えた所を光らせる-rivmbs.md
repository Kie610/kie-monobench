# AI が変えた所を光らせる

- 日付: 2026-10-22

## 作った物

動いている画面に AI(MCP の `app` の道具)がつないで文書を変えると、再計算の後に、変えた所を 1.8 秒光らせる(終わりの 0.6 秒で薄くする)。

- タイムライン: 足した・直した機能の札を差し色の枠で囲む(「タイムライン内を検索」と同じ枠)。
- ブラウザ: その機能の行と、その機能を含むボディの行を同じ枠で囲む。
- 3D のビュー: そのボディの面の色を差し色へ寄せる(強さは 6 段に丸め、段が替わる時だけ面の色を作り直す。GPU と CPU の描き方の両方。外観・材料の質感のボディも光らせる間は色で描く)。kmb-ui-view3d の `Scene::set_glow`。
- 下の帯: 「Claude 操作中」の札に道具の名前を添える(例「Claude 操作中: set_param(width = 70 mm)」、操作の実行は操作の名前)。
- 何を光らせるか: 要求の前の機能と、再計算の後の機能を比べ、足した・中身の変わった機能。パラメータだけ変えた時と取り消し・やり直し(機能の中身は同じ)は、計算の結果(形)の変わった機能。読むだけの要求、文書の変わらない要求は光らせない。画面の部品を操作する道具(`ui_*`・`command`・`script`)は流し終えてから比べる。
- 人の操作(コマンド欄で人が流した物を含む)は光らせない。光らせるのは MCP からの要求だけ(kmb-ui `live_ui.rs` の `live_tick`)。
- 矢印のカーソルは作らない。

## 試し方

- 設定の「AI との接続」で「AI からの接続を受ける」を入れ、AI から `app` の `set_param` で幅を変える。タイムラインの押し出しの札・ブラウザのボディの行・3D のボディが少しの間差し色で光り、下の帯に道具の名前が出る。
- 試験 `kmb-ui` の `claude_changes_light_up_the_changed_features_and_bodies`(読むだけでは光らない・変えると機能とボディが光る・時間が経つと消える・取り消しも光る)。
