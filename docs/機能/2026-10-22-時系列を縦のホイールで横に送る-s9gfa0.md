# 時系列を縦のホイールで横に送る

- 日付: 2026-10-22

## 作った物

2026-10-21 Kie が採用。下の時系列(タイムライン)の帯に機能が収まらない時、帯の上で縦のホイールを回すと横へ送る。

- 原因: 帯は横だけの ScrollArea で、egui 0.36 は既定で縦のホイールを横の送りに使わない(`Style::always_scroll_the_only_direction` が偽。egui の scroll_area.rs で確認)。Shift か横のホイールでしか送れなかった。
- 直し: 帯の Ui だけ `always_scroll_the_only_direction` を真にする(kmb-ui `timeline_ui.rs`)。縦の一覧の形は今までどおり。

## 試し方

- 機能が多い設計で、時系列の帯の上でホイールを回すと横へ送られる。
- 試験 `kmb-ui` の `timeline_tests::the_vertical_wheel_scrolls_the_timeline_sideways`(直す前は送られずに落ちることを確かめた)。
