# ナイトリーと手動の版のタグ

- 日付: 2026-10-29

## 作った物

配る物を組み立てる CI(`.github/workflows/release.yml`)に 2 つの回を足した(docs/verify.md の 15 節)。

- ナイトリー: 毎晩の main の検査が通った後、前のナイトリーから main が進んでいれば、検査したコミットを組み立てて、プレリリース「nightly」を中身ごと差し替える。本文は前のナイトリーから入った PR の題の一覧。
- 正式な版: 手で流す時に版の番号を入れると、ワークスペースの版と合うかを確かめ、main の先頭に注釈付きのタグ `v<版>` を付けて組み立て、リリースを下書きで作る。

## 決めたこと

- 毎日の更新を受け取れるようにしつつ、タグは正式な版と `nightly` の 1 本だけにして増やさない。ナイトリーは付け替え、古い物は残さない。
- ナイトリーは毎晩の検査を通ったコミットだけを出し、進んでいない日は出さない。GitHub の「最新」は正式な版のままにする。
- 正式な版のタグは GitHub の上で付ける。手元の PC の許可を待たずに、スレッドから回を起こせる。
- タグ付けから載せるまでを 1 回で行う。GitHub の道具で押したタグはほかの回を起こさないため。
- 版の番号はアプリの中では最後の正式な版のままにし、ナイトリーの区別は配る物の名前と本文で付ける。
