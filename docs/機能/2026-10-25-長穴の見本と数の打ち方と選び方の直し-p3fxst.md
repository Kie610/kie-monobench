# 長穴の見本・数の打ち方・選び方と名前の欄の直し

- 日付: 2026-10-25

## 作った物

- 長穴を描いている途中の見本の端を、できあがりと同じ半円にした(10-20 s5)。前は両端が丸ごとの円で見えた。中心と中心・全長・中心から・円弧・3 点円弧の 5 種すべて。半円は `slot_cap`(端の中心・幅の向き・ふくらむ側)で作る。
- 「正面から見る」(下の帯・右クリック・コマンド)を、もうその面を真正面から見ている時にもう一度押すと裏から見る(10-18 E15)。さらに押すと表に戻る。視点のボタンをもう一度押した時と同じ。`Camera::look_along_or_back`。スケッチの「正面から見る」は平らな図へ戻すので今のまま。
- 数の打ち方(10-22 u9): 先頭のカンマの小数(`,5`)を 0.5 と読むのをやめ、`1,5` と同じく誤りにした(「小数は点で書いてください」)。`max(1,5)` の引数の区切りはそのまま。代わりに全角の数字・小数点・符号(`１２．５`、`－３`、`−`)を普通の数として読む。全角の名前は名前のまま。スケッチの道具の欄に打つ数も同じ読み方にした。
- Shift+クリックの範囲は、最初に普通に押した(か Ctrl で足した)物を起点に保つ(10-24 h4)。前は範囲を選ぶたびに起点が最後に押した物へ移った。起点は文書ごとの状態 `range_anchor`。
- ブラウザの名前を付けた視点の名前の欄を、機能・グループの名前と同じく Enter・Tab・別の所を押すと決まり、Esc でやめる、にした(10-22 u6)。前は注目を毎こま戻していて、Enter か Esc を押すまで抜けられなかった。
