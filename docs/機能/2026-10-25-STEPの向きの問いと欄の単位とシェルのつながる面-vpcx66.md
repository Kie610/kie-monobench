# STEP の向きの問い・欄の単位の取り違え・シェルのつながる面の直し

- 日付: 2026-10-25

## 作った物

- JC が書いた STEP(頭の FILE_NAME の作った system が「jisaku-cadcam」)を読み込んだ時は、「立てますか」を聞かない。JC は Z を上にして書くので、立てる必要が無い。読み込んだ機能のデータに `upright` を持ち、画面はそれを見て問いを出さない。ほかの CAD の STEP には今までどおり 1 回聞く。
- 機能の式の欄で、長さの欄に角度(例「30 deg」)、角度の欄に長さを書いたら、計算を待たずに欄の横へ「単位の誤り」を赤で出す(`kmb_session::params::unit_mismatch`)。送りの速さのように長さの式で別の量を書く欄があるので、長さと角度の取り違えだけを見る。
- シェルの「接線チェーン」で開ける面を、フィレットの辺のたどりと同じくカーネルの辺の継ぎ目(なめらかな継ぎ目の辺でつながる面)でたどる(`kmb_cad::smooth_faces`)。継ぎ目の分からない辺がある時(truck など)だけ、前の網の法線の見分け方にする。
- 根本の直し: SMLib のカーネルは、辺の両側の面が接しているかを 1° で見ていて、フィレットで作った面と隣の平面の境目(近似の曲面のため 1.3° ほどずれる)を角と答えていた。核の `SEAM_DEG`(2°)にそろえた。面の法線を求められない辺は、黙って角と答えず「分からない」(`Seam::Unknown`)と答える。

## 試し方

- `kmb-ui` の `a_step_file_written_by_jc_is_not_asked_to_stand_up`、`kmb-cad-import-step` の `written_by_jc_reads_the_header`、`kmb-session` の `a_length_field_with_an_angle_is_told_at_once`、`kmb-cad` の `smooth_faces_follow_only_smooth_seams`、`kmb-solid` の `the_tangent_chain_opens_the_faces_joined_smoothly`(継ぎ目でたどる道に替えると、1° のままでは丸めの面へ進まず落ちることを確かめた)。
