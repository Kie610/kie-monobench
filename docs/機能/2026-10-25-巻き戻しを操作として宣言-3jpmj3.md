# 巻き戻しを AI・コマンド・台本からも同じ操作で

- 日付: 2026-10-25
- 意図: AI や台本で設計を進める人が、画面ではできる巻き戻しを AI から頼めない。間違った位置を渡しても何が悪いか分からない
- 仕分け: C・JC に合わせて作る(印を動かす口が CLI の専用コマンドだけで、操作として宣言されていなかった)。位置の誤りの知らせは A・作るで、同じ作りなので 1 本に束ねた

## 作った物

- ロールバックの位置を動かす操作 `cad.timeline.roll_back`(役割 `roll_back`)を kmb-cad で宣言した。引数は `position`(先頭から効かせる機能の数。省くと最後まで進める)。負の数と機能の数より後ろは「巻き戻しの位置 N が範囲の外です(0 から M)」の入力の誤りで止まり、何も変えない。コマンド検索・コマンド欄 `run` からも同じ操作が出る。
- 文書の変更にロールバックの位置を変える `Edit::SetRollback` を足した(コアの API に 1 つ足す。`CORE_API_VERSION` は公開まで上げない決まりなので据え置き)。
- CLI の `jc rollback <file> <position|end>` は、自前で位置を組むのをやめ、役割でこの操作を探して通す(CLI の終了の番号は入力の誤りの 1)。使う所の無くなった `kmb_session::edit::roll_back_to` は外した。
- MCP に道具 `roll_back`(`position` を省くと最後まで)を足し、`batch` にも入れられる。
- 画面のタイムラインの印と右クリックは今のまま(同じ `Op::SetRollback` を組む)。
