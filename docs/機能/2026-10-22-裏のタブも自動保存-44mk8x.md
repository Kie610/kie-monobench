# 裏のタブも自動保存する

- 日付: 2026-10-22

## 作った物

自動保存(設定の「自動保存」の間隔)が手前のタブだけを見ていたのを、しまってある裏のタブも見るようにした(jc-ui `files_ui.rs` の `autosave_tick`)。

- 原因: タブを替えると文書ごとの欄(文書・未保存の印・自動保存の写し)は裏のタブへしまわれる(`tabs_ui.rs` の `switch_tab`)。自動保存は手前の作業場の欄だけを見ていたので、変更してから別のタブへ移ると、その変更は写しに書かれなかった。落ちると消えた。
- 直し: 手前のタブと、しまってある各タブで、同じ間隔の決まり(変更してから間隔だけ待つ)で写しを書く。写しはタブごとに別のファイル(タブを作る時に名前が決まる)。保存・変更を捨てて閉じると、そのタブの写しだけを消す(前と同じ)。
- 書くのは画面の手番のまま(文書の JSON だけなので短い)。別のスレッドで書く形は、JC は書く量が小さく、今は要らない。

## 試し方

- 文書 A を開いて寸法を変え、文書 B を別のタブで開く。設定の自動保存の間隔だけ待つと、データフォルダの recovery に A の写しができる。
- 試験 `jc-ui` の `autosave_writes_every_unsaved_tab_not_only_the_front_one`(直す前は写しが 0 件で落ちた)。
