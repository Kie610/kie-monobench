# HRTF の大きさの平らにそろえと帰属の書き出し

- 決定: 音の解析とHRTF
- 日付: 2026-11-01

## 作った物

- 処理の手順の段 `normalize`: 輪の枠の集まりの大きさを、耳ごとの全方向の平均の大きさで割る。`reference` が無ければ自分の平均(拡散音場)、あれば渡した集まりの平均(頭の無い時に測った物を渡せば自由音場)。割る量は最小位相の FIR にして掛け、立ち上がりを動かさない。`below_hz`(既定 200 Hz)より下は割らず、その 1 オクターブ上まで対数の大きさで滑らかにつなぐ。
- 処理の手順の段 `credits`: 帰属の文書(既定の名前 `帰属.txt`)を書き出す。集まりごとに題・データベース・測った頭・作者の連絡先・組織・許諾・出典(SOFA の決まりの属性)と、通した処理の記録(変更したこと)を並べる。無い属性は「(記載なし)」と書く。CC BY-SA の表示(作者・出典・条件・変更したこと)をこの 1 ファイルで満たせるようにするため。

## 決めたこと

- 方向の平均は重みなし。輪の格子なら 1 方向の面積がほぼ等しいので足りる。面積の偏った格子で厳密にそろえるなら、先に輪へ `regrid` する。
- `normalize` は輪の枠の集まりだけに使う(onset の段の後)。最小位相の FIR を輪のまま掛けるので、時間の並びの IR に掛けると立ち上がりの前の分と尾が混ざるため。
- 組み合わせた集まり(`combine`)の帰属は、大きさの元の属性と、時間の元の題・許諾を書いた処理の記録で表す。時間の元の集まりも `credits` の `sets` に並べて、その属性を別の節に出す。

## 確かめたこと

- 試験(2 本): `normalize` の後は 2.5〜20 kHz で全方向の平均が 0 dB から 0.5 dB 以内、900 Hz より下は元の大きさから 0.5 dB 以内、立ち上がりは 0 番の近くに残る。基準に自分と同じ集まりを渡すと拡散音場と同じ値。輪の枠でない集まりは入力の誤り。`credits` の属性・記録・「(記載なし)」・名前の誤り。
- 手元の 1 回の確かめ(試験の外、実測の 2 つの HRTF): TH Köln の KU100(2° の Gauss–Legendre)と SADIE II の D1(48 kHz・256 tap)の SOFA から、手順(onset → 2° の輪へ三角形で regrid → combine → shift +3 → trim 前 4・後ろ 128・20 kHz から上をならす → 表)で「D1 の大きさ・KU100 の時間」の表を作り、別の道具で作った同じ加工の表と比べた。CLI で 15 秒。目標の「float16 の丸めの範囲」には届かなかった。
  - 半スペクトル(100 Hz〜16 kHz の大きさの差、方向ごとの最大): KU100 は中央値 0.002 dB・99% 0.22 dB、D1 の加工は中央値 0.21 dB・99% 6.7 dB。
  - 差のほとんどは `regrid` の三角形の探し方から来る。三角形は近い 8 点から選ぶが、D1 は方位が 1° 刻みの輪と仰角のまばらな輪(−15° と 0° の間など)が並ぶので、近い 8 点が 1 つの輪に並んで囲む三角形が作れず、10318 方向のうち 8532 方向が最近傍になった(KU100 は 226 方向で、極の近く)。そのため測った輪の上(仰角 0°・±60°)では差が 0 dB、輪の間では最大の差の中央値が 13〜17 dB になる。比べた表は、上下の輪の左右の隣 4 点を双線形の重みで混ぜ(立ち上がりをそろえてから)、極は輪の平均で埋める。組み合わせ・切り出しの段が足す差は小さい(D1 の加工の差の中央値 0.21 dB は、組み合わせる前の D1 の格子の差 0.21 dB とほぼ同じ)。
  - 立ち上がりの表(0.5° の格子): 差の中央値 0.09 sample、最大 0.81 sample(両耳の時間差で最大 23 µs)。この crate は 2° の集まりから最近傍で引き、比べた表は 0.5° の方向ごとに補間する。
