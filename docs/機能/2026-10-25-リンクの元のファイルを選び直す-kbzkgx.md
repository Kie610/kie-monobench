# リンクした部品の元のファイルを選び直す

- 日付: 2026-10-25
- 元の項目: 10-20 a7(リンクの元を付け直す)
- 意図: リンクした元のファイルを移したり差し替えたりした人が、画面からつなぎ直せず、別のファイルに替えると部品が全部消えた扱いになる
- 仕分け: A・作る。「最新にする」(crates/kmb-asm/src/link.rs の update)はファイルを選ぶ入力を持たず、ボディを元の最初の機能の番号だけで対応させていた。

## 作った物

- 部品の右クリック(ブラウザのリンクした部品の行)に「元のファイルを選び直す…」(操作 `asm.link_relink`)を足した。ファイルの窓で選んだ文書を新しい元にして写しを差し替える(取り消せる)。元が見つからない時も出る(その時は「最新にする」は出ない)。固定はそのまま残す。
- ボディの対応を「番号と名前が同じ → 名前が同じ → (同じファイルの時だけ)番号が同じ」の順にした。別のファイルに替えても同じ名前のボディが付いて来る。「最新にする」も同じ対応を通る。
- 新しい元に見つからないボディは機能を残して計算の誤りにし(番号を `link::GONE` にして、新しい元で同じ番号になった別のボディを黙って出さない)、変更の名前に「元に見つからないボディ: …」と並べる。画面は、リンクの操作の後に変更の名前を下の帯に出す。
- 元が見つからなくなった時、下の帯に「見つかりません(写しのまま使います)」と選び直し方を出す。
- 前後を撮って並べて確かめた(写真はリポジトリに置かない)。

## 試し方

- 台本 `リンクの元を選び直す.jcs`(データパネルから天板をリンクで挿入 → 部品の右クリックに「元のファイルを選び直す…」)。直す前は落ちる。
- `kmb-ui` の `a_missing_link_source_can_be_picked_again_from_the_menu`(元を消す → 帯の知らせ → 選び直す → 見つからないボディが帯に並ぶ)。
- `kmb-solid` の `relink_follows_bodies_by_name_and_lists_missing_ones`(番号が違っても名前で付いて来る・無いボディは誤り・増えたボディは同じ部品へ・取り消し)。番号だけで対応させていた途中の作りでは、新しい元で同じ番号になった別のボディを黙って出し、この試験が落ちた。

## 特許

- 切れたリンクの付け直しと名前での対応は、ファイルの参照を扱う道具で広く使われる形で、新しい計算や操作部品は足していない(避ける形への追加なし)。
