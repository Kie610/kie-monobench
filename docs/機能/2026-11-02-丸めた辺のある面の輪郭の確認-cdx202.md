# 丸めた辺のある面の輪郭の確認

- 意図: 丸めた辺のある面に置いたスケッチで、面の輪郭が閉じて面全体を輪郭に使いたい。
- 仕分け: A・決め待ち(投影の辺の一覧が空になる例があり、端のずれをつなぐ変更だけでは直らない)。

- 日付: 2026-11-02

## 作った物

投影された丸めた四角の微小なすき間は閉じ、大きなすき間は閉じないことを、3通りの大きさで確かめる試験を足した。直方体の上面へスケッチを置く操作では、面の辺が写され、領域が1つになることも確かめる。

## 調べたこと

幅40 mm・高さ30 mm・角の半径4 mmの四角と、高さ30 mmに置いた半径12 mmの円をロフトした。端面にスケッチを置くと領域は0件となった。スケッチの平面は端面を指すが、要素と投影の一覧は空だった。`body_edge_refs` の直線の辺と円の辺の取得結果は、それぞれ成功した空の一覧だった。

この再現は、端のずれをつなぐ許容より前の段で辺が渡らない。許容を広げる変更はしていない。直せていない再現試験はコミットしていない。

## 決めかねたこと

ロフトの縁は一般の曲線として列挙される場合があり、投影が読む直線と円の辺だけでは不足する。曲線を投影できる形へ直す方法と、その写しを再計算で同じ辺へ追従させる方法を先に決める必要がある。面の輪郭が閉じるという完了の条件は満たしておらず、修正は止めている。
