# 角を共有する辺の鈍角・打ち間違えた操作に近い名前

- 日付: 2026-10-25
- 意図: 120° の角を測っても 60° と出る / AI や台本が操作の名前を打ち間違えると「ありません」だけで直せない
- 仕分け: A・作る(角は測定の土台があり直線どうしを 0〜90° に畳んでいた。名前の打ち間違いは、近い名前を出す所がコマンド欄と画面の部品だけだった)

## 作った物

- 測定で、端を 1 つ共有する 2 本のまっすぐな辺は、その角から出る向きどうしの角を出す(鈍角も出す)。共有しない辺・軸は今までどおり 0〜90°。
- 操作の ID を打ち間違えると、「操作 … はありません」に「近い名前: …」を 3 つまで添える(編集距離が名前の長さの 1/3、少なくとも 2 まで、または含む物)。画面・CLI の `jc run`・MCP の `run_action`・コマンド欄の `run` は同じ `Headless::run_with` を通るので、どれも同じに出る。書き出しの操作の指定(`save_action_for`)も同じ。比べ方は `kmb_session::near` の 1 つ。
- MCP の `batch` の知らない道具の名前と、コマンド欄のコマンドの近い物は、まだ別の比べ方のまま(後で `kmb_session::near` にそろえる)。

## 試し方

- `kmb-measure` の `two_edges_sharing_a_corner_report_the_obtuse_angle`、`kmb-session` の `near::tests::a_mistyped_name_finds_the_close_ones_first`、`kmb-mcp` の `a_mistyped_action_id_suggests_the_close_ones`。
