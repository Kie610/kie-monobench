# HRTF の輪の双線形と三角形の探し直し

- 決定: 音の解析とHRTF
- 日付: 2026-11-01

## 作った物

- `regrid` の替え方 `bilinear`(輪の双線形): 元の格子を仰角ごとの輪に分け、行き先の上下の輪で方位の左右の隣 2 点を方位の比で、上下の輪を仰角の比(度)で混ぜる。一番上(下)の輪より外は、極の方向が無ければ極を輪の平均で埋め、輪と極の間を仰角の比で混ぜる。極そのものは輪の平均。極の方向があればその値を使う。
- `regrid` の替え方 `triangle` の探し直し: 近い 8 点で囲む三角形が作れない時、行き先のまわりを接平面で 8 つの向きに分け、向きごとの一番近い点(90° より内)を候補に足して一番小さい三角形を選び直す。近い 8 点で囲める方向は前と同じ答え。

## 決めたこと

- 輪の双線形は、極でない輪に方位が 3 つ以上並ぶ格子だけに使う。輪にならない格子(方向が散らばった物)では方位の補間が意味を持たないので、黙って仰角だけで混ぜず入力の誤りにし、`triangle` を勧める。
- 仰角を 1e-6° より近い方向を同じ輪にまとめる。方位は 0 以上 360 未満にそろえ、0° と 360° の両方がある格子は同じ方位の 2 点として扱う(隣の間が 0 になるので、どちらか一方の値になる)。
- 三角形の探し直しは、近い 8 点で見つからない方向だけにする。見つかる方向の答えを変えないため(KU100 の 2° の格子で既に合っている値を動かさない)。
- 処理の記録には、双線形で輪の平均で埋めた極の数を書く。

## 確かめたこと

- 試験(2 本): 方位 1° の輪が仰角 −45°・−15°・0°・15°・45° の 5 本だけある、極の無い格子(D1 の形を小さくした物)で、
  - 三角形: ±45° の中の 2° の輪の方向がすべて上下の輪にまたがる三角形で囲まれ、最近傍に落ちる方向が 0、混ぜた方向は行き先を向く。探し直しを外すと、この試験は最近傍に落ちる方向が出て落ちる。
  - 双線形: 仰角に線形・隣どうしの間で方位に線形な値をそのまま補う、輪の上では元の値 1 つ、67.5° は 45° の輪と極(輪の平均)の半々、極は輪の平均、輪にならない格子は誤り、手順の JSON の `"method": "bilinear"` で選べる。
- 実測の D1・KU100 での比べ直しは PC が要るので、まだしていない(not-run)。
