# 目の開け閉めを文書に保存する(表示/非表示)

- 日付: 2026-10-26

## 作った物

- 文書の区画 `cad.visibility`(型 `kmb_interchange::visibility::Visibility`、名乗りは kmb-cad)。行の目を閉じた機能、目を閉じた部品、目を閉じたまとまり(スケッチ・ボディ・作業平面など)、原点の目を持つ。ボディの行の目は最初に作った機能で持つ。
- 操作「表示/非表示」(`cad.visibility`、役割 `SET_VISIBILITY`)。引数は `features`・`components`・`folder`・`origin` と `show`。`show` を省くと、対象が 1 つでも見えていれば全部隠し、全部隠れていれば全部出す。機能を省くと選んでいる機能を対象にする。変更は区画を置き換える 1 つで、取り消しで戻る。もう同じ状態なら変更にしない。
- `Headless::visibility` と `Headless::hidden_features` で見え方を読む。`status` の機能の行は、3D で隠している物に `"hidden": true` を付ける。
- 見え方は行の目・部品の目(親の部品も)・まとまりの目を合わせて決める。まとまりは機能の区分で決め、作業平面などは計算の結果に作業平面・作業軸・作業点を出した機能にする。

## 決めたこと

- 目を全部開けても区画は外さない。区画の無い文書は、後の機能が使っているスケッチと作業平面などを隠した状態として読み、読むだけでは変更にしない。
- 区画は形の計算の鍵に入らないので、目を替えても取り消しても形は計算し直さない。
- 選択表示と、機能を直す間の一時の見せは画面の状態で、区画に入れない。

## 試し方

- MCP の `run_action` で `cad.visibility` を引数 `{"features": [2]}` で流すと、`status` のボディの機能の行に `"hidden": true` が付く。取り消すと消える。
- 通しの試験は kmb-bundle の `tests/visibility.rs`。
