# スイープのねじれと終わりの大きさ

- 元の項目: 他のソフトの更新 2026-10-18 M7
- 意図: 経路に沿う管やコイル、ねじれた形を作りたい人が、スイープで輪郭をねじったり先を細くしたりできず、コイルやテーパーのパイプを作れない。
- 仕分け: A・作る。ロフトは揃っている。スイープ(crates/kmb-cad-sweep の `Sweep`、SMLib の crates/kmb-kernel-smlib/src/skin.rs `sweep`)は輪郭を経路の向きに合わせて回すだけで、ねじれと大きさの欄が無かった。
- 日付: 2026-10-25

## 作った物

- スイープの欄「ねじれ」(角度の式)と「終わりの大きさ」(割合の式。50% と打てば半分)。どちらも経路の長さに比べて一様に効き、回す中心と大きさの中心は経路の点、回す向きは経路の進む向きの右ねじ。経路から離した円を 720° ねじれば 2 巻きのコイル、終わりを小さくすれば先の細い管。
- CLI・MCP の `cad.sweep` も引数 `twist`(deg)・`scale`(倍率)で同じ物を作る。欄の式はパラメータの名前の変更に追従する。
- カーネルの口 `Kernel::sweep` に `twist`・`scale` を足した(コアの公開の項目。CORE_API_VERSION は上げない)。SMLib は、ねじれか大きさのある時だけ、経路の区間ごとに 10° おきの断面(少なくとも 4 つ)を並べてなめらかにつなぐ。どちらも無い時は前と同じ正確な面(押し出しと回転の面)のまま。truck は前と同じくスイープに対応していない。
- 止める時: 閉じた経路でねじれか大きさを使う(一周した輪郭が始まりと合わない)、倍率が 0 以下か 100 倍を超える、倍率に単位を書いた、輪郭が経路の円弧の中心の側へはみ出す(大きくした断面でも確かめる)。
- 鏡に写したスイープはねじれの向きを逆にする。
- 試験: crates/kmb-kernel-smlib/tests/skin.rs の `an_end_scale_makes_a_frustum_and_a_twist_keeps_the_volume`(角錐台の体積、90° ねじった角柱の体積)・`a_circle_off_the_path_twisted_twice_is_a_coil`(コイルの体積 = 断面 × 高さ)・`a_twisted_pipe_through_a_corner_and_a_bend_keeps_the_area_times_length`・`a_twist_on_a_closed_path_and_a_zero_scale_are_refused`、crates/kmb-solid/src/sweep_loft_tests.rs の `a_sweep_twists_and_narrows_by_its_fields`(文書の欄から)。
- 特許: スイープのねじれと端の倍率は古くから広く使われる作り方で、避ける形は無し(確定度 A。新しい操作部品は作っていない)。
