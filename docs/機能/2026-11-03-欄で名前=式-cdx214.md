# 数の欄で名前付きの式を使う

- 日付: 2026-11-03
- 意図: 数の欄で「名前=式」と打ってもパラメータができるのはスケッチの寸法の欄だけで、機能の欄では作れない。式の欄に名前が入った窓は候補が勝手に開く恐れがある。
- 仕分け: C・作る(寸法の欄の道を機能の欄にも広げ、判定を1つにまとめる)。

## 作った物

押し出しの距離や組立の位置・回転角、行ごとの半径など、記述子が数の欄として宣言する式に「名前=式」を指定できる。確定するとパラメータができ、欄はその名前になる。パラメータと欄は1回の取り消しで戻る。画面の編集パネル・形の横の値の箱・CLIとMCPの機能の値を変える口は、同じ変更を通る。

名前の正しさ・予約語・パラメータと寸法の名前の重複・式の計算・単位補完は、`kmb-session::params` で共有する。スケッチの寸法も同じ確認を使う。誤りの文言は日英で用意し、画面の表示言語で出す。知らない欄や文章の欄を名前付きの式として解釈しない。

## 決めたこと

- 数だけの右辺は欄が宣言した単位で補う。長さは文書の長さの単位、角度はdeg。スケッチ寸法が単位を省く時のmm・degの扱いは保つ。
- 確定前の入力予告でパラメータを作らない。名前・式の確認に失敗したら文書も取り消しの履歴も変えない。
- パラメータの表に出す機能の範囲は広げず、機能の値を変える口は記述子の数の欄を直接調べる。
- 名前を持つ機能の編集を開いた直後に候補が開く件は、実際の編集画面で起きなかった。候補が開かずEsc1回で閉じる試験を残し、候補の処理は変えない。

## 試し方

押し出しの距離に「w=20」を打って確定すると、欄がwになり20 mmになる。取り消すとwと距離が一緒に戻る。MCPの画面の台本でも同じ入力と取り消しを通す。インチの文書の位置と回転角、行ごとの半径、同名・予約語・不正名・壊れた式・単位の取り違えも試験で確かめる。
