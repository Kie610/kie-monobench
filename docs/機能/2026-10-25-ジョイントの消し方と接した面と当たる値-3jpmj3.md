# ジョイントの Delete・接した面は動かさない・当たる値を聞く

- 日付: 2026-10-25
- 意図: ジョイントを直している最中に Delete を押しても何も起きない / 載せてある部品をつなぐだけのつもりが動いてしまう / ふたやアームがどこで当たるかを AI から知れない
- 仕分け: A・作る(3 件とも土台があり、足りない口を足す)

## 作った物

- ジョイントなどを直している途中に Delete で消すと、先に直すのを終えてから消す(前は消えた機能を直し続けていた)。取り消すと直した値のまま戻る。クリックで決める手順の途中の Delete は黙って捨てず、「手順の途中は消せません。Esc で手順をやめてから Delete で消します」と下の帯に出す。
- 合わせるジョイント(`asm.snap_joint`)で、部品 1 の原点が部品 2 の原点に既に重なり、Z が同じ線の上にある(載せてある・接している)時は、今の向きのまま動かさない「合わせる角度」と「反転」を初めの値にする。データの形は変えない。離れている時は今までどおりそろえる。
- 操作「当たるまでの値」(`asm.contact_reach`。引数 `joint`・`to`)を足した。ジョイントを今の値から `to`(回転は deg、スライダは mm)へ動かすと、接触セットの相手のどれにどの値で当たり、あといくつ動けるかを文で答える(形は変えない)。動きの範囲の外は範囲の端までを見る。MCP の `run_action`・CLI の `jc run`・コマンド欄から使える。計算は部品を引く時に止める計算(`contact::limit`)と同じ物を使う。
- 特許: 値を刻んで当たりを試す計算は、今ある接触セットの止め方そのもの(新しい計算は足していない)。答えを返す口を足しただけで、避ける形(docs/避ける形.md の自動分解の項)には当たらない。

## 試し方

- `kmb-ui` の `delete_while_editing_a_joint_removes_it_and_ends_the_edit`、`kmb-asm` の `a_snap_joint_between_touching_faces_keeps_the_part_where_it_is`、`kmb-solid` の `contact_sets_stop_a_dragged_joint_at_the_touching_value`(当たるまでの値の答えを足した)。
