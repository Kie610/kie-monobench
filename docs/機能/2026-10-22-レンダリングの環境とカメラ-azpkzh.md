# レンダリングの環境とカメラ

- 日付: 2026-10-22

## 作った物

環境とカメラ。レンダリングの作業空間の「シーンの設定」(設定の窓の 設計 → レンダリング)に、広く使われる CAD のシーンの設定と同じ欄を足した。前は環境の種類・背景(環境か透明)・大きさだけだった。

- 環境: 明るさ(lx、既定 1000)、環境の回転(°、光源の向きを Z のまわりに回す)、背景(環境・単色・透明)、背景の色(単色の時だけ出る)、グラウンド面(床を出すか)、反射(床に映り込み)、粗さ(床の映り込みのぼけ)。
- カメラ: 焦点距離(mm、35 mm 判の縦の画角で換算。既定 45 mm がこれまでの 30° と同じ)、露出(EV、既定 9.5)、被写界深度(注視点に合焦、ぼかしの強さを倍率で)、縦横比(ビューポートの縦横比・1:1・4:3・16:9・5:4・4:5・カスタム)。
- 縦横比を決めると、レンダリングの作業空間のビューに枠が出て、枠の外が暗くなる。キャンバス内レンダリングと静止画は枠の中を描く(枠の中だけを切り出したカメラ `Camera::cropped`)。静止画の高さの欄は、縦横比がカスタムの時だけ出す。
- 背景を単色にすると、床は影だけを受ける面(影の受け手)になり、単色の上に物の影だけが落ちる。
- 光の強さは lx/1000 × 2^(9.5−EV) を環境の明るさに掛ける。

設定は今まで通り文書の `render.scene` に JSON で残る。新しいキーは brightness・env_rotation・background_color・ground・ground_reflection・ground_roughness・focal_length・exposure・depth_of_field・blur・aspect。古い文書(キーが無い)は既定の値で読み、見え方は変わらない(焦点距離 45 mm = 30°、明るさ 1000 lx・露出 9.5 = 倍率 1)。CLI・MCP の render_still・render_turntable にも同じ引数がある(背景 color と background_color・brightness・exposure)。

縦横比の既定は「カスタム縦横比」(幅と高さのまま)。縦横比の無かった古い文書と同じ大きさの絵になり、黙って大きさを変えない。レンダリングの作業空間では、その比の枠がはじめから出る。

設定の窓は `.only` の条件を見て欄を出し入れするようにした(crates/kmb-ui/src/settings_ui.rs、`Field::applies`)。

## 作らなかった物

- 自分の HDR 画像を環境にする: 環境は式で書いた 3 種のまま。画像の読み込みと重要度の抽出が要るので別にする。
- 地面を平坦化(環境の画像を床に投影する): HDR 画像が無いので要らない。
- 合焦の点をクリックで選ぶ: 合焦は回す中心(注視点)に固定。
- 速い描き方(動画)の床の映り込み: 光線追跡の静止画とキャンバス内レンダリングだけ。
