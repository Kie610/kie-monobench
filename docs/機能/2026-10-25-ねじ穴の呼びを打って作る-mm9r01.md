# ねじ穴の呼びを打って作る

- 元の項目: 他のソフトの更新 2026-10-22 k8
- 意図: 細目や M14 以上のねじ穴を作りたい人が、穴のサイズの一覧(M2〜M12 並目)に無いので作れない。
- 仕分け: C・JC に合わせて作る。穴の呼びの表(crates/kmb-cad-hole/src/shape.rs `THREADS`)と、ねじの表(thread.rs `METRIC`、並目・細目)・書き方の読み取り(thread.rs `parse_size`)が別々にあった。切替を増やさず、呼びを打てば作る。
- 日付: 2026-10-25

## 作った物

- 穴の「サイズ」の欄を、一覧から選べて打つこともできる欄にした(一覧は前と同じ M3 が先頭の並目)。
- 読み取りはねじの表の `parse_size` に 1 つにした(`M6`・`M6x0.75`・`m16`・`M6×0.75`)。ネジ穴の下穴は `Size::tap_drill`(表の呼びは表の下穴、ほかは呼び径 − ピッチ)。前のねじ穴の径は変わらない。
- 通し穴は通し穴・ザグリ・皿の径の表が要るので、表の呼びだけ。表に無い呼びは理由を出して止まる。ネジ穴で表に無い呼びのザグリ・皿の既定は、径を決めた穴と同じ決め方(穴の径から)。
- 試験: crates/kmb-solid/src/hole_tests.rs の `a_tapped_hole_takes_a_typed_size_outside_the_table`。
