# 作業平面をミラー・分割・勾配の平面に

- 日付: 2026-10-27

## 作った物

- 平面の参照 `kmb_cad::PlaneRef` に `Datum { feature }` を足し、ミラーの対称の平面・ボディの分割の割る平面・勾配の引き出し方向に作業平面を使えるようにした。作業平面の寸法を変えると、写し・割る位置も付いて来る。
- 平面を選ぶ手順(「対称の平面を選ぶ」「割る平面を選ぶ」「引き出し方向を選ぶ」)の候補に、原点の平面の四角と並べて、その機能より前の作業平面の四角を出す(`kmb_cad::plane::plane_choices`)。CLI・MCP は引数 `plane` に作業平面の機能の番号を渡す。
- 平らな面も選べる平面の手順で、面の上に浮かせた作業平面の四角をクリックすると、後ろの面ではなく作業平面を選ぶ(前は後ろの面が先に当たり、面の上の作業平面を選べなかった)。視線の上で面より手前にある作業平面の四角を採る。原点の平面の四角は画面の上で大きさが一定で奥行きを決めないので、今までどおり面が先。スケッチを作成する時の平面選びにも効く。

## 決めたこと

- 欄の選択肢「作業平面」は、作業軸と同じく手順でクリックした時だけ入るので欄では隠す。
- 機能より後ろの作業平面は選べない(計算の順が回るため)。作業平面を作れなかった時は、別の平面に替えず、その下流を止める。
- 保存の版は上げない(`kind` で見分ける enum に行を足しただけ)。

## 試し方

- kmb-solid の `datum_tests`: YZ から 50 mm 浮かせた作業平面で板を写すと写しは x 60〜100 になり、60 mm にすると 120 まで伸びる。15 mm の作業平面で割ると法線の側は x 15〜40、25 mm にすると 25 から。作業平面の元の面が無い時は分割が作業平面で止まる。ミラーの「対称の平面を選ぶ」は前の作業平面を受け、後ろの作業平面は理由つきで断る。
- 画面の台本 `apps/kmb-app/tests/ui/作業平面でミラー.jcs`: 板の上面から作業平面を作り、ミラーの「対称の平面を選ぶ」で作業平面の四角を押すと、対称の平面が「作業平面」になる。クリックの直しの前は後ろの上面が選ばれて落ちた。

## 残り

- 押し出し・穴・回転の範囲「対象まで」の相手に作業平面(手順が面を選ぶ形なので、候補を足す形を別に作る)。
- 3D スケッチの直線を回転などの軸に選ぶ。
