# 作業軸と作業点

- 日付: 2026-10-26

## 作った物

- kmb-cad-datum に機能 `cad.datum_axis@1`「作業軸」を足した。作り方は 4 つ: 2 点を通る(ボディの角・円の辺の中心・作業点・座標)、ボディの辺に沿う(まっすぐな辺はその直線、円の辺はその円の軸)、円筒の面の軸、2 つの平面(原点の平面・平らな面・作業平面)の交わり。
- 同じ crate に機能 `cad.datum_point@1`「作業点」を足した。点はボディの角・円の辺の中心・座標(mm)のどれか。作業平面の 3 点と作業軸の 2 点に作業点を使える。
- 受け渡しの型は kmb-interchange の `datum` に `DatumAxis`(通る点・向き・描く範囲)と `DatumPoint`(位置)を足した。出力の名前は作業平面と同じ `datum`。
- 軸の参照 `kmb_cad::AxisRef` に `Datum { feature }` を足し、回転・円形と直線のパターン・ボディの移動の軸に作業軸を選べるようにした。軸を選ぶ手順の候補に、その機能より前の作業軸を出す(値 `{"datum": 番号}`)。回転は自分の軸の型に同じ 1 行を足した。
- 操作 `cad.add.datum_axis`・`cad.add.datum_point`(「構築」のまとまり)。作業軸は選んでいる物から作り方を決める: 角か作業点 2 つで 2 点、辺で辺に沿う、曲がった面で円筒の軸、平らな面 2 つで交わり。何も選んでいなければ押してからボディの辺をクリックする。作業点は角なら角、円の辺なら中心、何も選んでいなければ原点の座標の点(編集パネルで直す)。
- 3D のビューに、作業軸は灰色の線、作業点は灰色の点で描く(周りの物の線の役 `ink::line::SURROUND`)。

## 決めたこと

- 元の辺・面・角・作業点が消えたら別の物に付け替えず、作業軸・作業点を理由つきの誤りにする。重なる 2 点、平行な 2 平面のように作れない入力も誤りにする。
- 軸の欄の選択肢「作業軸」は、辺と同じく手順でクリックした時だけ入るので欄では隠す。
- 保存の版は上げない(どの型も `kind` で見分ける enum に行を足しただけ)。

## 試し方

- kmb-solid の `datum_tests`: 上面の辺の作業軸は板を厚くすると上がる。YZ と ZX の交わりの作業軸で板を 90° 回すと右ねじの向きに回る。平行な 2 平面は誤り。角の作業点は板を厚くすると付いて来て、それを使う 2 点の作業軸と 3 点の作業平面も付いて来る。重なる 2 点は誤り。円筒の軸と円の辺の中心。わざと壊した版(作業軸の参照を原点の X 軸に替える)では回す試験が落ちることを確かめた。
- 画面の台本 `apps/kmb-app/tests/ui/作業軸と作業点.jcs`。
