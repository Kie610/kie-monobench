# 面ごとの外観・外観の編集・分類と検索のあるライブラリ

- 日付: 2026-10-22

## 作った物

前は、外観はボディと部品にだけ付き、右クリックの決まった 18 色(材料の色 10・木 2・塗装 8)から選ぶだけで、色も粗さも直せなかった。

- 文書(crates/jc-core/src/appearance.rs): `DocumentData::appearances` に「このデザイン内」の外観(`AppearanceDef`: 名前・分類・色・金属・粗さ・元にしたライブラリの外観)と、面の外観(ボディの最初の機能 → 面の名前 → 外観の名前)を持つ。版 3 のまま足した(何も決めていない文書は書かない)。`Op/Edit::SetAppearances` で丸ごと置き換え、取り消せる。`Edit::SetBodyAppearance` も足した(操作からボディの外観を替える)。
  - 名前は、このデザイン内の外観を先に引き、無ければライブラリ(`DocumentData::resolve_appearance`)。ライブラリと同じ名前の外観を直すと、その文書の中では直した値になる。
  - 塗る順は、面の外観 → ボディの外観 → 部品の外観 → 物理材料の色。
  - 面の名前(「f2:side:e5」など)は形を作り直しても同じなので、寸法を変えても同じ面に付いたまま。面が無くなったら別の面に付け替えず、窓に「見つからない面 N」と出す(一覧の表の列も同じ)。
- ライブラリ(crates/jc-core/src/material.rs の `LIBRARY`): 前の 18 種(色と質感は同じ)を含む 61 種を、金属・塗装・樹脂・木・ゴム・石・その他の 7 つに分けた。名前と色は JC の独自。ガラス・液体は透けを描けないので置かない。
- 操作(crates/jc-io-render/src/appearance.rs、`render.appearance`、`role::action::APPEARANCE`): 1 つの操作を引数で使い分ける。`apply`・`remove`(`target` は body/face、`bodies`・`components`・`faces`)、`edit`(`color`・`metallic`・`roughness`・`rename`。名前を替えると使っている所も替える)、`duplicate`(「名前 (2)」)、`delete`(割り当て解除と削除)、`list`(このデザイン内の表)、`library`(`query`・`category` で探す表)。CLI・MCP も同じ。知らない外観・今のボディに無い面・ライブラリと同じ名前への名前替えは断る。
- 画面(crates/jc-ui/src/render/looks_ui.rs): 設計の「修正 ▾ → 外観」、レンダリングの「設定 → 外観」、A のキーで外観の窓を開く(画面を止めない)。
  - 上から、適用先(ボディ/コンポーネント・面。既定はボディ/コンポーネント)、選んでいる物の数、「選んだ物の外観を外す」、このデザイン内、ライブラリ(すべて/お気に入り・探す欄・分類ごとの一覧)。
  - 3D のビューで付ける物を選んでから見本を押すと付く(見本を引いて落とす形にしない。AGENTS.md の「押したまま動かす操作で形を作らない」に合わせ、選んでから押す)。
  - このデザイン内の見本の右クリック: 編集…・複製・適用するオブジェクトを選択・お気に入りに追加/外す・割り当て解除と削除。ライブラリの見本の右クリック: お気に入り・このデザインに写して編集…・複製。
  - 「外観を直す」の小窓: 名前・色(色の面と R・G・B)・金属・粗さ。OK・Enter で決め、キャンセル・Esc でやめる。
  - お気に入りは PC の設定(`layout.json` の `favorite_looks`)。
  - ボディと部品の右クリックの「外観」は、このデザイン内と分類ごとの一覧と「外観の窓…」にした(前の 18 色は分類の中にある)。
- 描き方: 3D のビュー(crates/jc-ui-view3d)はボディごとに面の外観の材質を持ち(`SceneBody::face_looks`)、GPU は面ごとに材質の番号を振る(`look_slots`)。CPU の描き方も面ごとに色と材質を替える。レンダリング・回す動画・アニメーションの動画・glTF は、網を材質ごとに分けて描く・書く(`jc_render::Object::with_faces`。木目の芯はボディ全体の箱に合わせる)。glTF は分けた網を「名前 (2)」のように別の物にする。

### 作っている間に見つけて直した物

- 3D のビューを CPU で描く時、描いた絵を使い回すかの指紋に材質(色・金属・粗さ)が入っておらず、色の同じ外観のまま粗さを直したり、面の外観だけを替えたりしても絵が替わらなかった(外観の名前を替えた後も前の赤のまま残った)。指紋にボディと面の材質を入れた。
- レンダリング・glTF・アニメーションの動画は、ボディに付けた外観だけを見て、部品の外観を受け継がなかった(3D のビューは受け継ぐ)。部品の外観も見るようにした。3D のビューの質感(金属・粗さ)も同じく部品の外観を受け継いでいなかった(色だけ替わっていた)ので直した。

## 作らなかった物

- 見本を 3D のビューへ引いて落として付けること: 選んでから見本を押す(上の理由)。
- レリーフ パターン(バンプ)・カットアウト・高度なハイライト: 光線追跡の網の法線を替える作業が要る。
- 物理材料を付け直した時に、そのボディの面の外観を外すこと: 黙って消さない決まりに合わせ、JC は残す。
- 3MF の面ごとの色: 3MF はボディの外観の色だけ書く。
- アニメーションの外観の段に、このデザイン内で作った外観を使うこと: 段の点検が文書を見ないので、ライブラリの外観だけ。
- 外観の窓での部品の選び方: 部品の外観はブラウザの部品の右クリック(と CLI・MCP の `components`)で付ける。
