# 外枠とメニューの日英

- 日付: 2026-10-27
- 決定: 表示の言語

## 作った物

- 分野 `frame`(窓のボタン・上の帯のボタンと説明・コマンド検索の欄・知らせの一覧・文書のタブとその右クリック・下の帯の案内と計算中の札・進みの帯)と `menu`(ファイルとヘルプのメニュー)を日本語と英語で書いた。簡体中国語・繁体中国語・韓国語は頭の注記だけのファイル。
- 設定の「表示の言語」を替えると、上の分野の字がすぐ替わる。ボタンの名前(画面の部品の木の名前)も同じ言語になるので、台本と MCP の `ui_*` は今の言語の名前で探す。

## 決めたこと

- キーの名前(Ctrl+S・Enter・Esc・Delete・Shift など)は訳さない。マウスのボタン(左・右・ホイール押し・ホイール)は訳す。
- 未保存の印などの付け足しは文を継がず、付いた形と付かない形を別の ID にする(`frame-tab-saved-modified` など)。
- ファイルのメニューの中の操作(STEP の読み込み・書き出しなど)の名前は操作の名乗りが持つので、ここでは訳さない(ツールバーの抜き出しで扱う)。

## 試し方

- 台本 `apps/kmb-app/tests/ui/表示の言語で外枠とメニューが替わる.jcs`: English にすると上の帯・タブ・下の帯・ファイルとヘルプのメニューが英語になり、日本語に戻すと戻る。
