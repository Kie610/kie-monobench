# 途中で半径が変わる丸めの失敗を再現する

- 日付: 2026-10-26
- 意図: 辺の途中で半径を変えて丸めた時に、計算できたと返りながら板の大部分が失われることを防ぎたい。
- 仕分け: C 試験だけ・修正は未完了(曲線の生成に問題を絞ったが、正しい補間を保つ修正には至っていない)。

## 作った物

円柱の円の辺を、途中で半径を変えて丸めた時の体積と網を確かめる試験を足した。小さい形をコードから作り、対応しないカーネルでは理由を記録して飛ばす。

長い板の試験を一時的に厳しくして、4通りの半径に加え、途中の点が2つある例、途中を太くする例を調べた。体積と指定位置の断面を確かめたが、下記の3条件が失敗した。修正できていない失敗の期待をPRに含めないため、この強化は外し、既存の「作れなければ理由つきで止まり、作れたら板を保つ」試験を残した。

## 分かったこと

- 60×40×8 mm の板では、始め1 mm・途中0.5 mm、始め1 mm・途中0.8 mm、始め1.2 mm・途中0.6 mm の3条件で、体積の守りが誤りを返す。始め3 mm・途中2 mm、途中の点が2つの例、途中を太くする例、円の辺は通る。
- 半径の法則を直接評価すると指定した値を返す。失敗する対称の例は、始端と終端を入れ替えても半径の並びが変わらないため、向きの取り違えだけでは説明できない。
- 端の傾きを0にする法則を辺の外まで延長すると、負の半径になる範囲がある。面を作る前の延長した曲線にも負の半径に相当する位置が現れ、指定した中央の半径を追っていない例があった。曲線を生成する内部のどの処理が原因かは未確定。
- 結合の設定順、結合の方法、円弧の作り方、曲線のパラメータを変える実験では、指定の形を保つ修正にはならなかった。端の曲率を0にする法則は試験の例を通ったが、補間の定義を変え、閉じた円の継ぎ目にも影響するため採らない。

## 未解決

根本原因の箇所を特定して直すには至っていない。製品の処理と体積の守りは変更していない。失敗する強化はPRから外し、再現の条件と調べたことをPRの本文に残す。既存の試験を消したものではなく、安全拒否を許す既存の期待へ戻している。解決済みとして扱わない。

## 試し方

`cargo test -p kmb-solid a_thinner_middle_on_a_long_top_edge_keeps_the_plate -- --nocapture` は、4例について安全に拒否するか、作れた板の体積が保たれることを確かめる。これだけでは丸めが成功したことを保証しない。`variable_fillet_on_a_round_rim_keeps_the_cylinder` は円の辺を確かめる。
