# 剛性グループを前のジョイントを書き換えない形に

- 日付: 2026-10-24

## 作った物

剛性グループ(crates/jc-asm/src/rigid.rs、`asm.rigid_group@1`)を、前のジョイント・位置を書き換えずに自分の位置で部品を動かす形にした。前は作る時に前のジョイントの `bodies` と `follows` に部品を足していたので、グループを消しても、タイムラインの印をグループの前へ戻しても部品が離れなかった(8-3「前の機能を書き換えない」に反する、F19)。

- データ: `members` に加えて、作る時に `follows`(グループの部品のどれかを動かす前のジョイント・位置、タイムラインの順)と `riders`(一緒に動くボディ: グループの部品とそれを土台にした部品。`with` はそのうち、もうそのボディを動かしている `follows`)を持つ。足した欄は既定が空なので、前の文書もそのまま読める(前の文書のグループは、作った時に書き換えた前のジョイントのまま動く)。
- 計算: `follows` の動きを順に掛けた物を P、ボディがもう受けた動き(`with`)を順に掛けた物を Q として、P・Q⁻¹ をボディに掛けて `moved:` で出す。出力 `transform` は P、出力 `ride`(`jc_interchange::animation::Ride`)はボディごとに乗せたジョイント。
- 後から作るジョイント(lib.rs の `links`): 土台がグループに乗るなら、`follows` にグループを入れ(グループがまとめて掛けるジョイントは入れない。`rigid::movers`)、新しく一緒に動く物をグループの `riders` に足す(土台を動かすジョイントに足すのと同じ)。動かす部品の今の位置から軸を戻すのも `movers` を使う。
- アニメーション・動きを見る表示・引く操作・接触の止め: `animation::moved_bodies` で、ジョイントのボディとグループがその動きに乗せたボディを一緒に動かす(`joint_poses`、`joint::drag`、`contact::limit`)。
- 点検 8-3 の例外(`REWRITE_KNOWN`)から `new_group` を外した。

## 作らなかった物

- ジョイントを作る時に、土台を動かす前のジョイントへ新しい部品を足すこと(`links`)は前のまま(足す機能と直す変更を別の関数で組むので 8-3 の点検には掛からない)。

## 試し方

試験 crates/jc-solid/src/asm_tests/motion_tests.rs の `rigid_group_moves_its_parts_together`(前の蝶番が変わらない、蓋を開くと札も動く、`moved_bodies` に札が入る、印をグループの前へ戻すと札が戻る、消すと戻り取り消すとまた動く、後から札につないだジョイントで蓋も回る、輪の組を断る)。
