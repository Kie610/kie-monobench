# 言葉の揺れの点検

- 意図: 使う人が、同じ操作なのに画面によって「削除」「消す」、「キャンセル」「やめる」と言葉が違って迷う。
- 仕分け: C・JC に合わせて作る。元は画面の字が翻訳の辞書にあるかの検査だが、JC は日本語だけで辞書が無い。代わりに用語表(docs/用語表.md)で使わないと決めた語が画面の字に残らないかを点検にした。
- 日付: 2026-10-25

## 作った物

- 点検「言葉の揺れ」(xtask/src/words.rs): `cargo xtask verify`・`checks` が、用語表の新しい節「使わない語(検査で止める)」の語と、crates/ と apps/ の `src` の文字列が丸ごと同じ時に落とす。文の中の語とテスト(`#[cfg(test)]` の中と名前が `tests` で終わるファイル)は数えない。用語表の「当てた言葉」の前の名前は、別の所では正しい語(「向き」「寸法」など)が多く、全部を落とすと誤りだらけになるので使わない。
- 今の揺れを直した: 接触セットの右クリックとレンダリングのギャラリーの「消す」→「削除」、下の帯の案内の「確定」「やめる」→「OK」「キャンセル」、ジョイントのドラッグの後の窓・アニメーションの段を足す途中・モデル管理の窓の「やめる」→「キャンセル」、モデル管理の「名前を変える」→「名前変更」、リンクの右クリックの「固定を外す」→「固定解除」、押し出しなどの演算の札の「新しいボディ」→「新規ボディ」、ねじ切りの欄「残す厚さ」→「残し量」。
- 用語表の「書き方の決まり」から、もう無い関数(`unit_for_label`)を指していた行を外した(欄は単位を宣言で持つ)。
- 試験: xtask/src/words.rs の 4 つ(表の読み取りと CRLF、丸ごと同じ字だけ・テストの中は見ない、テストのファイルを飛ばす、リポジトリの用語表に表がある)。

## 変わったこと

- 新しい画面の字に使わない語を書くと、検査で止まる。足したい語は用語表の表に行を足す。
