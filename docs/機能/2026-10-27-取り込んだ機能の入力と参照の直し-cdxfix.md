# 書き出しと機能の入力・参照

- 日付: 2026-10-27
- 意図: 設計した形を書き出す時と式や参照を使う時に、指定が黙って捨てられたり、誤りの場所が分からなくなったりすることを防ぐ。
- 仕分け: A 直す(書き出し・パターン・回転・ロフト・分割の土台があり、同じ操作と参照の決まりで確かめられる)。

## 作った物

`kmb-io-stl` の OBJ は単位換算後の頂点を小数 6 桁まで書く。
末尾の 0 と負の 0 は 3MF と同じ関数で取り除く。
書き出したボディ数・三角形数・単位はログに残る。
MCP の `export` の説明にも `.obj` が並ぶ。

`kmb-io-dxf` は、ほぼ縦の線の小さな雑音を含めて逆向きの重複をまとめる。
整理を止める `cleanup=false` でも、指定した `cleanup_tolerance` の範囲を確かめる。
画層名の改行や不正なグループコード、名前のない表は理由付きの誤りになる。
DXF の文字列を書き出す `to_dxf` は `Result` を返す。

`kmb-sketch` のパターンの式は「パターンの数」など、実際の欄名で誤りを示す。
表示用の欄名と参照用の名前を分け、日本語のパラメータ名も使える。
`kmb-ui-sketch` は入力中の Esc だけで式を取り消す。
入力していない時はエラーと見本を保つ。

`kmb-cad-revolve` は `profile` と `faces` の同時指定を誤りにする。
明示した `profile` は画面で選んだ面より優先する。
面から回転する輪郭の網の許容差は 0.001 mm とする。
共通の輪郭取得は既定の 0.01 mm を保つ。

面から作る新しい全回転では、同軸で包含を証明できる内側の道具を除く。
対象は単一領域で穴がなく、閉じた直線だけで軸の片側にある輪郭に限る。
凸な外側の全辺の半平面で、内側の全頂点が含まれることを確かめる。
曲線や穴のある輪郭、凹んだ外側、部分回転、異なる軸では道具を保つ。
同じ輪郭が重なる場合は先にある輪郭と区間名を保つ。
スケッチからの回転はこの整理を使わない。

近似の精度が変わる区間には、精度ごとに別の名前を付ける。
古い近似区間から作る面の参照は、別の面へ付け替えず理由付きで止める。
該当する面は選び直す必要がある。
直線と円弧から正確に読める輪郭は同じ形と名前を保つ。

`kmb-cad-sweep` のロフトは、点の断面で `kind: point` と `profile` を同時に指定すると誤りにする。
端の点の参照は、作業点の削除、スケッチの点の削除、頂点名の消失を理由付きで止める。
編集パネルの「端の点を選び直す」は日本語と英語の文言を持つ。

`kmb-solid` の分割縁の試験は、丸めた後も手前側を加工していることを確かめる。
元の手前の鋭角縁が消え、加工後の端点が y=0、z=6 と y=1、z=5 にあることを見る。
奥の y=20、z=5 の縁は元の位置に残る。
フィレットと面取りを幅 40 mm と 60 mm で確かめる。

## 試し方

`cargo test -p kmb-cli --test cli obj_export_writes_indexed_triangles_without_a_material_file` は実際の OBJ を読み直す。
頂点・法線・面の番号と正の体積、材料ファイルがないこと、書き出しのログを確かめる。
この試験は通常の CLI の検査から走る。

パターンの数へ `0` を入力すると、エラーが数の欄を指す。
入力していない時に Esc を押しても、エラーと見本を保つ。
暗い画面と明るい画面の文言を比べる。

既存の編集パネルでは 1280×800 と 1920×1080 で末尾のエラーが隠れる場合がある。
文言の比較は 1920×1400 で行う。
この変更ではパネルの配置を変えない。

点を端に持つロフトを開き、タイムラインの機能を二度押しして編集する。
英語の画面では「Reselect End Point」のボタンで端の点を選び直せる。
暗い画面と明るい画面でボタンの文言を確かめる。
