# プロジェクトの仕分け(モデル管理の画面の段 2)

- 決定: モデル管理と分類
- 日付: 2026-10-23

## 作った物

モデル管理の画面の設計(Kie 2026-10-21 決定)の段 2。プロジェクトの画面を新しいデザインにするのは Kie の決定(2026-10-23)。

- 前の「プロジェクトから探す」の頁(crates/kmb-ui/src/projects_ui.rs)をやめ、ホームの左にプロジェクトのフォルダの木(件数つき・三角で開閉・右クリックでエクスプローラーで開く・一覧から外す)、中央にフォルダとデザインのカード(パンくずつき)、右に概要を出す。
- 選ぶ: カードを押すと選び、Ctrl で足し引き、Shift で範囲。2 件以上で「N 件を選択中」の帯(移す・削除…・選択を解除・Esc)。フォルダのカードは二度押しで中へ。
- 移す: カードを左の木の行かフォルダのカードへ引いて離す(重なる間は点線と「5 → 7」)、または右クリック・帯の「移す」から行き先を選ぶ。左のフォルダを押すのはいつも開くだけ(Kie 2026-10-23「a」)。版の履歴(`.jc/history/<名前>/`)も一緒に動かし、元のフォルダの `.jc/moved.json` に移した記録を足す。リンクの部品は保存した絶対パスに元が無い時、この記録をたどって元を探す(kmb-asm `link::follow_moves`、続けて移した物も 16 回まで)。
- 名前を変える(右の概要の欄で Enter)・新しいフォルダ(左の欄、先頭に / で最上位)・削除(PC のごみ箱へ、版の履歴も。消す物の一覧の帯で確かめる。Kie q5)。
- 戻す: どれも中央の帯の「元に戻す」と、ホームを出している間の Ctrl+Z で戻せる(ごみ箱からの戻しは Windows と Linux。macOS は Finder で)。最近の一覧と開いているタブのパスも付け替え、戻す時は前の一覧に戻す。
- 分類をその場で直す(Kie q3): 右の概要の部品名・作品・ジャンル・タグ・材料の欄。欄を離れるか Enter で文書を書き直し、新しい版「分類を変更」として残す(縮小図は前の版の物)。開いているタブのデザインは、そのタブの「設計の属性…」で直す(二重の書き込みを避ける)。
- 右の概要: フォルダ(デザインとフォルダの数・大きさ・最後の変更・最近変えたデザイン 3 つ・ジャンルの内訳・よく付いているタグ(押すと絞り込む)・エクスプローラーで開く)、複数(縮小図・今の場所・大きさの合計・全部に共通の分類・一緒に動く物)。
- 絞り込み: 前の頁にあったジャンル・作品・タグの絞り込みを、中央の変更日の行に足した(全部の場所で使える)。フォルダの中では探す・絞る間はプロジェクト全体から出す(前の頁と同じ)。
- 中身は kmb-session: `organize`(移す・名前・ごみ箱・戻す・新しいフォルダ・分類・移した記録)と `library::folder_summary`。ごみ箱は `trash` crate(MIT、5.2.9。足した依存は urlencoding だけ)。画面はプロジェクトの木と概要を裏のスレッドで読み(同時に 4 本まで)、仕分けの後は前の物を出したまま読み直す。

## 決めたこと

- 移すのは「引いて離す」と「移す」の 2 通り。左のフォルダを押すのは開くだけ(Kie 2026-10-23「a」。設計.md の「押すと移す」は、1 回押すと概要のために選ぶ JC では、開くつもりで移ってしまうので採らない)。
- 移した記録は元のフォルダの `.jc/moved.json`(版の履歴と同じ `.jc` の中。データフォルダでなく文書の横に置くので、PC を替えてもフォルダごと付いて来る)。kmb-asm(層 cad)は kmb-session を使えないので、同じ形を自分で読む。形は両方の試験で同じ文字列を使って確かめる。
- フォルダそのものを移す・名前を変える・消すのは作っていない(デザインだけ)。「ここに新規デザイン」も後の段。

## 足した言葉

用語表の「ホームとモデル管理(2026-10-23 モデル管理の画面の段 1・2)」に、移す・名前を変える…・削除…・ごみ箱へ移す・元に戻す・新しいフォルダの名前・N 件を選択中・選択を解除・エクスプローラーで開く・全部に共通の分類・移すと一緒に動く物・絞り込みを外す。
