# 落ちた時の報告に作業中の部品を残す

- 日付: 2026-10-26
- 意図: 落ちた時の報告に、どの部品を作業中にしていたかが残らず、同じ操作をしても再現できない
- 仕分け: A・作る。作業中(アクティブ)の部品は開いている間だけの状態で文書に入らないので、報告の文書の写しからは分からなかった。

## 作った物

- クラッシュ報告(パニックと異常終了)に `active_component`(部品の番号と名前。文書の直下なら null)を足す(kmb-session `crash.rs`)。
- 画面と MCP は文書と一緒に作業中の部品を渡す。文書が同じでも、作業中の部品を変えれば印のファイルを書き直す。

## 試し方

- 試験: kmb-session `install_keeps_a_marker_with_recent_commands_until_dropped`(部品を変えると印に残る)、`an_unlocked_session_marker_becomes_an_abnormal_exit_report`(異常終了の報告に移る)。
