# 分割の縁と薄い壁の面の参照を確かめる

- 日付: 2026-10-26
- 意図: 蓋の縁を名前で指した丸めが寸法を変えると別の縁に行ったり外れたりしないか、薄い押し出しの側面にスケッチを描いても寸法や厚さを変えて付いて来るかが不安になる。
- 仕分け: C 試験だけ(辺は両側の面の名前で指す作り、薄い壁の辺は名前を順に付ける作りなので、起きない見込み。症状の形の試験を足して確かめる)。

## 作った物

`kmb-solid` の `adopted_reference_tests.rs` に2件の試験を足した。どちらも、起きないことを試験で確かめた。製品の処理は変えていない。

- 板を厚さの半分で分割し、蓋の切り口の手前の縁を、両側の面の名前で指して丸め・面取りする。板の幅のパラメータを40から60 mmへ変えても、同じ縁の位置に付いていること、削れる体積が縁の長さに従うこと、残りのボディは変わらないことを確かめる。
- 開いた線を薄く押し出した壁の+Y側の面を名前で指し、面の上のスケッチから2×2×3 mmの出っ張りを結合する。厚さの中央・内側・外側の3通りで、線の長さを40から60 mm、厚さを2から4 mmに変え、スケッチの平面の位置と法線、出っ張りを含む体積、保存する面の参照が同じことを確かめる。

## 決めたこと

外形の箱はカーネルの約束により少し大きくてよい。truck は各軸の両側に0.05 mmの余白を足すため、箱の端と形の端を同一視しない。出っ張りの実際の端は網の頂点で0.0001 mmの許容により確かめ、外形の箱がその端を含むことも確かめる。参照の平面の位置には0.000001 mm、体積には0.01 mm³の許容で別に確かめる。形や参照を誤って別の面へ移した場合に落ちる検査を保ち、薄い壁の試験はtruckでも飛ばさない。

分割の試験は平面による分割に対応するカーネルで流す。薄い壁の試験は同じ形の計算の道を通す。

## 試し方

`cargo test -p kmb-solid adopted_reference_tests -- --nocapture`
