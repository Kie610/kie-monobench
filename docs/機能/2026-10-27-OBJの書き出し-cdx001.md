# OBJ の書き出し

- 日付: 2026-10-27
- 意図: 設計した形を、描画や見た目を作るほかのソフトへ渡したい人が、広く読める網の形式で書き出せない。
- 仕分け: B 土台から作る(網の書き出しの土台は STL・3MF にあり、形式を 1 つ足すだけ)。

## 作った物

`kmb-io-stl` の操作 `io.export_obj` で、見えているボディを OBJ に書き出す。
ファイルメニューの「書き出し」に「OBJ を書き出す…」が並ぶ。
CLI・MCP・画面は同じ操作の宣言を通る。
`tolerance` は網の許容差、`exclude` は書かないボディ、`each` はボディごとのファイルを指定する。
`unit` は 3MF と同じく、省くと文書の長さの単位になる。

## 決めたこと

ボディの名前はブラウザと同じ名前で `o` に書く。同名には番号を添える。
OBJ の行を壊す制御文字とコメントの印は下線に置き換える。
頂点の共有は 3MF と同じ関数を使い、ボディ内で同じ位置の頂点をまとめる。
法線は三角形ごとに書き、面は `f v//vn` で頂点と法線を指す。
OBJ に単位の欄は無いため、座標を指定の単位に換算してコメントにも単位を書く。
材料の色は書かず、`.mtl` は作らない。

## 試し方

`kmb run part.kmb io.export_obj --out part.obj` で、見本を OBJ に書ける。
`--arg each=true` を足すとボディごとに分ける。
CLI の試験で、面の番号と体積、書き出しのログを確かめる。
`cargo test -p kmb-cli --test cli obj_export_writes_indexed_triangles_without_a_material_file` で実行する。
