# 公開しない資料を指さない

- 日付: 2026-10-25

## 作った物

リポジトリは後で公開するので、リポジトリの外に置く開発の記録(設計の控え・決定の台帳・引継ぎ・調べた資料・前後の写真)を指す書き方を外し、再び入らないよう点検で落とすようにした(xtask/src/products.rs、点検「他製品の名前」の中)。

- 断片・plan.md・verify.md・rules・消えたテストの表・コードのコメントにあった外の資料への道筋を、働きと理由だけの書き方に直した。前後の写真の置き場は「撮って並べて確かめた」に替えた。
- 点検が落とす物: 運用の記録と提案の置き場の道筋、設計の置き場の日付つきのフォルダ・特許の点検の置き場・資料のファイル(.md・.html・.png など)、作業場の共有の置き場の下の物、Artifact の URL。語と例は products.rs の試験にある。
- 落とさない物: 作業空間の名前の `design/…`(設定の頁・ピンの鍵・kmb-ui のフォルダ)、クラウドの検査の控え(`.cache/`)と検査の記録の置き場(設定の値として使う)。
- 名前を書いてよいファイル(消えたテストの表など)も、この道筋の点検は受ける。
- AGENTS.md 2 節の 7 に「外の記録の道筋も書かない」を足した。
