# 取残し加工の前の工具を直径とコーナー半径で打つ

- 日付: 2026-10-22

## 作った物

2D 輪郭・2D ポケット・アダプティブ(負荷一定)の取残し加工に、欄「取残し加工: 前の工具の直径」「取残し加工: 前の工具のコーナー半径」を足した(`kmb_cam_setup::RestSize`、`#[serde(flatten)]` で `rest_diameter`・`rest_corner`)。前の工具の番号が空の時に使う。番号があれば番号が勝つ。ライブラリに無い工具(人の手や別のソフトで先に削った工具)の削り残しを、その太さだけで削れる。

- 前の工具の形は、直径だけなら平、コーナー半径があればブルノーズとして削り残しを見積もる(`RestSize::tool`)。条件と刃長は使わない。
- 誤り: コーナー半径だけ(直径が無い)、直径が 0 以下、コーナー半径が直径の半分を超える。今の工具より細い前の工具は、番号の時と同じ誤り(`check_rest`)。
- 残り削りを見分ける所は、番号か直径のどちらかがあれば残り削りとする(`kmb_cam_setup::is_rest_data`): 工具ごとの G-code の書き出しを断る・「取残し加工」の候補に出さない・工具の順番の最初にしない(番号でたどる順番には入らない)。
- 加工の既定に直径とコーナー半径を入れない(入れると足す加工がみな残り削りになる)。工具の順番に足す時は、番号で打つので直径の欄を消す。
- ブラウザの工具の札は「Ø3.175 mm→T3」(番号なら今までどおり「T2→T3」)。

作っていない物: 取残し加工の「元: 前の操作・ストックのモデル」の選び方(JC は番号か直径だけ)。3D 粗取り・ペンシルの取残しは番号のまま(今回は 2D の 3 つ)。

## 決めたこと

- 番号と直径の両方があれば番号を使う(欄を消さずに切り替えられる)。
- コーナー半径は省けば 0(平)。直径の無いコーナー半径は黙って捨てず誤りにする。

## 足した言葉

前の工具の直径・前の工具のコーナー半径(用語表)。

## 試し方

作業空間「加工」→ ブラウザで「ポケット」を選ぶ →「T3 平 2 mm を順番に足す」→ 欄「取残し加工: 前の工具の番号」を空にし「前の工具の直径」に 3.175 →(コーナー半径に 2 を打つと誤り)→ OK → ブラウザに「Ø3.175 mm→T3」。試験 `kmb-samples` の `the_previous_tool_by_size_cuts_the_same`(番号 2 と直径 3.175 mm で同じ道になる。輪郭・ポケット・アダプティブ)、`exporting_by_tool_reduces_tool_changes_and_refuses_rest_machining`、e2e `apps/kmb-app/tests/ui/取残し加工の前の工具の直径.jcs`。
