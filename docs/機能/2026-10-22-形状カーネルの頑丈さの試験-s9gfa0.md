# 形状カーネルの頑丈さの試験(小さな穴・はみ出す角・穴のある面の網)

- 日付: 2026-10-22

## 作った物

ほかの CAD で見つかった形状カーネルの誤りが JC にもあるかを、同じ種類の形の試験で確かめた。どれも SMLib では正しく、直す所は無かった。

- 長い板(3000 mm)の小さな穴(半径 2)は、上の面を溝で分けても穴のまま。穴の周りを箱で切り出すと穴が残り、穴に合うピンを足すと埋まる。**truck は同じ誤りを持つ**(切り出しが穴の無い 4000 mm³ になる。理論は 3874.3)。truck は普段使わず、直すには third_party の truck の写しへ手当てが要るので、試験は SMLib の `differences.rs` から呼び、truck の契約には入れていない。
- 交わり(共通部分)で、0.27 mm だけはみ出す四角の角を円柱で切り落とす。両カーネルとも理論の体積になり、四角のまま返さない(truck は網から体積を出すので 3e-5 ほどずれる)。
- 表示の網で、穴を切り抜いた面の三角形は面の上に留まる。穴の側面の三角形の頂点は半径の上、上の面の三角形は面の高さで、面積の和は穴を除いた面積(穴を横切る三角形が無い)。網の細かさ 0.1・0.01 mm の両方、両カーネルで通る。
- 足し引きのやり直しで元の形から大きく外れた候補を捨てる直しは、JC の SMLib の足し引きにやり直しの候補が無いので当てはまらない(A、kmb-kernel-smlib にやり直しの処理が無いことを確かめた)。

## 試し方

- 試験 `kmb-kernel-smlib` の `differences::a_small_hole_in_a_long_plate_stays_a_hole_when_its_face_is_divided`、契約の `an_intersection_trims_corners_that_stick_out_a_little`・`a_display_mesh_of_a_face_with_a_hole_stays_on_it`(SMLib と truck の両方)。
