# 流れの矢印

- 日付: 2026-11-02

## 作った物

格子の流れの結果に「矢印を出す・隠す」を足した。一定の間隔に置いた矢印の向きで流れの向き、長さと色で速さを示す。2D と断面表示では平面の上に、断面を出さない 3D では空間に並べる。表示の切り替えは `study.view.arrows` で、速度の量を持つ格子の結果に出る。

2D・3D の流れの研究に長さの欄「矢印の間隔」を足した。式と単位を使え、空なら自動。`kmb-study::Plan` の表示用の値で渡し、解く仕事の鍵には含めない。文書に欄が無い時も読み込め、矢印は初めは隠す。

## 決めたこと

- 自動の間隔は平面の長辺に約 30 本、空間の長辺に約 12 本とし、セルの大きさの整数倍に切り上げる。指定の間隔もセルより細かくしない。
- 物体のセルには矢印を置かない。速度に比例した長さを使い、凡例の最大の速さで間隔の 0.9 倍とする。長さが間隔の 3% 未満なら描かない。
- 軸は三角柱、先の 25% は三角錐にする。矢印を出す時は流線と速さの色・凡例を共有し、速さを塗った断面とも同じ凡例を使う。矢印を隠した流線だけの表示は、流線専用の凡例を保つ。
- 点・向き・長さを求める純関数と、網を作る処理を分けた。凡例の全時刻・今の時刻の切り替えを長さにも適用する。

## 試し方

2D または 3D の流れの研究を実行し、結果の「矢印を出す」を押す。「矢印の間隔」を直しても解き直さずに表示が変わる。「矢印を隠す」で元の表示へ戻る。

一様な速度の位置・向き・長さ、物体のセルの除外、速度が半分の時の長さ、断面の向き、空間への配置と凡例の共有を試験で確かめる。画面の通しの試験では MCP の `ui_*` の道具で研究の実行と矢印の切り替えを押し、網の増減と文書が変わらないことを確かめる。

## 合わせて保つ物

研究の実行前の確かめと位相による変形を残し、矢印は解く条件に含めず表示だけに使う。組立の質量特性と曲線の情報を保つ共通の型・操作には変更を加えない。間隔の入力は長さの欄の共通の読み方を通し、保存済みの式を開く時には書き換えない。
