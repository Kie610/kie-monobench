# スケッチを終えても視点を戻さない

- 日付: 2026-10-25
- 元の項目: 10-23 u1(スケッチを終えても視点を戻さない)
- 意図: スケッチを描き終えてすぐ押し出したい人が、終えた途端に入る前の向きへ視点が飛んで、描いた所を見失う
- 仕分け: C・JC に合わせて作る。スケッチの編集器(kmb-ui-sketch)は 3D のビューと別に自分の視点を持つ(平らな図か、右ドラッグで回した 3D の視点)ので、終えると 3D のビューは入る前の視点のままだった。

## 作った物

- 中央のビューを持つ編集器に、最後に描いた視点を渡す口 `FeatureEditor::view_camera` を足した(既定は `None`)。スケッチの編集器は、平らな図ならその見え方と同じに見える「平面を正面から見る 3D の視点」(前からある `space_camera`)、回していればその視点を渡す。
- 編集器を終えた最初のコマに、3D のビューをその向き・真ん中・大きさ(傾きも)へすぐ替える(`Camera::restore_now`)。OK・Esc・終了のボタンのどれで終えても同じ。3D スケッチは今までどおり。
- 前後を撮って並べて確かめた(写真はリポジトリに置かない)。

## 試し方

- 台本 `スケッチを終えた時の視点.jcs`(写真 3 枚)。
- `kmb-ui-sketch` の `finishing_a_sketch_keeps_the_view_it_was_seen_from`(平らな図で終える → XY 平面を真上から見る向き。右ドラッグで回してから終える → その向き)。直す前は入る前の等角(ヨー -60°・ピッチ 30°)に戻って落ちる。
