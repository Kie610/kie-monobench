# 2026-10-22 採用分の小さな直し 9 件

- 日付: 2026-10-22

## 作った物

2026-10-22 に Kie が採用した 60 件のうち、JC に足りない・JC にも同じ欠けがあった物の小さな直し。どれも直す前に試験が落ち、直した後に通ることを確かめた。

- 中心の円: 円周を既にある点(線の端など)に合わせて描くと、円周上の拘束を付ける。前は半径を測るだけで、点を動かすと円が離れた(kmb-ui-sketch `view/mod.rs` の `Tool::Circle`)。直径を打った時・値を固定した時は付けない(2 点・3 点の円と同じ拘束)。
- オフセットの調べで見つけた物: JC のオフセットは写し全体で 1 つの拘束(`ConstraintKind::Offset`)なので、「端が元に引き戻される」不具合は起きない。代わりに、オフセットした線をトリム・分割すると `Sketch::replace_curve` がこの拘束を外し、ほかの辺の平行・距離の関係まで黙って消えていた。切った片へ付け替え、共有の端で接する関係だけ外す(kmb-sketch `tools.rs`)。
- 体積: truck の `signed_volume` は世界の原点のまわりで四面体を足していた。網を作れなかった面のすき間があると、形を原点から離すほど値がずれた(1 面欠けた 10 mm の立方体で 1000 → 14333 mm³)。網の外形の箱の中心のまわりで足す(閉じた網の値は変わらない)。SMLib は前から箱の中心で積分しているので済み。
- 行列の守り: `kmb_core::kernel::placement_problem` を足し、両カーネルの `transform` の入口で、最後の行が (0, 0, 0, 1) でない・数でない値がある・向きの部分の行列式が 0 の行列を断る。鏡映(行列式が負)と拡大縮小は通す。契約テスト `transform_refuses_a_matrix_that_is_not_a_placement`。
- ブラウザの長い名前: 行の名前は前から … で切っていた。切った時は名前の全部をツールチップに出す(kmb-ui `browser_ui.rs`。注意や状態の文があれば egui がその下に重ねる)。
- CLI の終了の番号(調べで見つけた): `--help` は前から 0 で終わる。引数の誤り(知らないコマンド・引数なし・要る引数が無い)が clap の 2 で終わり、JC の決まり(2 は計算の誤り)とぶつかっていた。`Cli::try_parse` にして 1(入力の誤り)にする。
- Delete: 面・辺・角だけを選んで Delete を押すと、前は黙って何もしなかった。消し方を下の帯に出す。ジョイントを直している間の Delete は、前から選んでいる機能を消す。
- パラメータ: 新しいパラメータの式は前から空で始まる。式の欄の Enter でも足せるようにした(候補を選ぶ Enter は除く)。
- 断面: JC の断面は文書に入れない画面の状態なので「編集」の行は無い。閉じて開き直すと、前に閉じた時の平面・位置・向きから始める(面を選んで開いた時は、その面に平行で真ん中から)。

## 試し方

- スケッチで線を描き、中心の円の円周を線の端に合わせる。線の端を引くと円が付いて来る。
- 箱の上の面だけを選んで Delete を押すと、下の帯に「面・辺・角は消せません…」と出る。
- 長い名前のスケッチをブラウザで指すと、名前の全部が出る。
- 断面を XY にして位置を動かし、閉じて開き直すと、同じ所で切れている。
