# STL・3MF を網のボディで読み込む

- 意図: 配られた STL や 3MF の部品を設計に取り込めず、加工用の形にするには別のソフトで作り直す必要がある。3MF の物の名前が捨てられ、ボディの名前が分からない。
- 仕分け: B 土台から作る。網を読み込んでボディにする読み手と機能を足す。
- 日付: 2026-10-31

## 作った物

`kmb-format` に STL・3MF と中央の目録を使う zip の読み手を置く。`kmb-cad-import-step` の `solid.import_mesh@1` が元の網を KMBMESH1・deflate・base64 で文書に埋め、単位と折れ目の角度から表示・加工の網を作る。`cad.import_mesh` はファイルの引数と許可範囲の検査を通す。画面・CLI・MCP は同じ宣言を使う。

「挿入」の一覧に「STL・3MF を読み込む…」を並べる。ツールバーの登録は一覧から使い、大きなボタンを増やさない。単位・折れ目の角度は編集パネルで直せる。複数の物はファイル名の部品にまとめ、同じ名前には番号を付ける。1 回の取り消しで機能・部品・名前が戻る。

## 決めたこと

- 元の座標はファイルの単位で持ち、評価で mm にする。3MF の部品と build の置き方を合成し、別の model も同じ包みの中だけで解決する。色・材料など読まない種類は注記に出す。
- 頂点は f32 のビットが一致する物だけまとめる。負のゼロはゼロとする。重なる頂点や面積 1e-12 mm² 未満の三角形を除き、その数を出す。閉じた網だけ、体積が負なら向きを返す。
- 閉じているかは頂点の番号でなく位置で調べ、各辺を 2 枚の三角形が逆向きに使うことを求める。閉じない網の体積は開いた縁の数つきで断る。表示・加工・網の書き出しには使える。体積と重心は網の近くを基準に計算して桁落ちを抑える。
- 網は `BodyKind::Mesh` で、面は平面の指定を持たない 1 面。問い合わせの控えは Arc で共有する。SMLib は設定した網のカーネルへ任せる。足し引き・面の編集・STEP の書き出しには使わず理由を出す。
- STEP の操作は網を除いた数と理由を知らせ、網だけなら空のファイルを書かず断る。STL・3MF・OBJ は網を含める。
- 表示の法線は、辺を共有し折れ目の角度以内の三角形をつなぐ扇ごとに面積で平均する。形や加工の点の位置は変えない。
- 三角形は 500 万枚まで。展開した zip は合計 2 GiB までで、暗号化・分割・データ記述子・zip64 は理由を返す。モデルの参照と XML は 64 段まで。頂点は三角形の上限の 3 倍までで、大きすぎる入力を断る。
- 保存形式とコアの API の版は変えない。新しく足したボディへ部品を作らず名前を付ける変更は `Edit::NameBodies` で表す。

## 試し方

STL のバイナリと ASCII、複数の solid、3MF の書き出しとの往復・単位・部品の入れ子・別 model・変換を小さな入力で確かめる。閉じた立方体と開いた網は両カーネルの同じ契約を通す。共通の操作からの読み込み・取り消し・保存、加工のセットアップと経路、STL と STEP の書き出しも確かめる。
