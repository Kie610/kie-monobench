# 丸い面の半径

- 日付: 2026-11-03
- 意図: フィレットの丸い面や球の面を測っても、面積しか出ず半径が分からない。
- 仕分け: A・作る(円柱の半径はあり、球・円環の当てはめが無かった)。

## 作った物

球の面と円環の面を、表示用の網の頂点から最小二乗で当てはめる。計測表に半径・直径・中心を出し、円環では管の半径と大きい半径を分ける。面積も網で測った値を残す。表の見出しは日本語と英語で表示する。

`kmb-measure::Kind` の `Sphere` と `Torus` は、MCPの計測と面の一覧のJSONにも出る。球は中心・半径・面積、円環は中心・軸・大きい半径・小さい半径・面積を持つ。文書の形式とカーネルの口は変えない。

## 決めたこと

- 球は座標の平均と縮尺をそろえ、球の式の最小二乗で求める。円環は点と面の向きの散らばりから複数の軸を試し、軸に沿う断面の円を初期値にして幾何的な距離を最小二乗で補正する。
- 円環の反復は最大40回で、点が多い時は決まった順の256点までを使う。認めるかどうかは、間引かない全頂点から曲面までの最大誤差で確かめる。
- 許容は既存の円柱の当てはめと同じく、半径rと中心cに対して `1e-4 × (1 + r) + 2e-6 × |c|` mmとする。有限でない値・特異な点列・半径の範囲外・管が中心まで届く円環は値を出さない。半径の範囲は既存の円柱と同じく0.000001〜1000000 mmとする。認められない曲面は面積だけを返す。
- 円環の「半径」「直径」は管の断面の値とする。「大きい半径」「大きい直径」は、円環の中心から管の中心の円までの値とする。
- 距離と面積は選んだ面の元の網で測る。半径の追加によって面を延ばしたり、中心から測る対象を増やしたりしない。曲面の距離を網で測る注も保つ。

## 試し方

箱の3本の辺を同じ半径でフィレットにし、角を「ローリングボール」にする。球面を選んで計測を開くと半径と直径が出る。円柱の縁の丸めでは管と大きい円の半径が出る。MCPの画面の台本で球面の選びと計測を通し、日英の表示を確かめる。解析的な球・円環・部分円環の網では半径と直径を数式の値と比べ、楕円体では面積だけになることを確かめる。
