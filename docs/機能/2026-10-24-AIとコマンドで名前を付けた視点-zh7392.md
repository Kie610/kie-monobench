# AI とコマンドで名前を付けた視点を使う・傾きを保つ・戻る時に跳ばない

- 日付: 2026-10-24

## 作った物

- 名前を付けた視点を画面のほかからも使える。MCP は `named_views`・`save_named_view`(真ん中の点・ヨー・ピッチ・傾き・見える高さ・投影)・`rename_named_view`・`remove_named_view`、`screenshot` の `named_view` でその向きで描く。CLI は `jc view list|save|rename|rm`。どれも `Headless` を通り、画面と同じ `edit::save_named_view` などの変更を使う(名前が空なら「視点N」、重なれば番号を足す。向きが正しくなければ断る)。
- 視点に傾き(`roll`、度。古い文書は 0 で読む)を足した。フリーオービットで傾けて保存した視点は、戻した時に傾きも戻る。
- 戻る時は、向き・傾き・真ん中・大きさを一緒に滑らかに移す。前は真ん中と大きさだけ先に飛び、その後に回り始めたので一瞬形が跳んだ。アニメーションの段はすぐ置く `Camera::place` を使う。

## 試し方

- 試験 `jc-ui` の `a_named_view_brings_back_the_same_direction_and_size`(跳ばない・傾きが戻る)、`jc-mcp` の `the_ai_saves_and_uses_named_views`。
- `screenshot` の `named_view` は向きだけを使い、形全体が収まるように描く(真ん中と大きさは使わない)。
