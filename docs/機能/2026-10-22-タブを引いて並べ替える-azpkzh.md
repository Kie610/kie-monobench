# 文書のタブを引いて並べ替える

- 日付: 2026-10-22

## 作った物

上の帯の文書のタブを左で引くと、落とす先に縦の線が出て、離すとその位置へ動く(crates/jc-ui/src/tabs_ui.rs の `move_tab` と `doc_tabs_bar`)。動かしても今のタブは替わらない。落とす先は見えているタブの範囲だけで、帯に入らず「ほかのタブ」の一覧にまとめたタブは、引く先にはならない。タブの空いた所を引くと窓が動く作り(title_drag)はそのまま。

画面の台本の `drag` は、3D のビューの面の名前で無ければ画面の部品(タブなど)の中央を押して引くようにした。`click` で欄の名前のラベルを押すと、横に入切が無ければ一覧の口を開く(どちらも crates/jc-ui/src/cmdline.rs)。

## 試し方

e2e apps/jc-app/tests/ui/タブを引いて並べ替える.jcs。試験 crates/jc-ui/src/tabs_tests.rs の `tabs_are_reordered_and_the_front_tab_stays_in_front`。
