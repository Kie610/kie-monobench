# 3D スケッチのフィレットの入口の確認

- 意図: 3D スケッチの線にフィレットをかけようとすると、何も起きず理由も出ない。
- 仕分け: A・試験だけ(3D の道具にフィレットは無く、名前で呼んだ操作は失敗を返すことを確かめた)。
- 日付: 2026-11-02

## 作った物

3D スケッチの編集中に、2D のフィレットを無反応のまま呼べる入口が無いことを確かめる試験を足した。現象は起きなかったので、製品の道具や表示は変えていない。

MCP の `ui_key` でスケッチを開き、`ui_expect` でフィレットのボタンが無いことを確かめる。`ui_click` とコマンド欄・台本の `click` は、フィレットを見つけられなかった失敗を返す。いずれも文書と 3D の道具の状態を変えない。

3D のコマンド一覧に 2D のフィレットの道具は無く、フィレット専用のキーの割り当ても無い。2D スケッチでは同じ名前のボタンを MCP のクリックで押し、フィレットの道具を始められることも確かめた。

## 決めたこと

3D スケッチにフィレットの道具は足さない。使えないボタンを新しく出す変更や、新しい断りの文も足さない。

## 試し方

`kmb-ui-sketch` の `fillet_3d_ui_tests` が、3D の入口の不在・失敗の答え・文書が変わらないことと、2D の道具を始められることを確かめる。2D の形を丸める操作は、既存の `fillet_by_two_lines_with_a_typed_radius` でも確かめる。
