# 自動拘束(足りない拘束と寸法の候補を予告して付ける)

- 日付: 2026-10-22

## 作った物

スケッチの拘束と寸法の候補を自動で作る。AI は使わず、決まった規則で候補を作る。

- 核: crates/jc-sketch/src/auto_constrain.rs の `auto_constrain`。拘束の候補は「今の位置で既に成り立っている」物だけで、種類の表の順(一致 → 線上・円周上 → 水平・垂直 → 接する → 同心 → 平行・直角)、同じ種類の中は要素の番号の順。寸法の候補は円の直径・円弧の半径・線分の長さ、最後に残った点の基準の点(原点か、選んだ点)からの横と縦の距離。値は今の形で測った値(mm、小数 3 桁)。
- 選び方: 候補を順に 1 つずつ試し、足すと式の数だけ階数が上がる(自由度が減り、余分にならない)物だけを残す(crates/jc-sketch/src/solver.rs の `independent`)。今の位置のヤコビ行列の行を、それまでに残した行の張る空間から外して、残りが有るかで見る。候補ごとに SVD をし直さないので、線 100 本の図で 2 秒(debug)。
- 画面: スケッチの 拘束 ▾ の「自動拘束」。押すと候補を図に拘束の道具の色(赤紫)で出し、パネルに「候補 N 個。全部を付けると自由度 A → B」、種類ごとのチェック、「寸法も付ける」、OK・キャンセルを出す。OK で 1 回の取り消しで付ける。Esc かキャンセルでやめる。予告の間に図が変わったら予告をやめる。線を選んでから押すと、選んだ線だけ。点を 1 つ選んでから押すと、その点を位置の寸法の基準にする。
- CLI・MCP: 操作 `cad.sketch.auto_constrain`(引数 dimensions・gap・angle)。選んでいるスケッチに候補を全部付ける。タイムラインの右クリックにも出る。

## 決めたこと

- 接するは、同じ点を端に持つ線分と円弧・円弧と円弧だけ。一致でつながるだけの別の点では、ソルバが接するを距離の式で書き、接する所で微分が 0 になって余分に見えるので作らない(試して確かめた)。
- 円・円弧の中心どうしが重なる時は、一致でなく同心にする。
- 平行・直角は端を分け合う 2 本だけ(全部の組を見ると候補が多すぎる)。
- 付けた後に解き直して確かめることはしない。ソルバは拘束ごとに SVD をし直すので、線 16 本の図でも debug で数分かかった(付けた後の普通の再計算も同じだけかかる。大きい図のソルバの速さは別の課題。F3 の「危ない所」)。行を外す時の許容はソルバの階数の許容より厳しいので、残した物がソルバに余分と見られることはない。
- 選んだ線だけを対象にした時も、相手が選んでいない線になる拘束(隣の線との直角など)は作る。選んでいない線どうしの拘束は作らない。

## 試し方

スケッチを直す → 拘束 ▾ → 自動拘束 → 予告を見て OK。e2e apps/jc-app/tests/ui/自動拘束.jcs(作図の見本で自由度 13 → 0)。試験 crates/jc-sketch/src/auto_constrain_tests.rs(7 本)、crates/jc-ui-sketch/src/auto_ui_tests.rs(2 本)。
