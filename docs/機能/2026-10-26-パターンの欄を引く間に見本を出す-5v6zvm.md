# パターンの欄を引く間に見本を出す

- 日付: 2026-10-26
- 意図: スケッチのパターンの数や距離を欄で動かしている間、結果が見えず、離すまで確かめられない。
- 仕分け: A・作る(JC は欄を動かし終えるまで反映せず、途中の見本も無かった)

## 作った物

- パターンのパネルの欄(数・角度・距離・向き)を引いている間、引いている途中の値でパターンを作り直して解いた見本を編集器に置き(`Editor::pattern_ghost`)、ビューは文書の代わりにそれを描く(`crates/kmb-ui-sketch/src/pattern_ui.rs`・`view/mod.rs`)。
- 文書は離すまで変えない(取り消しの段は今までどおり 1 つ)。離すと見本の値で文書に入り、見本は消える。値が変わった時だけ解き直す。

## 決めたこと

- 見本は寸法の値(パラメータを含む)で解いた、できあがりと同じ形にする。作れない値(数が 0 など)の間は見本を出さず、今の形のまま。
- 試験: `kmb-ui-sketch` の `dragging_the_count_shows_the_result_before_release`。
