# 輪郭フォントの文字(TrueType・OpenType と日本語の名入れ。1 本線は既定のまま)

- 日付: 2026-10-22

## 作った物

文字(`cad.text@1`)で PC の輪郭のフォントを選べるようにし、日本語の名入れを押し出し・ポケット・V 彫りで加工できるようにした。1 本線の Hershey は彫刻の既定として残す(新しい文字は前と同じく 1 本線)。

- 字の形を文書に入れる: 文字の機能のデータに `outline`(書体の名前・太さ・画面の名前、em の単位の数・大文字の高さ・ascent・descent、使う字ごとの送り幅と輪郭)を持つ。輪郭はフォントの単位のまま SVG の path と同じ書き方の文字列(`M`・`L`・`Q`・`C`・`Z`)。計算はこれだけを使い、フォントのファイルを読まない(別の PC で開いても形が変わらず、試験が PC に依らない)。字の形の入っていない字は空けて「字「…」の形が文書に入っていません」と知らせる。
- 読み方(crates/jc-text/src/outline.rs): skrifa(MIT/Apache。egui の epaint が使うのと同じ版で、新しく落とす物は無い)でヒンティング無しに読む。TrueType の 2 次のベジエは誤差なしに 3 次に上げる。OS/2 の fsType が「制限つき」(0x0002)と「ビットマップだけ」(0x0200)のフォントは入れずに断る。
- 字を形にする(crates/jc-text/src/glyph.rs): ベジエを許容差 0.002 mm で線分と円弧にする(スケッチのスプラインと同じ)。外と穴は輪の向きでなく入れ子の深さで決める(「回」は穴のある領域 2 つ)。輪どうし・自分自身と交わる輪(「の」のように払いが輪の中を通る字、可変フォントの重なる輪、字の間隔を詰めて重なった字)は、交わる輪だけを非ゼロの塗りでまとめる(i_overlay。まとめた輪は折れ線)。
- 高さの基準: 「大文字の高さ」(前と同じ)と「字の枠」(1 em。日本語の名入れ)。字の枠の時の縦の中央は ascent と descent の間。
- PC のフォントの一覧(crates/jc-text/src/fonts.rs): Windows は `%WINDIR%\Fonts` と `%LOCALAPPDATA%\Microsoft\Windows\Fonts`、ほかの OS は決まったフォルダと、JC のデータフォルダの `fonts`。一覧はファイルの頭と `name` 表だけを読む(TTC は書体ごと。画面の名前は日本語の名前があればそれ、文書には英語の名前を書く)。一覧は持ち主(操作と画面の編集器)が 1 回作って覚える(新しい static は使わない)。
- 画面: 新しい crate jc-ui-text の編集器。文字の設定欄の下の「フォント」の一覧に「1 本線(飾りなし)」「1 本線(飾りあり)」と PC のフォントを出し、名前で絞れる。字の形を入れることを許さないフォントは押せない。輪郭のフォントの文字を直すと、打ち足した字の形を PC の同じフォントから入れる。設定欄は、輪郭のフォントの時は「1 本線のフォント」「線の太さ」を隠し、「高さの基準」と「輪郭のフォント」を出す。欄の名前「大文字の高さ」は「文字の高さ」にした(字の枠の時もあるため)。
- 画面の共通の部分(jc-ui の設定欄): 同じ画面の更新で記述子の欄が変えたデータを、専用の編集器にも見せるようにした。前は編集器が前のデータを見ていたので、文字の欄に打って Enter で決めると、直すのを終えるのと同時で字の形を足す機会が無く、「文字がありません」になった。
- CLI・MCP: 操作 `cad.text.font`(`name` か `file`+`index`、`style`。空か「1 本線」で戻す)。文字の右クリックの「フォントを変更」(名前を打つ)も同じ操作。
- 線に沿わせる文字、幅に合わせる、複数行、揃え、文字を線に分解(輪郭の線分・円弧がスケッチの線になる)も輪郭のフォントで動く。

## 決めたこと

- 字の並べは送り幅だけ(カーニング・合字は入れない)。縦書きと右から左の文字は作らない(縦書きは句読点の向きの差し替えと縦の送りが要る。右から左は docs/避ける形.md)。
- 字の形はフォントを選んだ時と字を打ち足した時に入れる(画面の編集器と `cad.text.font`)。CLI で文字だけを直した時は、`cad.text.font` を同じ名前で流し直すと入る。
- フォントのファイルは同梱しない。試験には OFL のフォントから字を抜いた小さな物を置いた(crates/jc-text/tests/fonts/README.md)。
- 1 本線の文字のデータは前と同じ形(欄を足さない)。古い文書はそのまま読める。

## 足した言葉

用語表に「フォント」「1 本線(飾りなし)・1 本線(飾りあり)」「高さの基準: 大文字の高さ・字の枠」「文字の高さ」「フォントを変更」を足した。

## 試し方

文字を選ぶ → 設定欄の「フォント」→ 名前で絞って PC のフォントを選ぶ → 文字に日本語を打つ → 押し出し。e2e apps/jc-app/tests/ui/輪郭フォントの文字.jcs(見本の部品のボスの上の面に文字を置き、試験の日本語のフォントで「自作の名入れ」。Enter で決めても打ち足した字の形が入ることも見る)。試験 crates/jc-text/src/outline_tests.rs(9 本: 一覧から名前で探す、「回」の島と穴・「の」の自分と交わる輪、大文字の高さと字の枠、CFF の字、文書との往復、形の無い字、埋め込みを許さないフォント、重なる輪、円に沿わせる、幅に合わせる)、crates/jc-solid/src/text_outline_tests.rs(2 本: 「口回」を押し出した体積が領域の面積 × 高さ、形の無い字を知らせて残りを作る)、crates/jc-ui-text/src/tests.rs(1 本: 人の操作でフォントを選び、字を打ち足し、1 本線に戻す)。
