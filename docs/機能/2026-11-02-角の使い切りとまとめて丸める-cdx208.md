# 角の使い切りとまとめて丸める

- 意図: 辺の半分の半径で両端の角を丸められるようにし、面取り・フィレットで幾つもの角を一度に落としたい。
- 仕分け: A・作る(角を丸める・面取りする処理はあり、使い切りの半径と複数の角を一度に選ぶ道が無かった)。

- 日付: 2026-11-02

## 作った物

長方形の辺をちょうど使い切る丸めと面取りを受け、輪郭の長さ0の線分を残さない。四隅を同じ半径で丸めると、長方形は長穴、正方形は円になる。

角の点を Shift・Ctrl のクリックか囲みで選び、フィレットか面取りで値を打って Enter すると、選んだ角を一度に処理する。処理できない角が1つでもあれば何も変えず、成功すれば1回の取り消しで戻る。

## 決めたこと

- 長さの比較はスケッチの許容 1e-9 mm を使う。超える値は断り、使える長さを知らせる。
- 接点が辺の端に来るときは同じ点を使う。使い切る辺に寸法や投影の参照がある場合は補助線として残し、参照を切らない。
- 同じ円の隣接円弧はつなぎ、円周が一周すれば円にする。半径の寸法の番号・名前・値は保って新しい円へ付け替える。
- 複数の角の番号を先に集め、スケッチの複製に順に当てる。全部作れた複製だけを変更として返す。

## 試し方

単体試験で長穴・円・面取りの閉じた輪郭、許容の内外、円弧をまとめても寸法の名前が残ることを確かめる。画面の試験で Shift・Ctrl・囲み、四隅、1隅だけ作れない組、一度の取り消しを確かめる。

MCP の `ui_type` で囲みの台本を流し、`ui_click` でフィレット、`ui_type` で寸法の値、`ui_click` で取り消しまで通す試験もある。文書や選びの内部は書き換えない。
