# 後で見つけた異常終了は最後の記録の時刻を出す

- 日付: 2026-10-22

## 作った物

2026-10-21 Kie が採用。前回の起動が正しく終わらなかった報告は、次の起動で見つけるので、報告の時刻が「見つけた時刻」になり、落ちた頃が分からなかった。

- 原因: kmb-session `crash.rs` の `collect_abnormal_exits` が報告の `time` に今の時刻を入れていた。さらに起動中の印のファイルを書き直すたびに `started` も今の時刻に戻していた(起動の時刻が残らない)。
- 直し: 印のファイルに起動の時刻(`started`、最初の 1 回だけ)と最後に書いた時刻(`noted`)を持たせる。後で見つけた報告は `time` を `noted`(無ければファイルの更新時刻)にし、`detected` に見つけた時刻、`detected_later: true` を入れる。報告の一覧(ヘルプの「報告」)は「最後の記録 ○分前」と出し、ホバーで「落ちたのはこの後」と説明する。
- 公開 API は変えない(`Summary` に欄を 1 つ足すだけ)。

## 試し方

- JC を起動して少し操作し、タスクマネージャーで強制終了する。もう一度起動し、ヘルプの報告の一覧で、その報告の時刻が「最後の記録 …」になっていて、ホバーで説明が出る。
- 試験 `kmb-session` の `an_abnormal_exit_found_later_says_so_and_keeps_the_last_noted_time`。
