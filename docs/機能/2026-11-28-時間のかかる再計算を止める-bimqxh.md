# 時間のかかる再計算を止める

- 意図: 大きな部品の挿入や時間のかかる再計算の間、画面が待たされ、途中で止められない。
- 仕分け: C・JC に合わせて作る(中止の仕組みは解析とレンダリングにある。再計算と挿入にも同じ道を通す)。
- 日付: 2026-11-28

## 作った物

- 機能の状態に「止めた」(`FeatureStatus::Stopped`、JSON では `stopped`)を足した。利用者が再計算を止めると、計算していた機能とその後ろの機能が「止めた」になり、その前の機能の結果と形はそのまま出す。誤りの数には入れない(`RecomputeReport::stopped` で分かる)。
- コアの再計算に、利用者が止める印を足した(`recompute_stoppable`・`recompute_watched_stoppable`・`Document::recompute_stoppable`)。新しい変更で要らなくなった計算をやめる印(結果を出さない)とは分けた。
- 長い機能も途中で止まる: 機能は `EvalCtx::stopping` で印を見て、立っていれば誤りを返して早く終える。印を見た機能の結果は(誤りでも形でも)使わず、キャッシュにも残さない。組み込んだ文書の計算(`EvalCtx::recompute_nested`。リンクで挿入した部品)は、中の機能ごとに印を見て止まる。
- セッションの口: `Headless::stop_recompute`(走っている裏の再計算を止める)、`Headless::stopper`(別のスレッドから止める口)、`Headless::open_within`(決めた時間で止めて開く)。止めた後は勝手に計算し直さず、変更・取り消し・`Headless::recompute` で計算し直す。
- 画面: 下の帯の「再計算中」の札の横に「中止」。止めると「再計算を止めました」と「再計算」を出す。タイムラインの止めた機能は ⏹ の印と説明。コマンド欄は再計算の間は次を待つが、「中止」を押すコマンドだけは待たない(人も計算の途中に押すため)。
- MCP の `app`: `stop`(止める。止まるのを待たずに `{"stopped": 真偽}` を返す)と `recompute`(止めた再計算をもう一度行い、終わってから答える)。
- CLI: `kmb recompute <文書> --stop-after <秒>`。その秒数で終わらなければ止め、止めた機能の状態で出して終了の番号 2。文書は保存しない。
- 試験: `a_stopped_recompute_keeps_what_it_computed_and_stops_only_the_rest`・`a_long_feature_that_sees_the_stop_leaves_nothing_behind`・`stopping_inside_a_nested_document_stops_the_feature_that_holds_it`(コア)、`stopping_a_background_recompute_keeps_the_document_and_computes_again_on_request`・`opening_with_a_time_limit_stops_a_long_recompute`(セッション)、`a_long_recompute_is_stopped_from_the_status_bar_and_by_the_ai`(画面。`ui_click` で「中止」と「再計算」、`app` の `stop` と `recompute`)。
- 写真: `write_recompute_stop_screens`(apps/kmb-app/tests/screens.rs、暗明で計算中・止めた後・計算し直した後)。

## 決めたこと

- 止めた再計算の後の文書は、止めた機能から後ろを「止めた」にして下流だけを止め、文書の中身は変えない。取り消しの履歴にも残さない。
- 止めるのはボタンと操作だけにし、Esc には付けない(Esc は内側から 1 段ずつ戻す決まりのため)。
- 止める頼みは、走っている計算にだけ効く。止める印は計算を終えてから下ろす(始める前に立てた印も、その計算を止める)。
- 止める印を見ずに最後まで終えた機能の結果は残す(止める時に計算していた機能でも、終えていれば形を出す)。

## 残したこと

- 部品の挿入(ファイルを読んで組み込む部品のボディを数える所)は、まだ画面の糸で一度に行う。裏の仕事にして進み具合と中止を出すのは次の作業にする。挿入した後の再計算は、ここで作った止める口で止まる。
