# スケッチの開閉と作業中の部品の確認

- 意図: 部品の中で開いたスケッチを終えても、作業中の部品が変わらず、続けて作る機能が別の部品に入らないでほしい。
- 仕分け: C・試験だけ(この作りでは起きないことを、スケッチの開閉と続くボディの作成で確かめた)。
- 日付: 2026-11-02

## 作った物

部品Aを作業中にして部品Bのスケッチを開いて終えても、作業中はAのままで、続けて作った新規ボディがAに入ることを確かめる試験を足した。Bを作業中にした時は、同じ流れで新規ボディがBに入る。この作りでは起きないので、製品コードは変えていない。

実際のスケッチ編集器を組み込んだ画面へ、MCPの `ui_click`・`ui_key`・`ui_type`・`ui_select` を送る。部品の丸で作業中を替え、スケッチの行から編集を始め、終了のボタンで戻る。押し出しはコマンド欄から操作を呼び、編集パネルで「新規ボディ」を選んで決める。操作の間は画面の内部の状態を直に書き換えない。

## 決めたこと

スケッチの編集の前・途中・終了後と、押し出しを決めた後の作業中の部品を確かめる。足したボディが作業中の部品に入り、もう一方には入らないことも確かめる。
