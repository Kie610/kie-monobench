# 機能を消す時に、使っている物と中身がなくなる部品も一緒に消せる

- 日付: 2026-10-25
- 元の項目: 10-24 a1(挿入を消すと部品・ジョイントも消す)
- 意図: 読み込んだ部品を消した人が、つながる相手の無いジョイントや空の部品が残って混乱する
- 仕分け: C・JC に合わせて作る。勝手には消さず、消す前の確かめに「一緒に消える物」を並べて選ばせる(参照が切れたら止める・黙って消さない、の決まりのまま)。

## 作った物

- 機能を消す時の確かめの窓(右クリックの「削除」・Delete)に「一緒に消す」を足した。押すと、選んだ機能と、それを使う機能(たどった先も)と、中身が全部なくなる部品を 1 回の取り消し単位で消す。「削除」は今までどおり選んだ物だけを消す(使っていた機能は理由つきで止まり、部品の箱は残る)。
- 窓に「中身がなくなる部品」の一覧を出す。使っている機能が無くても部品の中身が全部なくなる時は、黙って消さずに窓を出す。
- 中身がなくなる部品の数え方は `jc_session::edit::components_emptied`(子の部品が残る部品・もともとボディの無い入れ物は数えない)、まとめて消す変更は `edit::remove_features_with_users`。
- 前後を撮って並べて確かめた(写真はリポジトリに置かない)。

## 試し方

- 台本 `挿入を消す時に一緒に消える物.jcs`(蓋つきの箱で「蓋」を消す → 蓋を上げる・蝶番・つまみの回転が並ぶ → 一緒に消す → Ctrl+Z → 削除だけ)。直す前は「一緒に消す」が無く台本が落ちる。
- `jc-session` の `removing_with_users_also_drops_the_parts_left_empty`。

## 作らなかった物

- ジョイントの土台(base)の部品は計算の入力でないので、土台のボディだけを消してもジョイントは「使っている機能」に並ばない(土台を指したまま動き続ける)。土台を入力にするか、消す時に部品の参照を見る拡張点が要る(コアの API に及ぶので別に)。
- 区画の中の参照(接触セット・動きの検討・アニメーション)の片付けは見ていない(区画の持ち主のモジュールが答える拡張点が要る)。
