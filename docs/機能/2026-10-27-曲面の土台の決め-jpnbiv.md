# 曲面の土台の決め(面のボディ・面を張る・厚みを付ける)

- 日付: 2026-10-27

## 作った物

コードはまだ無い。曲面(サーフェス)を作る最初の範囲「閉じた縁で囲んだ所に面を張る → 面に厚みを付けてソリッドにする」の作り方を決めた。作る本は 3 つに分ける: 面を張る(機能 `solid.surface_patch@1`、新しい crate `kmb-cad-surface`)、厚みを付ける(`solid.thicken@1`、同じ crate)、IGES を読む(`solid.import_iges@1`、`kmb-cad-import-step` の crate)。

## 決めたこと

- 面のボディ(厚みの無い面だけのボディ)は、ソリッドと同じく機能の出力 `body` の `Value::Shape` で持ち、種類はカーネルに問う(`Kernel::body_kind`、既定はソリッド)。`Value` と保存の形、`FORMAT_VERSION` は変えない。
- カーネルの口は既定で今の動きを変えない形で足す: `body_kind`・`planar_sheet`(平らな輪郭に面を張る)・`patch_sheet`(立体的な閉じた縁に面を張る。縁の区間は線・円弧・点を通る曲線・ボディの辺そのもの)・`thicken`(表側・裏側・両側)・`import_iges`。truck は面のボディを作らない(対応していない誤り)。
- 面のボディでは `mass`・`volume` を「面のボディには体積がありません。厚みを付けると体積と重さが求まります」の誤りにし、足し引き・シェル・丸め・面のオフセットも理由つきで断る。体積 0 の物として重さや加工へ黙って流さない。STL・3MF・OBJ の書き出しには入れず警告を出し、STEP には書く。
- 名前: 平らな面は `{tag}:face`、張った曲面は `{tag}:patch`(縁が 5 本以上で面が縁ごとに分かれる時は `{tag}:patch:{縁の区間}`)、面の縁は `{tag}:rim:{縁の区間}`(縁の辺の `EdgeInfo` は `[面の名前, 縁の名前]`)。厚みを付けた形は、面の向きの側を `{tag}:front:{元の面}`、反対を `{tag}:back:{元の面}`、縁の側面を `{tag}:side:{縁の区間}` にし、片側・両側を切り替えても名前の意味を変えない。
- 厚みは欄に数を打って決める。矢印を引いて決める操作は作らない。
- IGES のファイルは、STEP と同じくカーネルの crate の中で読む(カーネルの層は io に依存できず、面と境の線を io から渡す型がコアに無いため)。最初は面と立体だけを読み、線だけの要素は数を警告に出す。

## 足した言葉
