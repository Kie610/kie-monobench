# 3D マウスで視点を動かす(割り当てと速さの設定)

- 日付: 2026-10-26
- 意図: 3D マウスを持つ人が、片手で形を回しながらもう片手で選びたい。速すぎて飛ぶ・放しても少しずつ動く・後ろの窓まで動く・軸の向きが手に合わない、を設定で直せることも要る。
- 仕分け: B・土台から作る(読み取りの続き。視点の動かし方と設定を足す)

## 作った物

- kmb-ui-view3d: 1 コマ分の量 `Nav`(画面移動の画素・ズームの倍率の対数・画面の上の軸/右の軸/視線のまわりの回転・ボタンの操作)と `Camera::nav`。回すのは今の回す中心のまわり。拘束オービットは Z を上に保ち視線のまわりは回さず、フリーオービットは今の向きの基準で 3 軸とも回す。ズームは画面の中心(回す中心)へ寄る。
- 受けるビューは 3D のビュー(`view3d`)が決める: ポインタの下のビュー、無ければ最後にポインタが乗ったビューの 1 つだけ。画面の枠は毎コマ `set_nav` で量を渡すだけなので、設計・加工・スケッチの 3D のビューがどれも受ける。
- kmb-ui の `mouse3d`: 機器の値 → 0 合わせ → 遊び(既定 0.05)→ 緩い出だし(|x|^1.5)→ 入り切り・反転・主な軸だけ → 速さ(0.1〜4 倍)× 1 コマの時間(上限 0.05 秒)。速さ 1 でいっぱいに倒すと、回す 150 度/秒、画面移動はビューの高さ 1 つ分/秒、ズーム 3 倍/秒。手で持った形を動かす向き(押した向きへ形が動く)。
- 既定の割り当て: 左右に押す=左右の画面移動、上下に引く=上下の画面移動、前後に押す=ズーム(設定で「上下に引く」と入れ替え)、前後に傾ける=右の軸のまわり、ひねる=上の軸のまわり、左右に傾ける=視線のまわり。ボタン 1=全体表示、2=等角(なし・前・上・右にも替えられる)。3 番目からはログに出すだけ。
- 設定の「マウス」の「3D マウス」: 状態の行、使うか、速さ、オービット/画面移動とズームの入り切り、主な軸だけ、ズームの向き、6 軸の反転、遊び、今の位置を 0 にする、既定に戻す、ボタン 1・2。配置のファイル(`Layout::mouse3d`)に入り、無い欄は既定(古い設定でも起動できる)。「配置を既定に戻す」では残す。
- JC の窓が前にない時と、設定で切った時は動かさない(押されたボタンは捨てる)。

## 決めたこと

- 量はビューの引数(`Controls`)ではなく、コマごとに egui の一時の記憶で渡す。スケッチの 3D のビューへ引数を通さずに済み、受けるビューを 1 つに絞るのも 3D のビューの中で決められる。
- 2D だけのスケッチの画面(3D のビューを使わない物)はまだ受けない。

## 試し方

- 試験: `view3d::turn_tests::the_3d_mouse_turns_like_the_orbit_and_zooms_to_the_pivot`、`mouse3d::tests`(遊びと緩い出だしと速さの上限、主な軸・反転・0 合わせ・ズームの向き、ボタンの割り当てと古い設定、作り物の機器で設計のビューが回り、切ると止まる)。
- 実機: 3D マウスをつないで、設計のビューで押す・引く・傾ける・ひねるの向きと速さ、ボタン 1・2 を確かめる。向きが手に合わなければ設定の反転で直す。
