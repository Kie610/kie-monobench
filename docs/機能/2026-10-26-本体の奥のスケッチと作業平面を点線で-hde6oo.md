# 本体の奥のスケッチと作業平面を点線で描く

- 日付: 2026-10-26
- 決定: 本体の奥のスケッチを点線で
- 意図: スケッチや作業平面が本体の奥にあっても形の上に描かれ、どれが手前で、どれを選べばよいか分からない
- 仕分け: C JC に合わせて作る(今は形を描いた後に重ね描きするので奥行きを見ない。形と一緒に深度を見て描き、隠れた所は隠れた辺の点線にそろえる)

## 作った物

- 3D のビューで、スケッチの線(作図の線の役 `CONSTRUCTION`)と作業平面(面の役 `DATUM`)を形と一緒に深度を見て描く(kmb-ui-view3d の `Behind`)。手前に見える所は今の色と太さ、本体に隠れた所は隠れた辺と同じ刻み(4 point 描いて 3 point あける)と濃さ(描画の設定「隠れた辺の濃さ」)の点線。作業平面の塗りは手前に見える所だけ、名前の札は今まで通り上に重ねる。
- GPU では太さを線ごとに持つ線の管(`vs_wide_w`)と、手前だけを透かして塗る面の管を足した。線は稜線と同じだけ手前へ寄せるので、面の上に描いたスケッチは点線にならない。CPU の描画も同じ見え方にした。
- 表示 ▾ の「目安」に「全部透かす」(既定は切、画面の配置の `see_through`)。入れると今まで通り全部を形の上に重ねる。線だけの表示、ボディの無い文書も今まで通り。
- スケッチの単独の点、作業軸・作業点は今まで通り上に重ねる。

## 決めたこと

- 押した時の選び方は変えていない(面は手前から拾い、点線にした線は選ぶ対象を変えない)。

## 試し方

- 見本(`--sample`)でスケッチ「板の輪郭」と「ボスの輪郭」の目を開け、等角で見る。底面の奥の辺と円が薄い点線、手前の辺は水色の線で見える。表示 ▾ の「全部透かす」を入れると全部が水色の線になる。
- 作業平面を板の横の面から -25 mm で作り、本体の中に入った所の縁が点線、塗りが本体の上に出た所だけに付くことを見る。
