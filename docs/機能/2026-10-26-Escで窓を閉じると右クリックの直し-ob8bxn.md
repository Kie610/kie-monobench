# Esc で窓を閉じると右クリックの直し

- 日付: 2026-10-26
- 意図: 窓やメニューを開いた人が、いつもの手(Esc・素早い右クリック・複数選んで右クリック・好きなキーの組み合わせ)で思ったとおりに閉じる・使えるようにする。黙って閉じる・選びが変わる・受けたまま黙るを無くす
- 仕分け: C・JC に合わせて作る(どれも JC の作り(egui の窓とメニュー、3D のビューの右クリックの選び、設定のキーの受け方)から起きる別の症状で、元の直し方は真似ず、根の所を 1 つずつ直した)

## 作った物

- Esc で見るための窓を閉じる: 取り消しの履歴・文の窓・版の履歴・版の見比べ・レンダリングの絵・構成表・操作の手引きのうち、いちばん上の 1 つを閉じる。窓が無ければ編集パネルのパラメータを閉じる。閉じた Esc は使い切り、作る途中や選びを重ねて戻さない(Esc は内側から 1 段ずつ)。選んで決める窓(消す・名前変更など)は前から自分で Esc を受ける。`kmb-ui` の `Workspace::close_on_esc`。
- 右クリックのメニューは `kmb_ui::theme::RightMenu`(`right_menu`)だけで出す。egui のメニューはどのボタンのクリックでも閉じるので、素早く 2 回右クリックすると 2 回目(出たメニューの角か元の物の上)で一瞬で消えていた。出ているメニューの上か元の物の上の右クリックでは閉じず、元の物の上なら押した所へ出し直す。
- 3D のビューで選んでいる辺・頂点の上を右クリックしても、選びを変えない(前は下の面が選びに入り、メニューがその面に効いた)。`Workspace::context_pick`。
- キーの付け替えで Ctrl+C・Ctrl+X・Ctrl+V(と Ctrl+Insert)は Shift・Alt を足しても付けない。PC はこれらを写す・切り取る・貼り付けるとして渡し、キーとしては来ないので、前は受けたまま黙っていた。今は理由を出し、受けたまま別のキーを待つ。

## 決めたこと

- Esc で閉じる窓は、閉じても何も失わない見るための窓だけにする。設定の窓はキーを受けている間に Esc を使うので入れない。
- 右クリックのメニューに、egui の `Response::context_menu` を直に使わない。
