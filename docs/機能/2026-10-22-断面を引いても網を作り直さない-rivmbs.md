# 断面を引いても網を作り直さない(確かめただけ)

- 日付: 2026-10-22

## 作った物

2026-10-21 Kie が採用(断面の平面を引くと遅くなる)。JC には直す所が無いことをコードで確かめ、記録だけにした。

- GPU の描き方では、断面の平面の位置はシェーダーに渡す値だけで、切り取る側の画素を捨てる(`kmb-ui-view3d/src/gpu3d.rs`)。網の作り直しの鍵(gpu3d.rs の網の指紋)には断面の位置が入らないので、平面を引いても網は作り直さない。
- CPU で描く時(GPU の描画装置が無い所)だけ、断面にかかる三角形を描くたびに切る(`view3d.rs` の `clip_section_with`)。これは描く時の計算で、網は作り直さない。
