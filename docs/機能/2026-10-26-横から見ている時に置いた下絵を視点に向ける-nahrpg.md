# 横から見ている時に置いた下絵を視点に向ける

- 日付: 2026-10-26
- 意図: 正面や右から見ている時にキャンバスを置くと、絵が真横を向いて線にしか見えず、置けたのか分からない。
- 仕分け: B・土台に足す(置く平面を決める所に、今の視点を見る分岐を足す)

## 作った物

- 「キャンバス…」で何も選ばずに置く時、XY 平面に決めず、今の視点にいちばん向いた原点の平面(XY・YZ・ZX)に置く。角度は絵の上が画面の上になるよう 90° 刻みで決め、裏から見ている時は「水平方向に反転」を入れて文字が鏡にならないようにする(kmb-sketch-canvas の `face_view`)。平らな面を選んでいれば、今までどおりその面に置く。
- 操作 `cad.canvas_insert` に省ける引数 `view`(`{eye, up}`。視点へ向かう向きと画面の上)を足した。画面は、`view` を宣言する操作をファイルの窓から実行する時に今の視点を渡す(kmb-ui の `run_action_with`)。CLI・MCP は渡さなければ今までどおり XY 平面。

## 試し方

正面(または右)の視点にして、何も選ばずに 挿入 ▾ → キャンバス… → 絵を選ぶ。絵が正面を向き、字が正しい向きで見える。試験 crates/kmb-ui/src/design/canvas_tests.rs の `a_canvas_placed_from_the_side_faces_the_view`、crates/kmb-sketch-canvas の `a_canvas_faces_the_view_it_is_placed_from`。
