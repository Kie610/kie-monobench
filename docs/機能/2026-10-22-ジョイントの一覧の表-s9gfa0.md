# ジョイントの一覧の表

- 日付: 2026-10-22

## 作った物

2026-10-21 Kie が採用。組立のジョイントが何と何をつなぎ、今どの値かを 1 枚の表で読めるようにした。MCP からは `run_action` で `asm.joints`(「ジョイントの一覧」)を呼べば表が返る。MCP の入出力は変えていない。

- 列: 番号・名前・種類・動く側・土台の側・ボディ・原点・軸・値。
- ボディは「ボディN(「機能の名前」#番号)」と書き、どの形か分かるようにした。土台の無いジョイントは「地面(動かない)」。
- 値は回転・スライド・平面(X と Y)・球(傾き・ひねり)の今の値。
- メニューには出さない(調べ物の操作。コマンドの検索と MCP から使う)。

## 試し方

- 組立にジョイントを 2 つ作り、コマンドの検索で「ジョイントの一覧」を実行すると、表に 2 行出て、動く側と土台の側の名前が合っている。
- 試験 `kmb-solid` の `asm_tests::the_joint_table_says_what_each_joint_connects`。
