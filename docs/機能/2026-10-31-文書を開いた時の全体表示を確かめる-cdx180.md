# 文書を開いた時の全体表示を確かめる

- 意図: 文書を開いた時、形が画面の端や外に出ていて、全体を見る操作を押し直す。
- 仕分け: A・試験だけ(現行の初回描画は見えている形全体に合わせており、用意した文書では起きなかった)。
- 日付: 2026-10-31

## 作った物

`kmb-ui` の画面試験で、原点から 12 m 離れた位置にある 2 つのボディの文書を開いた。起動直後、空のタブへの読み込み、別の文書から新しいタブへ開く場合の 3 通りで、全体表示を押さずにすべての網の頂点がビュー内に収まることを確認した。現象は起きなかった。

保存した視点を選び、その後の描画と別のタブから戻る操作で、向き・中心・大きさが保たれることも確認する。空の文書は既定の視点を保ち、表示を合わせるだけでは文書の変更や取り消しの段を作らない。

## 決めたこと

表示の動きは変えない。現行の 3D ビューはまだ合わせていないカメラだけを初回に合わせ、形が無い間は待つ。形が届けば、見えているボディ全体の外形へ合わせる。

名前付きの視点は文書の一覧に保存され、選ぶと適用される。最後に選んだ視点を開き直した時に自動で復元する働きは、この確認では追加しない。

## 試し方

`cargo test -p kmb-ui offset_documents_fit_on_open_without_a_fit_command` と `cargo test -p kmb-ui a_saved_view_is_not_refitted_by_later_frames_or_returning_to_its_tab`。
