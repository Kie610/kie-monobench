# 尺度(ボディの大きさを倍率で変える)

- 日付: 2026-10-22

## 作った物

面を直す機能のうち「尺度」。修正のメニューの「尺度」(`solid.scale@1`、crates/jc-cad-modify/src/scale.rs)。欄は広く使われる CAD にそろえて、エンティティ(ボディ 1 つ)・点(中心。空なら原点)・尺度タイプ(均一・不均一)・尺度係数(均一)・X 尺度・Y 尺度・Z 尺度(不均一)。倍率は単位の無い数で 0.001〜1000。

形は今のカーネルの口 `Kernel::transform` に拡大の行列を渡して作る(SMLib も truck も移動と同じ道。新しい口は足していない)。面の名前は変えないので、尺度の後の機能は前と同じ面を指せる。元のボディは尺度のボディに置き換わる(コピーは作らない。写したいなら先に移動/コピーで写す)。

## 決めたこと

- 点を空にした時の中心は原点にした(移動/コピーの回転はボディの外形の中心)。原点に置いて作った部品が、置いた所のまま大きさだけ変わる。加工の原点もずれない。
- 不均一は円を楕円にする。穴・円筒の面は円でなくなるので、後の穴の加工やフィレットが円として扱えないことがある(試験で楕円柱の体積と幅は確かめた)。

## 足した言葉

用語表に「尺度」と欄の名前を足した。

## 試し方

修正 ▾ → 尺度 → ボディの面をクリック → 尺度係数に 2 → OK。体積を計測で 8 倍になる。e2e apps/jc-app/tests/ui/ボディの尺度.jcs。試験 crates/jc-solid/src/modify_tests.rs の `scale_grows_a_body_about_a_point_and_rejects_bad_factors`・`non_uniform_scale_turns_a_cylinder_into_an_elliptic_one`。

## 直した不具合

SMLib の移動(crates/jc-kernel-smlib/shim/jc_smlib.cpp の `jc_transform`)は、行列が回転と平行移動だけかを x・y の長さと直交と `cross(x, y)·z > 1` で見ていた。z の長さを見ていなかったので、Z だけを伸ばす行列(1, 1, 3)を回転と読み、拡大を落として形が変わらなかった(試験で修正前に失敗、修正後に通過を確かめた)。z の長さも見るようにした。今までは移動・回転と鏡映(行列式が負で回転と読まない)だけを渡していたので表に出ていなかった。
