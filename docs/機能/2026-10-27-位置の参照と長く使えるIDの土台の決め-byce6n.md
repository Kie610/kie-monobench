# 位置の参照と長く使えるボディの ID の土台の決め

- 日付: 2026-10-27

## 作った物

コードはまだ無い。機能が読むボディの決め方、ボディの長く使える ID、面の名前の縮め方、ジョイントの原点などの位置を形の要素の参照で持つ作り、古い文書の開き方を決めた。作る本は 3 つに分ける: ボディの ID と読み方(kmb-core、保存の形の版 6)、面の名前の縮め方(kmb-core と両カーネル)、位置の参照(kmb-interchange・kmb-cad-datum・kmb-asm・kmb-cad-modify)。切れた参照を種類ごとに選び直す・捨てる作業は、コアの公開の型を変えない形で別に作る。

## 決めたこと

- ボディの ID は、ボディを最初に作った機能と、その機能の中の番号(0 は出力 `body`、n は出力 `part:n`)。`body_names` と部品の木の鍵は今の JSON のまま読める。
- 機能のデータの中の機能の番号は「そのボディ」を指す印にし、再計算が「読む機能の手前での、そのボディの最新の形」に解く。ボディの形の移り変わりの表は、再計算の最初に文書と登録だけから 1 回作る派生物にし、`body_root`・`body_heir`・`visible_bodies` はその表を引く。間に機能を差し込むと後ろの機能が付いて来る。読むボディが手前で無くなっていたら、ほかのボディに付け替えず止める。
- 古い文書(保存の形の版 5 以前)の機能には「選んだ時点で固定」の印を付け、開いた形を前と同じにする。今の読み方と結果が同じ機能の印は開いた直後に外し、違う機能だけ知らせを出して「最新の形を読む」で外せるようにする。
- 面が 2 回以上割れた時の名前は「元の名前 + 最後に割った機能 + 番号」にし、何度割っても長くならないようにする。1 回だけ割った面は今と同じ `#k`。割れた切れ端の前の名前は無くなるので、それを指す参照は黙って付け替わらず止まる。カーネルは前の決まりの名前も持ち、古い文書の参照は開いた後に今の名前へ書き換える。
- ジョイントの原点・移動の点から点の位置・作業点は、角・円の中心・辺の中点・面の中心・平行な 2 面の真ん中・2 辺の交点・作業点・座標のどれかの参照で持ち、評価の中で解く。数だけの前の値は座標として読み、前の文書の形を変えない。解けない時は止め、選び直すか作った時の座標で固定する。
- 同じ形を何度も置く出現は、ボディの ID を変えずに、ボディの ID に置き方を足した別の ID で持つ。
