# 壊れたブーリアンの結果と、読めない書き換えを止める

- 日付: 2026-10-24

## 作った物

- ブーリアンを使う機能(押し出し・回転などの結合・切り取り・交差、ブーリアンの機能、フィレットと面取り)は、どれも jc-cad の `checked_boolean` を通す。対象があるのに結果が空になったら止め、交差なら「交差すると何も残りません(道具のボディが対象に当たっていません)」と言う。体積が向きに合わない結果(削るのに増える・足すのに減る)も「結果の形が壊れています」で止める。止めた機能は誤りになり、対象のボディは消えずに残る。これまではブーリアンの機能だけ確かめが無く、当たらない交差でボディが黙って消えた。
- MCP の `set_feature` は、`add_feature` と同じく読めないデータ(数の欄に "NaN" など)を文書に入れる前に断る(jc-session `Headless::check_data`)。これまでは書き換えると赤い機能が残り、後の機能まで誤りになった。

## 試し方

- 試験 `jc-solid` の `an_intersection_that_leaves_nothing_stops_and_keeps_the_body`(ブーリアンの機能と押し出しの交差の両方)。
- 試験 `jc-mcp` の `a_sketch_with_a_non_numeric_position_is_refused`(書き換えも断り、文書が変わらない。確かめを外すと落ちることを確かめた)。
- 見本の全部の面と辺の試験(`jc-samples` の matrix)で、3D の見本の面 f10:side:e9 を「結合」で押し出す手が、これまで通っていたのに止まるようになった。結果を調べると、SMLib の体積は 0、網の符号つき体積は元の +22650 mm³ に対し −22892 mm³ で、殻が裏返った壊れた形だった(画面では明暗が逆に見え、加工の内外を取り違える)。止めるのが正しいので、通った手の記録(tests/matrix_baseline.txt)から外した。結合で殻が裏返る元(カーネルのブーリアン)は未調査。
