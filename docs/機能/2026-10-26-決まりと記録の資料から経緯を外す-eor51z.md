# 決まりと記録の資料から経緯を外す

- 日付: 2026-10-26

## 作った物

- policy.md・plan.md・verify.md・地図.md・用語表.md と docs/機能/ の断片から、決めた人・AI・スレッド・PR の番号・決めた日付・判断の番号・比べた一覧の番号を外した。決まりは今の形だけを書き、理由は読み手の判断に要る時だけ残した。
- 点検「記録の資料の経緯」(`xtask/src/prose.rs` の `check_records`): 決まりと記録の資料に、決めた人と AI の名前を書いた行を落とす。コードの区画・インラインのコード・画面の下の帯の字(「Claude 待ち受け中」など)は見ない。
- 点検「採用分の仕分け」: 他のソフトの更新から採った物の断片は頭に「- 意図:」「- 仕分け:」を書き、「- 元の項目:」を書くと落とす(`xtask/src/docs.rs` の `HISTORY_FIELDS`)。

## 決めたこと

- 採った物の断片が、どの項目から採ったかは書かない。項目の日付と番号はリポジトリの外の開発の記録で断片の名前と結ぶ。
- 測った日・特許の満了の日・上流のリリースの日のような事実の日付は、決まりと記録の資料に書いてよい。点検は名前だけを見る。
- 「スレッド」は計算の用語(別のスレッドで作る)でも使うので、決まりと記録の資料の点検では数えない。
