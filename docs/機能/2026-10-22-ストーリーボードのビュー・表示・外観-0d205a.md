# ストーリーボードのビュー・表示/非表示・外観

- 日付: 2026-10-22

## 作った物

アニメーションのストーリーボードの段に 3 種類を足した(`kmb_core::animation::StepKind`)。

- ビュー(`View { view }`): 前のビューの段の視点から、この段の視点(`ViewPose`: 注視点・ヨー・ピッチ・見える高さ・透視。名前を付けた視点と同じ量)へ動かす。注視点はまっすぐ、ヨーは近い回り方、高さは比で動かす。最初のビューの段の前はその段の視点(`view_at`)。
- 表示/非表示(`Visibility { targets, visible }`): 部品を段の始めに見せる・隠す(`shown_at`)。後の段が前の段を上書きする。
- 外観(`Appearance { targets, appearance }`): 部品の外観を段の長さをかけて替える(色を混ぜる。`appearances_at`)。設計の外観は変えない。

操作は kmb-asm の `anim.view`(リボンの「ビュー」のまとまり。役割の印 `role::action::ANIMATION_VIEW`)、`anim.visibility`・`anim.appearance`(「変換」)。表示/非表示と外観は、部品の面を選んでから押すか、押してから面をクリックする(ブラウザで選んだボディでもよい)。表示/非表示は省くと今の時刻の様子の逆、外観は省くと今の外観と違う最初の塗装の色で、段の帯の欄(「見せる」・外観の一覧)で直す。

段の帯の左に「記録」(赤い記録ボタン)。入れるとビューの段が無ければ今の視点を始めの段にし、入れている間は視点を動かして 0.4 秒止まるたびにビューの段を足す(ホイールのひと続きは 1 つの段)。ビューの段があれば、時刻を動かすたびに 3D のビューの視点をその時刻の物にする。ビューの段の欄の「今の視点にする」で視点を置き換える。

アニメーションの動画(`render.animation_video`)は、コマごとにその時刻の視点・隠れ方・外観で描く。視点は画面のカメラと同じ式(`view_camera`)。画面で目を閉じたボディは、表示の段で見せない限り描かない。

作っていない物: 表示/非表示を時間をかけて薄くする(フェード。3D のビューと動画の描き方にボディごとの透けが無い)。段を再生ヘッドの位置に入れる(今までどおり帯の最後に足す)。外観の窓の大きなライブラリ(外観は今の 10 色と材料の色の一覧)。

## 決めたこと

- ビューの段の視点は名前を付けた視点と同じ量で持ち、ロール(画面の傾け)は持たない。投影は画面では画面の投影の設定のまま、動画では段の透視の印で描く。
- 表示/非表示は段の始めに替える(長さは次の段までの間。既定 0.5 秒)。外観は色を混ぜ、途中は質感の無い塗装、替え始めと替え終えた所は外観の質感で描く。

## 足した言葉

表示/非表示・外観・ビュー・記録・今の視点にする・見せる(用語表)。

## 試し方

作業空間「アニメーション」→ 段の帯の「記録」→ 視点を回して止める(段「ビュー」が入る)→「記録」を切る → 時刻を動かすと視点が戻る → 部品の面を選び「表示/非表示」→ 段の終わりで部品が消える →「外観」→ 段の帯の外観の一覧で色を選ぶ → 動画に書き出す。試験 `kmb-ui` の `the_storyboard_records_views_and_hides_and_recolors_parts`、e2e `apps/kmb-app/tests/ui/ストーリーボードのビュー・表示・外観.jcs`。
