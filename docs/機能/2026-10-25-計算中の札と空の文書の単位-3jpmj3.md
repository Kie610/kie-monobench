# すぐ終わる計算で札を出さない・空の文書にも新しい単位

- 日付: 2026-10-25
- 意図: 寸法を打ったりスライダを引いたりする人が、下の帯の「再計算中」が一瞬ずつ出たり消えたりして落ち着かない / 起動してすぐ設定で単位を inch に変えた人が、開いている空の文書が mm のままで作り直す
- 仕分け: C・JC に合わせて作る(JC は窓を覆わず下の帯に札を出すだけなので、札を遅らせる)。空の文書の単位は A・作る(起動の時の空の文書に入れる土台がある)

## 作った物

- 下の帯の「再計算中」の札は、続けて 0.3 秒(`BUSY_BADGE_DELAY`)を越えた時だけ出す。すぐ終わる計算では出さない。出す時刻に描き直しを頼むので、長い計算では遅れずに出る。
- 設定の「新規デザイン」で単位や設計の属性を変えると、まだ何もしていない無題の文書(手前のタブ)にも入れる。取り消しの履歴には入れず、変更にもしない。裏のタブの空の文書は今までどおり(切り替えた後に新しい文書を作れば入る)。

## 試し方

- `kmb-ui` の `a_quick_recompute_shows_no_busy_badge`・`changing_the_new_document_unit_also_sets_it_on_the_untouched_untitled_document`(設定の窓で「ミリメートル(mm)」→「インチ(in)」を押す)。

## 後回し

- スケッチを終えても視点を戻さない件は、スケッチの編集器が自分の視点を持つので、編集器(kmb-ui-sketch)から 3D のビューへ視点を渡す口が要り、平らな図で終えた時に何を渡すかを先に決める必要がある。スケッチの列の作業と重なるため、この束では作っていない。
