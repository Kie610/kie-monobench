# 表示の言語の枠

- 日付: 2026-10-26
- 決定: 表示の言語

## 作った物

- crate `kmb-i18n`(層 core): 言語(日本語・英語・簡体中国語・繁体中国語・韓国語)と「自動」(OS の言語。日本語・中国語・韓国語でなければ英語)、文言の訳の一式(`Catalog`)。訳は `crates/kmb-i18n/locales/<言語>/<分野>.ftl`(Fluent の形)に書き、組み込む。足りない訳は 選んだ言語 → 英語 → 日本語 → ID の順に探す。
- 分野 `common`(OK・キャンセル・適用・閉じる)と `settings`(設定の窓の題・検索・上のタブ・手で書いた頁の名前・表示の言語の欄)を日本語と英語で書いた。簡体中国語・繁体中国語・韓国語は頭の注記だけのファイル(訳を足す置き場)。
- 設定の「画面」の頁の先頭に「表示の言語」を足した。値は `layout.json` の `appearance.language`(`auto` か言語の符号。知らない値は自動)。選ぶとすぐ設定の窓の字が替わる。
- 画面のアプリは起動の時に OS の言語を読む(`Workspace::use_os_language`)。試験の画面は日本語のまま。
- 訳す人向けの手引きは `crates/kmb-i18n/locales/README.md`。

## 決めたこと

- 文言は置き場ごとに別の ID にする。同じ字でもボタンと見出しで訳し分けることがあるため。共通の ID(`common-`)は働きまで同じボタンだけ。用語の揺れは ID の共有ではなく用語集でそろえる。
- ID は小文字とハイフンで、頭はファイルの分野。意味が変わったら ID を替え、字の誤りの直しだけなら替えない(替えると全言語で未訳に戻る)。
- 文を切って継ぎ合わせない。数や名前は差し込み口で渡し、数で形が変わる語は Fluent の選び分けで書く。
- 日本語と英語は同じ ID の組を持つ。ほかの言語は英語に無い ID を持たない(`kmb-i18n` の試験)。

## 試し方

- 設定 → 一般 → 画面 → 表示の言語で English を選ぶと、設定の窓の題・タブ・頁の名前が英語になる。韓国語を選ぶと、訳の無い所は英語で出る。
