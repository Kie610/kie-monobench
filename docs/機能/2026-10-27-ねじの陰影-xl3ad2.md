# ねじの陰影

- 日付: 2026-10-27
- 意図: ねじを付けた穴やボスが 3D の陰影表示でただの穴・円柱と同じに見え、どこにねじがあるかを形を見ただけでは確かめられない。
- 仕分け: B 土台から作る(ねじは円筒の面に付ける属性で形のねじ山を作らないので、見せる道が無かった。属性から見せ方の印を出す道を足した)

## 作った物

ねじ(`solid.thread@1`)と、穴の機能でねじ穴(下穴)を選んだ物は、3D のビューで円筒の面にねじ山の陰影が付く。面を軸に直角な輪の帯に半ピッチごとに切り、帯ごとに法線を軸の向きへ交互に傾けるので、形は変えずに明暗の縞がねじ山の斜面のように見える。ピッチは呼びの物で、ねじの長さを決めた時は開いた端(穴の口・ボスの先)からその長さだけ。おねじもめねじも同じ見せ方で、明るい画面でも暗い画面でも同じ。

- 機能は出力 `thread_marks`(`kmb_interchange::ThreadMarks`、`cad.thread_marks@1`)に円筒の軸・半径・ピッチ・範囲を入れる(kmb-cad-hole)。
- 画面(kmb-ui)は機能の名前を見ず、出力の名前と型で印を集め、ボディの最後の機能ごとに 3D のビュー(kmb-ui-view3d の `Scene::set_thread_marks`)へ渡す。ビューは網の三角形のうち印の円筒に乗る物だけを帯に切る(`thread_bands`)。切る前の網を持っておき、印が替わったら切り直す。
- 帯の網は位置を変えないので、測る・拾う・面の名前は前と同じ。GPU の描き方も CPU の描き方も網の法線で陰を付けるので、描き方を足さずに効く。

## 決めたこと

- 見せ方の印は計算の出力で、文書には残さない。ビューは面の名前でなく円筒の幾何で面を探すので、truck のように円筒が 2 面に分かれても両方に付く。
- 帯は輪(軸に直角)で、らせんの線は作らない・描かない。
- 法線を傾ける角は `THREAD_TILT`(0.55 rad)。

## 試し方

- e2e の台本 `apps/kmb-app/tests/ui/ねじの陰影.jcs`(基準部品のボスにおねじ、中央の穴にめねじを付け、前と後を撮る)。明るい画面で撮るには `JC_SCREENS_BRIGHTNESS=light`。
