# MCP の道具の表を 1 つに

- 日付: 2026-10-26

## 作った物

- MCP の道具を、道具 1 つにつき 1 行の表(`apps/kmb-mcp/src/server.rs` の `tools!`)で書く。表の 1 行から、MCP の道具(説明・引数の形・中身)と、まとめて実行(`batch`)の 1 手の読み方・入れられない理由を一緒に作る。前は道具の定義と batch の読み分けが別の 2 か所にあり、道具を足すたびに両方を直していた。
- 道具の名前・説明・引数・答えは前と同じ。batch に入れられない道具とその理由、値の式を直すだけの手で作り直しを後へ回すこと、絵を返す道具の絵を batch の結果に入れないことも前と同じ。

## 決めたこと

- 表の 1 行は `"説明" fn 名前(s, a: 引数の型) 種類 => 中身;`。種類は `edit`・`value`(値の式だけを直す手)・`picture`(絵を返す)・`outside "理由"`(batch に入れない)・`server "理由"`(文書の錠の外で動く。今は `app` だけ)。
- batch の 1 手は、道具を 1 つずつ呼ぶ時と同じ中身を閉じ込めた物にし、道具ごとの列挙の型をやめた。

## 試し方

`cargo test -p kmb-mcp --lib`(batch の試験と、道具の一覧の試験)。
