# スイープとロフト(ガイドレール・同じ平面の断面を断る・ねじれた断面)

- 日付: 2026-10-22

## 作った物

ロフトのガイドレール、同じ平面に続けて並ぶ断面を理由つきで断ること、90 度より大きくねじれる断面、星形でない断面と円のロフトも含める。断面の穴と曲面は含めない。

- 新しい crate jc-cad-sweep(層 cad)。機能 `solid.sweep@1`(プロファイル・経路・演算)と `solid.loft@1`(断面の並び・ガイドレール 2 本まで・演算)。経路とレールはスケッチの出力 `paths` の線を番号で指し、端のつながる線を分かれ道までたどる(`chain`)。円は閉じた経路。
- スケッチの出力 `paths` の型をコアの `jc_core::Lines`(`geom.lines@1`、番号つきの線)にした。ソリッドの機能はスケッチの crate に依存できない(層の点検)ので、点の `Points` と同じくコアの型で読む。形は前の `sketch.paths@1` と同じで、出力は保存しないので古い文書に関わらない。
- 作る手順は Recipe に `Sweep`・`Loft` を足した(jc-cad)。パターン・ミラー・移動は経路とレールの平面も一緒に動かす。ミラーの輪郭の写しは `mirror_edge`・`mirror_profile` にまとめた。
- カーネルの口: コアの `Kernel::sweep`・`Kernel::loft` と、平面の上の線の並び `PlanarPath`(jc-core)。既定は「このカーネルでは使えません」。truck は既定のまま(新しい立体の操作は SMLib だけ)。
- SMLib(crates/jc-kernel-smlib/src/skin.rs): 面は SMLib の皮張り(SmApiCreateSkinPrimitive)を使わず、Rust で有理 B スプラインの網を組み、shim の `jc_patch_solid` が面と両端の蓋を作って縫う。皮張りの API は断面ごとの曲線の対応とねじれを外から決められず、ガイドレールも無いため。
  - 断面: 線は 2 次の 3 点、円弧は 90 度ごとの有理 2 次。断面の向きを法線でそろえ、始まりを角(角が無ければ周を 720 に割った点)の中から隣の断面に一番近い所に取る。90 度を超えるねじれもそのままつなぐ(k16)。
  - 対応: 全部の断面の角を周の長さの割合で合わせて区切り、区切りごとに 1 枚の面にする。L 字と円のように角の数が違っても、星形でなくてもつながる。
  - 断面の間: 断面を通る補間(次数は 3 と断面の数 −1 の小さい方)。
  - ガイドレール: レールが断面に触れる所を始まりに取り、1 本なら反対側を動かさずに伸ばし、2 本なら相似で合わせた中間の断面を 1 区間に 7 枚差してから張る。
  - スイープ: 線の区間は平行に動かし、円弧の区間は円弧の軸のまわりの回転面(厳密)。線と線の角は二等分の平面で留める(マイター)。円弧のからむ接しない角と、輪郭より小さい曲がりは断る。
  - 面の名前: `{tag}:side:{輪郭の線}:{経路の線}`・`:start`・`:end`(スイープ)、`{tag}:side:{最初の断面の線}`(ロフト、重なれば #k)。
- 画面: 設計の作成に「スイープ」「ロフト」(アイコン sweep・loft)。スイープは動かす領域 → 経路の線、ロフトは最初の断面 → 続きの断面(Ctrl で順に足し Enter)→ ガイドレール(省けば Enter)。編集パネルは記述子の欄(断面とガイドレールは行の並び)。
- CLI・MCP: 操作 `cad.sweep`(profile・path・operation)と `cad.loft`(first・sections・rails・operation)。
- 見本 `jc_samples::sweep_loft_document`(e2e の `#! sample sweep`): L 字の経路と円の断面、下の四角と上の円。

## 決めたこと

- 同じ平面に続けて並ぶ断面は、「断面 i と断面 i+1 が同じ平面にあります」で断る。離れた断面で同じ平面に戻るのは、つなぐ間に別の断面があれば許す。
- 経路の端が輪郭の平面から離れていたら断る(黙って経路を動かさない)。遠い方の端から始まる経路は向きを反す。閉じた経路は輪郭の平面の上の頂点から始める。
- 輪郭より小さい曲がりは自分と交わるので断る(切って足し直すことはしない。下の特許)。
- 断面の穴は「穴の無い閉じた輪郭 1 つずつ」で断る。
- レールは 2 本まで。3 本以上と、レールが断面に触れていない時は断る。

## 足した言葉

用語表に「スイープ」「ロフト」「経路」「断面・ガイドレール」を足した。
