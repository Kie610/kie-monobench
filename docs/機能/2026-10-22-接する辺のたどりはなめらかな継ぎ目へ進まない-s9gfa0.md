# 接する辺のたどりはなめらかな継ぎ目へ進まない

- 日付: 2026-10-22

## 作った物

2026-10-21 Kie が採用。フィレット・面取りの「つながるエッジも入れる」と辺のダブルクリックで、両側の面が接している角の無い継ぎ目(平面とそれに接する円筒の境目など)へは進まない。

- 再現: 上の角を丸めた棒(上の平面と端の円筒がなめらかにつながる)に、壁が継ぎ目の上に乗る溝を切り、溝の上の縁からたどると、縁の上下へまっすぐ続く継ぎ目 2 本まで選んでいた。継ぎ目には丸める角が無いので、丸めは失敗するか形が崩れる。
- 原因: たどり(当時は jc-core、今は jc-cad の `chain.rs`)は辺の端の点と向きだけを見ていて、辺の両側の面が接しているかを知る手段が無かった(カーネルの辺の情報 `EdgeInfo` に無い)。
- 候補: (1) カーネルが辺の真ん中で両側の面の法線を比べて印を返す、(2) 表示の網の法線から画面と機能の側でそれぞれ推す、(3) 後回し。(2) は網の粗さで外れ、同じ判断を 2 か所に置くことになる。カーネルは出っ張りかを決めるのに既に両側の法線を出している(SMLib の C の層 `jc_all_edges`)ので、(1) を選んだ。
- 直し: `EdgeInfo` に `smooth`(両側の外向きの法線が 1° 以内でそろう)を足し、SMLib が曲がった辺の一覧(`curve_edges`)で付ける。たどりは `smooth` の辺へ進まない。truck は付けない(偽のまま)。今は `smooth` の代わりに継ぎ目の型 `Seam { Unknown, Corner, Smooth }` で持ち、たどりは `Corner` の辺へだけ進み、分からない辺では止まる。truck も両側の平面の法線から求める(構造のレビュー 段 3)。
- 外すと元に選んだ辺へ戻る点は、JC では元から済み(データは選んだ辺だけを持ち、計算の時に広げる)。

## 試し方

- 上の手順の棒と溝を作り、フィレットで溝の上の縁を「つながるエッジも入れる」で選ぶと、縁の 1 本だけが選ばれる。
