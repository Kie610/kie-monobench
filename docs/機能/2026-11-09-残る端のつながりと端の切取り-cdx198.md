# 残る端のつながりと端の切取り

- 日付: 2026-11-09
- 意図: 線を消したりトリムしたりしても残った線のつながりを保ち、端ちょうどで切っても長さ 0 の線を残さない。
- 仕分け: C・JC に合わせて作る(JC は端のつながりを一致の拘束で持つので、消す処理で残る点どうしをつなぎ直す形にする)。

## 作った物

線を消す時は、消える点を含む一致の群を読み、残る点どうしの一致を近い順に1対1で付け直す。線を全部トリムして消す時も同じ処理を通る。既存の残る拘束と点の位置は変更しない。すでにつながっている点対へ一致を重ねず、新しく組んだ端は別の組に再使用しない。

残る端が2つなら、消えるかなめを介していた2本の端がつながり、引いた時も一緒に動く。3つ以上が互いに独立して残る場合は、1対1の規則により余りや複数の点対になる。全体を1つにつなぐ規則ではない。余った点・位置・既存の関係を捨てたり、代表点の星形や鎖へ組み直したりしない。

線・円弧・楕円弧・スプライン・円錐曲線の端と許容内の交点でトリムする試験、線・円弧の端で延長する試験を追加した。既存の端を除く判定をそのまま使い、幾何の許容値は変更していない。

## 試し方

3本の線の端を真ん中の線の点を介した一致で結び、その線を削除または全部トリムする。残った端を引くと相手も一緒に動く。端ちょうどの交点で切る時は極小の片を残さず、残る曲線は元の曲線上にある。
