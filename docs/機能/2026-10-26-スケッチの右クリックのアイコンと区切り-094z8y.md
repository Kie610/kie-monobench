# スケッチの右クリックのアイコンと区切り(2 本目)

- 日付: 2026-10-26
- 意図: スケッチの右クリックのメニューでも、どの行が何をするかを字を読み切らずに見分けられ、キーも覚えられるようにする。項目が多い選んだ時のメニューを、種類ごとの区切りで分ける
- 仕分け: C・JC に合わせて作る(1 本目の設計の右クリックと同じ行 `menu_row` を使う)

## 作った物

- 2D スケッチの図の右クリック(`kmb-ui-sketch` の `menu.rs`)と 3D スケッチの図の右クリック(`space3d/menu.rs`)の行を `kmb_ui::theme::menu_row` にした。左に道具と同じアイコン、右にキー。キーは名前の後ろの括弧に書かない(「元に戻す(Ctrl+Z)」は「元に戻す」になった)。元に戻す・やり直し・スケッチ寸法・補助線・オフセット・パラメータのキーは設定で付け替えたキーに追う。
- 区切り: 道具の中は「決める・捨てる」「寸法の種類」「オフセットの向き」「移動・削除」。何も選んでいない時は「繰り返し」「選んだ寸法・拘束」「元に戻す・やり直し・貼り付け」「表示・パラメータ」「書き出し・押し出し」「最近の道具」。選んだ時は「寸法・線の種類」「拘束」「オフセット・移動」「切り取り・コピー・貼り付け・削除」「選択を外す」。
- 最近の道具・拘束の行は、リボンと同じ絵を出す(`tool_icon`・`constraint_icon`)。
- スケッチの図に「スケッチの図」の名前を付け、画面の要素の操作で右クリックできるようにした。

## 確かめ方

- `kmb-ui-sketch` の `menu_tests`・`clipboard_tests`・`space3d::tests`、台本 `apps/kmb-app/tests/ui/スケッチの右クリックのアイコンと区切り.jcs`。
