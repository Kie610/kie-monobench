# G-code の材料・設定の頁・知らせの写し・字体の探し方・辺のたどりの速さ・テーパーの予告

- 日付: 2026-10-25

## 作った物

- G-code の頭の「材料」(U13): 削るボディに付けた材料(部品表と同じ `cad.materials`)があればそれを書き、付けていない時だけ設計の属性の材料を書く。前は設計の属性の文字だけを書いていたので、部品表と違う材料が出ることがあった。セットアップからボディの元の機能をたどる(`jc_core::body_root`)。
- 設定の頁(U39): モジュールの設定(`jc_core::Settings`)が置く作業空間を `group` で宣言し(操作の `group` と同じ語)、設定の窓は `cam` を加工の頁、ほかを設計の頁に出す。前は設定の id の頭の文字で決めていたので、id の付け方しだいで加工の設定が設計の頁に紛れ込めた。
- 知らせの一覧(u5): 行ごとの「写す」と「全部を写す」(古い順に UTC の時刻つき)。失敗・注意の色は、知らせを出す所が `WinState::fail`・`warn` で決める(文の言い回しを見ない)。誤りの枝(`Err`)と、誤りを伝える文の所を `fail` にした。
- 日本語の字体(u28): 決まった道に無ければ、系と利用者の字体のフォルダを 3 段まで探し、最初の書体が仮名と漢字を持つ字体を使う。探すのは起動の後の裏のスレッドで、最初の画面は待たせない。
- 接してつながる辺のたどり(u23): 端の点を升に入れた表で近い辺だけを見る。4000 本の輪とつながらない辺 4000 本で、前は 3.1 秒(デバッグ版)、後は数 ms。
- 押し出しのテーパー(M4): 直している間の道具の形と線を、できる形と同じく傾いた壁で描く。外周は輪郭の平面から離れるほど内へ寄り、穴は広がる(`jc_cad::prism::PrismCap::solid_tapered`・`rings_at`)。前は傾きを無視したまっすぐな柱だった。

## 試し方

- `jc-samples` の `the_gcode_header_names_the_body_material_before_the_property`(直す前は「材料 A5052」のままで落ちる)、`jc-ui` の `each_module_gets_a_page_on_its_workspace_tab`・`a_notice_keeps_the_tone_its_sender_chose`・`a_japanese_font_is_found_outside_the_fixed_paths`、`jc-cad` の `a_ring_of_many_edges_is_followed_quickly`(直す前は 3.1 秒で落ちる)、`jc-cad` の `a_tapered_tube_leans_its_walls_into_the_material`(角すい台の差の体積)。
- 画面: 下の帯の知らせの印を押し、行の「写す」と「全部を写す」で写せること、失敗の知らせが赤い印になることを見る。
