# 名前の変更とずらしの式は計算の鍵どおりに動く

- 日付: 2026-10-22

## 作った物

2026-10-21 Kie が採用。「名前を変えると設計を全部計算し直す」「反転した平面の先の式をたどらず形が古いまま」という誤りが JC にあるかを試験で確かめた。どちらも JC の作りで防げていて、直す所は無かった。

- 機能やボディの名前を変えても(取り消しても)、計算する機能は 0 で、表示の網も作り直さない。計算の鍵は種類・データ・入力で名前を含まず、表示の鍵はボディの機能と形の番号だけなので。
- 平面からずらしたスケッチのずらしの式(`d`)が参照するパラメータを変えると、そのスケッチから作った形も動く。JC は式が参照するパラメータを入力として宣言していないと評価が誤りになる(`EvalCtx::expr`)ので、たどり漏れがあっても黙って古いままにはならない。JC には「反転した平面」が無く、ずらしはスケッチの欄の式なので、同じ形の誤りは起きない。

## 試し方

- 試験 `jc-ui` の `tests::renaming_a_feature_or_a_body_computes_nothing_and_keeps_the_meshes`、`jc-solid` の `tests::changing_the_parameter_of_a_sketch_offset_moves_what_is_made_from_it`。
