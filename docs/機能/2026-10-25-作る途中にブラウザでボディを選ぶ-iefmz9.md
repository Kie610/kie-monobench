# 作る途中にブラウザでボディを選ぶ

- 日付: 2026-10-25
- 元の項目: 10-24 h5(作る途中にブラウザで本体を選ぶ)
- 意図: 結合などで本体を選ぶ人が、ビューで重なって拾いにくい本体をブラウザで押すと、作っている途中の機能が決まって終わってしまう
- 仕分け: B・土台から作る(ブラウザの行は押すと選び直すだけで、選ぶ欄へ渡す道が無かった。3D のビューのクリックが欄へ入れる道を、ブラウザの行からも通す)

## 作った物

- 選ぶ欄が受けている間にブラウザのボディの行を押すと、作っている途中の機能を決めて終えず、その欄へボディが入る(3D のビューでボディを押した時と同じく、1 つだけ受ける欄は次の欄へ進み、いくつでも受ける欄は足す・外す。Ctrl で留まる)。
- ブラウザは最後までの形のボディを並べるので、行の最後の機能が直している機能そのもの(結合の対象など)のことがある。直している機能の手前のそのボディに読み替えて入れる。手前に無いボディは「より後にできるので使えません」と出す。
- ボディを受けない欄(面や辺を選ぶ欄)が受けている時は、何も決めずに「…を選ぶ欄です。3D のビューで選んでください」と出す。
- 欄が受けていなければ、前と同じく行を選ぶ。

## 試し方

- `kmb-ui` の `a_body_row_pressed_while_a_field_takes_bodies_goes_into_the_field`: ブーリアンを足した後、ブラウザの「ボディ1」を押すと対象に入り、作っている途中のまま道具の欄へ進む。直す前は押した時点で決まって終わり、この試験は落ちた。
