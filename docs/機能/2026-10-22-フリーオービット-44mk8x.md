# フリーオービット(上下の軸に縛らずに回す)

- 日付: 2026-10-22

## 作った物

視点を回す時に、Z を上に保つ「拘束オービット」(今までの回し方、既定)のほかに、上下の軸に縛らない「フリーオービット」を選べるようにした。

- 切り替え: 3D のビューの下の帯の「オービット」を右クリックすると、拘束オービット・フリーオービットを選べる。設定の「マウス」の「オービットのタイプ」でも選べる。画面の配置(layout.json の `free_orbit`)に残る。
- 回り方: 横に引くと画面の上下の軸のまわり、縦に引くと画面の左右の軸のまわりに回る。真上を越えて裏へ回れる(拘束オービットは真上で止まる)。回す量は拘束オービットと同じ。右ドラッグ・ホイール押しドラッグ(設定で回す時)・オービットの左ドラッグに効く。軸の玉を引いて回すのと 2D スケッチの 3D の視点は今までどおり拘束。
- 傾きの戻し方: フリーオービットで傾けた後、拘束オービットで回すか、決まった向きのボタン(上・前・等角など)を押すと、上を Z に戻す。傾けている間は決まった向きのボタンを光らせない。
- 作り(jc-ui-view3d `Camera::orbit_free`): 今の右・上・視線の向きを画面の軸のまわりに回し、ヨー・ピッチ・傾き(`roll`。前は 2D スケッチの 3D の視点だけが使った)に分け直す。名前を付けた視点はヨーとピッチだけを残す(傾きは残らない)。
- 「選んだ物に垂直に見る」を共通にする直しは要らない(JC の「正面」は 1 つの操作で、もう共通)。

## 足した言葉

用語表の「拘束オービット・フリーオービット」(設定の欄は「オービットのタイプ」)。

## 試し方

- オービットを右クリック → フリーオービット。右ドラッグで縦に大きく引くと、真上を越えて裏から逆さまに見える。上のボタンを押すと、上が Z に戻る。
- 試験 jc-ui-view3d の `free_orbit_turns_over_the_top_and_about_the_screen_axes`・`after_a_free_orbit_the_view_buttons_and_the_constrained_orbit_set_z_up_again`。画面の切り替えは e2e `apps/jc-app/tests/ui/フリーオービットと原点の平面.jcs`。
- オービットの右クリックの前後を撮って並べて確かめた(写真はリポジトリに置かない)。
