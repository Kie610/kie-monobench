# 動きが 2 つ以上のジョイントを引いて動かす

- 日付: 2026-10-22

## 作った物

3D のビューで部品を左ドラッグした時、円柱・ピンスロット・平面・ボールのジョイントは、押した点がカーソルの視線にいちばん近づくよう、動き全部の欄を同時に直す(前は角度だけ回った)。回転・スライダのジョイントは前と同じ 1 つの欄の引き方のまま。

- jc-core `animation`: ジョイントの今の様子 `Drive` に、動き全部 `dofs`(`Dof` = 欄の名前・回転か移動か・軸。点に掛ける順で、値が全部 0 の時の軸)を足した。`dofs_pose`・`dofs_unpose`(値の時の動きとその逆)と、`follow`(減衰付きの最小二乗で、前のコマの値から寄せる。列は長さで割ってから解くので回転と移動の単位の違いが効かない。視線と同じ向きの移動と、軸の上の点の回転は使わない。回転は 1 回に 0.5 ラジアンまで)。
- jc-core `extension`: `DragMotion::Follow` と、`Drag` の `dofs`(動き全部)・`still`(変えない欄)。
- jc-asm `joint`: 動きが 2 つ以上の種類は `Drive::dofs` を出し、`drag` は `Follow` を返す。平面は回転を `still` にする(X・Y だけでどこへでも届くので、回転も動かすと引くうちに少しずつ回る。試験 `a_planar_part_slides_without_turning_when_the_turn_is_held` でその失敗を確かめてから決めた)。`position::after_positions` は `dofs` の軸にも後の位置の動きを掛ける。
- jc-ui `joint_drag_ui`: `Follow` の引き方。欄ごとに下限・上限で止め、式で決めた欄は変えない(全部が式なら引かずに知らせる)、離すと戻る位置のある欄だけ戻す、札と「位置を残す/元に戻す」の帯に変えた欄を全部出す(「角度 -28.8 deg  距離 31.2 mm」)。1 回引くと 1 つの取り消し単位は前と同じ。
- コマンド欄に `drag <面の名前> <右へ> <下へ>` を足した(押してすぐ引き始め、8 コマに分けて引いて離す。止まったまま待つと長押しの重なりの一覧が出るため)。

## 決めたこと

- 平面のジョイントは引いても回さない(回すのは欄とスライダ)。円柱・ピンスロット・ボールは動き全部で付いてくる。
- 回転・スライダは前の引き方(画面の回し方 Around/Along)のまま。カーソルに付いてくる形は、軸を真横から見ると回転が ±90 度で頭打ちになるため。

## 試し方

- 単体: jc-core `animation` の `a_cylindrical_part_follows_the_cursor_by_turning_and_sliding`・`a_turn_seen_from_the_front_keeps_going_around`・`a_planar_part_slides_without_turning_when_the_turn_is_held`・`a_ball_part_turns_toward_the_cursor_and_stops_at_its_limits`。jc-ui `a_cylindrical_part_turns_and_slides_with_the_cursor`(上限・式の欄・戻る位置・取り消し単位)。
- e2e: `apps/jc-app/tests/ui/円柱のジョイントを引く.jcs`(蓋つきの箱の蝶番を円柱にし、蓋を右上へ引くと、帯に角度と距離が出る)。
- 人の手順: 蓋つきの箱の蝶番をダブルクリック → 種類を「円柱」→ OK → 蓋の上の面を左ドラッグで斜めに引く。蓋が蝶番の軸の向きに滑りながら回る。
