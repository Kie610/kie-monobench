# 密閉箱とバスレフ箱の周波数特性

- 日付: 2026-10-31

## 作った物

`kmb-acoustics` に、ドライバーの値と箱・ポートから音圧、電気インピーダンス、群遅延、コーンの振幅、ポートの風速を求める純粋な計算を置く。層は analysis で、`module()` は名乗りだけを組み立てへ登録する。文書の機能・画面・操作は足さない。外の依存を追加せず、回路に必要な複素数の四則だけを自前で持つ。

## 決めたこと

- 入力は SI。空気は 20 °C、密度 1.204 kg/m³、音速 343.2 m/s。電圧は実効値、振幅と風速の出力はピーク。距離と半空間・全空間を選べるが、伝播による位相を加えず、回路自体の群遅延を出す。
- Cms は Vas/(ρc²Sd²)、Mms は 1/((2πfs)²Cms)、Rms は 2πfsMms/Qms、Bl は √(2πfsMmsRe/Qes)。Qts と Qms か Qes の組からもう一方を求められる。重ねた入力の差は Qts が 2%、Bl・Mms が 5% まで。検査後は式から求めた一組を使い、回路の整合を保つ。欠け・矛盾・有限でない値は入力の誤りで両方の値を知らせる。
- 密閉箱は吸音材の比で容積を増やす。バスレフは容積のコンプライアンスと吸音の直列抵抗、漏れの並列抵抗、ポートの質量と直列抵抗を解く。漏れも放射する体積速度に含める。端の補正は片側バッフル・片側開放が 1.46r、両端フランジが 1.70r、両端開放が 1.22r。
- ポートの長さは c²Sp/((2πfb)²Vb') から端の補正を引く。0 以下なら管を作らず理由を返す。管の共振は c/(2Leff)。
- 周波数は既定 10〜2000 Hz、1/48 オクターブ。表示用の範囲は 5〜20000 Hz、刻みは 1 オクターブあたり 1〜1536 点に制限して過大な確保を避ける。1 点を解く口は正の周波数なら 5 Hz 未満も扱う。
- 群遅延は音圧の位相を連続につなぎ、不等間隔の3点の中央差分で求める。端は片側差分。F3 は 10max(fs,fc,fb) の Le=0 の音圧を基準とし、その周波数から解析範囲の下限まで下へたどって最初の3dB低下を対数の周波数で補間する。
- 最大値と超過範囲は指定した解析範囲の中を調べる。Xmax、風速10m/sと17m/sの境は対数の周波数で補間し、17m/sを超える範囲は注意にも出す。許容入力 Pe は数として保持し、自動で電圧を制限しない。
- 結果は周波数ごとの配列と要約、注意を JSON で往復できる。集中定数の目安で、分割振動・箱の面の振動・部屋の反射は含まない。

## 試し方

fc・Qtc・ポートの長さと共振・1Wの通過域の感度を閉じた式と照らす。低周波の傾き、共振前後のインピーダンスの山とコーンの谷、ポートの風速を別々に確かめる。48点と96点の刻みで F3 と群遅延が収束し、同じ入力から同じ結果が出ることを確かめる。
