# 面を張る

- 日付: 2026-10-27
- 意図: 外装のような自由な曲面を作りたい人が、線で囲んだ所に面を張れない。
- 仕分け: B 土台から作る。厚みの無い面だけのボディを区別して運ぶ。

## 作った物

`kmb-cad-surface` の `solid.surface_patch@1` は閉じた縁に面を張る。
設計の「作成」の一覧から「面を張る」を選ぶ。
「縁」の行でスケッチの領域、3D スケッチの線、ボディの辺を指定する。
作成時は縁をクリックし、Ctrl で選び足して Enter で決める。
後から「縁」の各行で種類と参照を編集できる。
3D スケッチの線分は `line` に線分の EntityID を保存し、並べ替えても同じ線を追う。
作成操作だけが受ける `wire` は出力順の番号で、保存する前に EntityID へ解決する。
ID の無い曲線は、線1本のスケッチを「全体」で選ぶ。
複数の曲線はスケッチを分け、個別の出力番号では追跡しない。
領域の名前を空にするとスケッチの輪郭全体を使う。

平らな縁には平面を張る。
立体的な 4 区間には境界の曲線を通る曲面を張る。
それ以外は縁ごとの曲面を縫い合わせる。
端の隙間、交差、重なり、長さの無い区間、32 区間を超える縁は理由つきで断る。
面と縁は生成元の名前を引き継ぎ、寸法の変更で作り直す。

面のボディは両面を描き、面積と外形を測れる。
体積と質量は出さず「面のボディ(体積なし)」と知らせる。
足し引き、シェル、辺の丸め、面のオフセットには使わない。
STEP は面のボディも書き、STL・3MF・OBJ は面のボディを除いて警告を出す。

## 決めたこと

ボディの出力と保存の形はソリッドと共通にする。
カーネルへの問い合わせでボディの種類を区別する。
面のボディの測定結果に、体積や質量の 0 を入れない。
