# 線を描く途中の取り消し後に描き直す

- 意図: 線をつなげて描いている途中で元に戻した後も、続きのクリックが受け付けられてほしい。
- 仕分け: A・直す(文書の取り消しと、描きかけの点の参照が食い違うことを画面の試験で再現した)。
- 日付: 2026-11-02

## 作った物

線をつなげて描く途中で「元に戻す」を押すと、文書から消えた点を描きかけが参照し続けていた。表示を更新する時に、描きかけの始点と輪郭を閉じる最初の点が、今のスケッチの点として残っているかを確かめる。点が消えていれば描きかけを捨て、線の道具を続ける。

## 決めたこと

- 取り消して消えた点を、別の点へ付け替えない。次のクリックを新しい始点、その次を終点として描き直す。
- 今のスケッチにある点を指している描きかけは保つ。線の道具での確認に絞る。
- 描きかけは画面の状態で持ち、文書の取り消しの単位や保存形式を変えない。

## 試し方

線分のボタンを押して3本つなげて描き、画面の「元に戻す」を押した後の点の参照と、新しい2回のクリックで線が描けることを確かめる。3本とも戻してから描き直すことと、Escで道具を終えてもスケッチの編集は続くことを、同じ画面の試験で確かめる。
