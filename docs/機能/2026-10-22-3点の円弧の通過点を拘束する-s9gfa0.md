# 3点の円弧の通過点を拘束する

- 日付: 2026-10-22

## 作った物

2026-10-21 Kie が採用。3 点の円弧の途中の点(3 回目のクリック)が既にある点に吸い付いていれば、その点を円弧の上に拘束する(3 点の円と同じ。後で動かしても通ったまま)。何も無い所をクリックした時は点を残さない。

- 原因: 画面(kmb-ui-sketch `more_tools.rs`)は途中の点に吸い付いた点でなく生の位置を渡し、kmb-sketch `draw.rs` の `add_arc_three_points` も途中の点に拘束を付けなかった。
- 直し: `add_arc_three_points` の途中の点を `Spot`(吸い付いた点と位置)で受け、点なら `PointOnCircle` を付ける。始点・終点と同じ点なら付けない。

## 試し方

- 点を置き、3 点の円弧の 3 回目のクリックをその点に吸い付けて描くと、拘束の一覧に「円周上」が付き、点を動かすと円弧が付いてくる。
- 試験 `kmb-sketch` の `a_three_point_arc_keeps_a_snapped_middle_point_on_it`。
