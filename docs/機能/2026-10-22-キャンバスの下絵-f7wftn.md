# キャンバス(写真や図面の下絵)

- 日付: 2026-10-22

## 作った物

挿入 ▾ の「キャンバス…」で PNG・JPEG・BMP の絵を選ぶと、平らな面を選んでいればその面に、ほかは XY 平面に置く(`cad.canvas@1`、新しい crate jc-sketch-canvas、層 cad。絵を読む・縮めるのは新しい crate jc-image(層 core)で、WASM のプラグインも使う jc-format に image の crate を入れないために分けた。画面は jc_session::canvas を通して画素に戻す)。欄は中心 X・Y・角度・幅(縦は絵の比)・不透明度(既定 50%)・水平方向に反転・垂直方向に反転。編集パネルと右クリックに「平面を選ぶ」(原点の平面か平らな面のクリック)と「キャリブレーション」(絵の上の 2 点をクリックし、その間の本当の長さを打つ。1 点目は動かさずに幅と中心を変える)。

- 絵は文書に base64 で入れる(STEP の読み込みと同じく、元のファイルを動かしても開ける)。長い辺が 4096 画素を超える絵は縮めて入れる(透明の無い絵は JPEG、ある絵は PNG)。
- 機能の出力はコアの型 `jc_core::Picture`(平面・4 隅・絵・key・不透明度)。形・加工・書き出しには使わない。
- 3D のビュー: `Overlay::pictures` に入れ、jc-ui-view3d の `picture_shape` が 4 隅の間を 12×12 に割った網に絵を貼る。スケッチの編集: 同じ平面に前から置いたキャンバスを、格子の上・スケッチの線の下に描く。
- 絵を読むのは key ごとに 1 回(jc-ui の picture_ui が egui の一時の覚えに置く。画面に貼るのは長い辺 2048 画素まで)。絵を画素に読み・縮めるのは jc-image(依存 image 0.25、png・jpeg・bmp だけ。WASM のプラグインも使う jc-format に image を入れないため別の crate)、文書に入れる文字は jc-format の `base64`。

## 決めたこと

- 3D のビューではボディの上に半透明で重ねる(奥行きを見ない。透過の表示を入れた時と同じ見え方)。ボディの後ろに隠す描き方は GPU の描画に絵を足す大きな作り直しになるので、今は作らない。
- 置いた時の幅は 100 mm。大きさはキャリブレーションか幅の欄で合わせる。
- 名前は広く使われる呼び方の「キャンバス」「キャリブレーション」にした。

## 足した言葉

用語表に「キャンバス」「キャリブレーション」と欄の名前。

## 試し方

挿入 ▾ → キャンバス… → 絵を選ぶ → 不透明度などを直して OK → タイムラインのキャンバスを選び、編集パネルの「キャリブレーション」→ 絵の上の 2 点をクリック → 本当の長さを打って Enter。スケッチを XY 平面に作ると、下に絵が見える。e2e apps/jc-app/tests/ui/キャンバスの下絵.jcs(絵は同じフォルダの 下絵の見本.png)。試験 crates/jc-ui/src/design/canvas_tests.rs、crates/jc-sketch-canvas の corners、jc-format の base64、jc-image、jc-session の canvas。
