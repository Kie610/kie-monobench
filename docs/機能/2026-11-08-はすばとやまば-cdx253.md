# はすばとやまばの歯すじ

- 日付: 2026-11-08

## 作った物

歯車の輪郭 `cad.gear@1` の欄「ねじれ角」と「ねじれの向き」。モジュールと圧力角は歯直角の値を受ける。軸に直角な断面のモジュールは歯直角のモジュールをねじれ角の余弦で割り、圧力角は歯直角の圧力角の正接を同じ余弦で割って逆正接を取る。ねじれ角が 0 の時は平歯車の形を保つ。

歯車のボディ `cad.gear_body@1` は、輪郭を軸に沿う直線へスイープする。ねじり角は歯の幅とねじれ角の正接の積をピッチ円の半径で割る。右は軸の正の向きへ進む時に正、左は負に回る。回す中心は歯車の軸の上に置く。

欄「やまば」は歯の幅を二分し、中央へ向かう歯すじを逆の手で合わせる。欄「中央の溝の幅」が 0 より大きければ、中央を歯底円の円柱でつなぐ。両端の歯の位相は元の輪郭に合わせる。

## 決めたこと

- やまばの中央で歯の位相を合わせ、中央の溝を除いた左右の幅を等しく取る。
- やまばは新規ボディ・結合・切り取りを受ける。交差はまだ作れない誤りにする。左右の部位を順次交差して誤った形を作らない。
- 内歯の中央の溝は、歯底円から輪の外径までの円環でつなぐ。
- 輪郭が円板の間は歯の輪として全体をねじる。腕とボスを分ける欄は土台と同じく注意を残し、歯の幅以外の厚さへは変えない。

## 試し方

歯車の輪郭で「ねじれ角」を 20 deg、「ねじれの向き」を右か左にする。ボディの編集で「やまば」を入れ、必要なら「中央の溝の幅」を指定する。歯の幅より大きい溝や、ねじれ角の無い輪郭に対するやまばは入力の誤りになる。
