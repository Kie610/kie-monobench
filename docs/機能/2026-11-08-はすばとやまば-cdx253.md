# はすばとやまばの歯すじ

- 日付: 2026-11-08

## 作った物

歯車の輪郭 `cad.gear@1` に「ねじれ角」と「ねじれの向き」を指定できる。モジュールと圧力角は歯直角の値を受ける。軸に直角な断面のモジュールは歯直角のモジュールをねじれ角の余弦で割り、圧力角は歯直角の圧力角の正接を同じ余弦で割って逆正接を取る。ねじれ角が 0 の時は平歯車の形を保つ。

歯車のボディ `cad.gear_body@1` は、輪郭を軸に沿う直線へスイープする。ねじり角は歯の幅とねじれ角の正接の積をピッチ円の半径で割る。右は軸の正の向きへ進む時に正、左は負に回る。回す中心は歯車の軸の上に置く。

欄「やまば」は歯の幅を二分し、中央へ向かう歯すじを逆の手で合わせる。欄「中央の溝の幅」が 0 より大きければ、外歯は歯底円の円柱でつなぐ。内歯は歯底円から輪の外径までの円環でつなぐ。両端の歯の位相は元の輪郭に合わせる。

## 決めたこと

- やまばの中央で歯の位相を合わせ、中央の溝を除いた左右の幅を等しく取る。
- やまばは新規ボディ・結合・切り取りを受ける。交差はまだ作れない誤りにする。左右の部位を順次交差して誤った形を作らない。
- 内歯の中央の溝は、歯底円から輪の外径までの円環でつなぐ。軸と同心の丸穴は保つ。軽くする穴やキー溝があるやまばは、中央の溝の幅を 0 mm にし、正の溝幅との組合せは明示的な未対応とする。
- はすばとやまばは穴・キー溝を含む円板全体をねじる。腕とボスは歯の幅と同じ厚さを指定する。異なる厚さを指定した組合せは、値を黙って無視せず未対応の誤りとして断る。ねじれ角が 0 の時は従来の腕とボスの厚さ・位置を保つ。

ねじれ角・ねじれの向きは外歯と内歯にだけ出す。やまばと中央の溝幅は参照する輪郭の種類に追従し、ラック・鎖車・ベルト車・ロープ車では出さない。

## 試し方

外歯の「種類」は「平歯車」のまま、歯車の輪郭で「ねじれ角」を 20 deg、「ねじれの向き」を右か左にする。ボディの編集で「やまば」を入れ、必要なら「中央の溝の幅」を指定する。歯の幅以上の溝や、ねじれ角が 0 の輪郭に対するやまばは入力の誤りになる。ねじれ角が空なら 0 deg、中央の溝幅が空なら 0 mm を使う。種類を変えて欄が消え、外歯へ戻った後も、空の既定値で計算できる。以前の独自の入力値の復元は保証しない。

## 計算時間の確認

修理後 `1124d094` の候補で、30 歯・モジュール 2 mm・ねじれ角 20 deg・歯の幅 20 mm の右はすばと左はすばを、他の重い検査・画面検査・大きい入出力を止めて各 1 回測った。右は **0.634458 秒**、左は **0.596631 秒**で、双方が 2 秒以内だった。立体の体積・両端の歯位置を確かめる同じ実試験も 1 件通過した。時間の判定と試験本体の通過は分けて記録した。

実行ファイルは `e0511211` で組み立てたもので、最新 main を通常 merge した `1124d094` と全ツリーが一致することを確認して使用した。今回の資料と写真の追加は、計算コードを変えない。

以前の値は現候補の性能と混ぜない。`53571e69` の排他測定は右 0.637 秒・左 0.599 秒、領域別にねじっていた未採用の `088af45e` の排他測定は右 1.546178 秒・左 1.500216 秒で、いずれも過去のソースの参考記録とする。最初の `51acc0dd` で得た右 0.603 秒・左 0.586 秒は、他の処理との排他を確認していない参考観測とする。
