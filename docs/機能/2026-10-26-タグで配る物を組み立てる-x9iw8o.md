# タグで配る物を組み立てる

- 日付: 2026-10-26

## 作った物

`.github/workflows/release.yml`。`v<版>` のタグを押すと、GitHub の CI が Linux と Windows で画面・CLI・MCP の 3 つの exe を release で組み立て、許諾文の一覧とライセンスの文と一緒に成果物に置く。`cargo xtask release` は `--tag` でタグが版と合うかを先に確かめ、選んだ crate の exe を全部数える(docs/verify.md の 15 節)。

## 決めたこと

- CI は xtask を呼ぶだけ。タグと版の突き合わせとパスの数えは xtask が持つ。
- 検査は main の回に任せ、タグの回では流さない。GitHub のリリースは作らず、成果物に置くだけにする。
