# パターン・ミラーの写しを別のボディにする

- 日付: 2026-10-25

## 作った物

ルールに合わない物の直しの M32。種類が「ボディ」の矩形状パターン・円形状パターン・ミラーで、写しを元と足し合わせずに別々のボディにできる。

- 欄「写しを別のボディにする」(`separate`)。入れると元のボディは残り(`Feature::keeps`)、写し 1 がこの機能のボディになる。
- 右クリックの「写しを別のボディに分ける」(`cad.pattern_split_copies`)。まだボディになっていない写し 2 から先に、写しのボディの機能(`solid.pattern_copy@1`、`{"of": パターン, "index": 番号}`)を 1 つずつ足す。1 つの機能が 1 つのボディなので、写しの数だけ機能が要る。
- パターンは写しを `copy.N`、写しの数を `copies` に出す。

## 決めたこと

- 個数を式で変えた時の合わせ方: 機能を黙って足し引きしない(評価は純粋で、評価の中から機能を足せない)。増えた写しはまだボディにならず、パターンの注意(設定欄に出る)が「写し N はまだボディになっていません」と知らせ、もう一度「写しを別のボディに分ける」を押すと足す。減った時は、余った写しのボディの機能だけが止まり(下流だけが誤り)、注意が理由を言う。
- 分ける操作は機能を足すだけで、パターンを書き換えない(後から足す機能は前を書き換えない。写しのボディの機能を消せば分ける前に戻る)。なので印は欄で先に入れる。
- 写しのボディの機能を消すと、その写しは見えなくなり注意が出る。
- 1 つの機能が何個でもボディを出せる形(コアの変更)にすれば、数に合わせて自動で増減できる。今回はコアを変えない形にした。

## 試し方

- `cargo nextest run -p jc-solid pattern_copies_can_be_split_into_their_own_bodies`(分ける前は写し 2 が注意に出る → 分けて 3 つ → 4 にすると注意 → もう一度分けて 4 つ → 2 に減らすと余った 2 つの機能だけが止まる)。
- 画面: 箱を選んで矩形状パターン(種類はボディ、個数 3)を足し、欄「写しを別のボディにする」を入れて OK。タイムラインのパターンを右クリック →「写しを別のボディに分ける」。ブラウザのボディが 3 つになり、写しのボディの機能が 1 つ増える。
