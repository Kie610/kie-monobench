# スケッチの領域と札と中心線

- 日付: 2026-10-30
- 意図: スケッチで、触れた領域の選び方・領域の名前・貼り付けた中心線・札の重なりなど、小さな取りこぼしで手戻りしている。
- 仕分け: C 試験で確かめ、起きる所だけ直す。

## 作った物

`cad.sketch.regions` は、スケッチの閉じた領域の名前を表で返す読み取り専用の操作。
`feature` にスケッチの機能の番号を渡し、省くと選んでいるスケッチを読む。
画面のコマンド検索と、CLI・MCP の同じ操作の道から使える。
名前は計算済みの領域の鍵をそのまま返し、文書を変えない。

中心線をコピーして貼り付けると、中心線の印も付け直す。
普通の補助線は中心線にしない。中心線の印が無い古いコピーのデータも読む。
コピーに中心線の印が無かったことが、普通の線になる原因だった。

寸法の札を選び、矢印キーで画面上の位置を 5 px ずつ動かせる。
位置は既存の札と同じく形に対する相対位置で保存し、形の寸法は変えない。
値の欄へ入力している時は、矢印を文字カーソルへ渡す。
新しいドラッグの手順は足さない。

角度の札にも、既にある寸法の重なり回避を使う。
円弧の半径を既存の間隔でずらした候補を比べ、先に置いた札や拘束の印を避ける。
人が置いた札はその位置を優先する。新しい配置の仕組みは作らない。

## 試し方と調べたこと

| 項目 | 扱い |
|---|---|
| 点で接する領域 | 別の名前を保つ。クリックした一つの領域は Enter でも増えず、その領域だけを押し出せる試験を残す |
| 領域の名前の一覧 | 読み取り専用の操作を足す |
| 重なった線 | 外周や内側の分ける線を重ねても領域と名前が変わらない試験を残す。領域の作り方は変えない |
| 寸法の札の位置 | 選んだ札を矢印で動かせるようにする |
| 中心線の貼り付け | コピーに印を持ち、貼り付け先の番号へ付け直す |
| 角度の札の重なり | 既存の重なり回避を使う |
| 引いて離した直後 | 最初のフレームに移動先の点を描き、変更を保存し、次の描き直しも求める試験で起きないことを確かめる |
| 小さい窓と大きい字 | 幅 1280・字 250% で四つの寸法と拘束の印、軸と格子の札が重ならないことを試験で確かめる |
| 3D スケッチの小物 | 投影の線は派生出力で通常の要素と別。線への吸い付きとリンク切断は、要素への変換と拘束の連携が要るので、この変更には含めない |

3D の投影の拾いは名前つきの辺全体を画面の近さで調べており、手前の面だけには絞っていない。
この拾い方は変えない。
