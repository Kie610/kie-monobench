# 置いた部品を軽く描く

- 日付: 2026-10-27

## 作った物

同じ部品をいくつも置いた時の表示の網は、元の形の網を 1 回だけ作り、置いた行列で動かして作る(出現ごとに写した形を網にしない)。画面・CLI・MCP の測る網も同じ道を通る。鏡に映して置いた出現は三角形の向きを裏返して表を外へ保つ。面を拾う時は、ボディを囲む箱を視線が通らなければ、そのボディの箱の木を作らずに飛ばす(初めて拾う時に全部の木を作って画面が止まらない)。見た目は変えない。

## 測った値

基準部品(三角形 816 個)を置いた数ごと、組み立てた試験の版(debug)で。

| 置いた数 | 網を作る時間(前 → 後) | 初めて拾う時間(前 → 後、800 三角形の板) |
|---|---|---|
| 25 | 817 ms → 45 ms | 53 ms → 4 ms |
| 100 | 3,559 ms → 100 ms | 250 ms → 14 ms |
| 400 | 14,106 ms → 260 ms | 843 ms → 29 ms |

## 決めたこと

- GPU のインスタンス描画(同じ網を行列の並びで描く)は作らない。今の描き方は全部のボディを 1 本の束にして 1 回の命令で描いており、命令の数は増えない。重かったのは出現ごとに写した形を網にする所と、初めて拾う時の箱の木だった。
- 網を作るのは出現の元の形だけで、元のボディ自身も表示していれば同じ網を使う。ジョイントで出現を動かす間は、カーネルが形ごとに控えた元の網を使い回す。

## 残した物

- 出現の網を GPU の記憶で共有すること(400 個で頂点の束は約 27 MB。今は不足していない)。
- 拾う箱の木を出現で共有すること(視線を出現の行列の逆で元の座標へ戻す)。
