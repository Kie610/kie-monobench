# 整理と保存した絞り込み

- 日付: 2026-10-23

## 作った物

同じ・似ているデザインの整理、保存した絞り込み、フォルダの操作。

- ホームの左に「整理」の区画: 同じ・似ているデザイン(組の数)・分類のないデザイン・見つからないファイル(件数)。
- 同じ・似ているデザイン: 登録したプロジェクトの中から 3 種類の組を出す。中身が同じ(文書の JSON の指紋。JC が保存した物は最新の版の指紋と同じ)、名前が似ている(末尾の番号・v2・(1)・コピー・「 - コピー」・「のコピー」を除くと同じ。中身が全部同じ組は除く)、形が近い(体積・外形の箱の 3 辺・面の数がどれも 2% 以内で、名前も中身も違う)。どれも候補を並べるだけで、自動では移しも消しもしない。組は小さなカードを横に並べ、版の多い方(同じなら新しい方)に「残す候補」の印。組を押すと右に「この組の違い」(場所・版の数・更新・大きさ・体積・外形の箱・面の数・ジャンル・作品・タグ。違う値は色を変える)と「版の多い方を残して、ほかを削除…」(消す物の一覧の確かめの帯を出す。開いている物は外す)。
- 形の数は保存の時に版の履歴へ残す(`history::Version::shape`、縮小図と同じ網から数える。`history::Snapshot`)。前からある版には無いので、その物は「形が近い」に出ない(表は —)。
- 分類のないデザイン: ジャンル・作品・タグのどれも無いデザイン(全部のプロジェクトから)。カードを選ぶと右の概要で分類を直せる。
- 見つからないファイル: 最近使ったデザインのうちファイルが無い物。移した記録(`.jc/moved.json`、フォルダごと移した物は上のフォルダの記録)から今の場所が分かる物は、帯の「まとめて付け替える」か右クリックの「移した先に付け替える」で最近の一覧を直す(ファイルは動かさない。元に戻すで戻る)。
- 保存した絞り込み: 探す語・ジャンル・作品・タグ・変更日で絞っている時、「絞り込みを保存…」で名前を付けると、左の「保存した絞り込み」に並ぶ(データフォルダの `filters.json`)。押すと全部のプロジェクトと最近のデザインから当てはまる物を出す。右クリックで削除。
- 一覧表示: 中央の右上の「格子」「一覧」で、カードと表(名前・場所・版・更新日・大きさ・タグ)を切り替える。表の見出しを押すと並べ替え(もう一度で逆)。行の選び方・二度押し・右クリック・引いて移すはカードと同じ。
- フォルダそのものの操作: フォルダの右クリック(左の木の行・フォルダのカード)と右の概要の「…」に、ここに新規デザイン・名前を変える…・移す・削除…。移す・名前を変えると中のデザインと版の履歴も一緒に動き、元の親に移した記録を残す。開いているタブと最近の一覧のパスも付け替える。削除は PC のごみ箱へ(確かめの帯。中に開いているデザインがあれば止める)。どれも元に戻すで戻る。プロジェクトそのものは動かさない(一覧から外すだけ)。
- ここに新規デザイン: 右の概要(フォルダ)・フォルダの右クリック・データパネルのフォルダの中。そのフォルダに「新規デザイン.json」(あれば「新規デザイン 2」…)を新規デザインの既定の値で作って開く(版 1 も残す)。
- リンクの部品の元を探す時も、フォルダごと移した記録をたどる(kmb-asm の `link::follow_moves`)。
- 中身は kmb-session(`tidy`・`filters`・`organize` の `move_folder`・`rename_folder`・`trash_folder`・`new_design`・`follow_moves`)で、CLI・MCP からも同じ関数で使える。画面は kmb-ui-library(`tidy_ui.rs`)。

## 決めたこと

- 形の数は保存の時に版へ残し、整理の時に形を計算し直さない(kmb-session はカーネルを知らないため。古い版は形が近いに出ない)。
- 「ここに新規デザイン」はファイルをすぐ作る(保存の窓に始めのフォルダを渡す口が無いため。名前はホームで変える)。
- 中身が同じの組でも、名前の似ている組には出さない(同じ組が 2 回出るのを避ける)。形が近い組からは、中身が同じ物どうしと名前の似ている物どうしを除く。

## 作っていない物

- 組の「見比べる」(ファイルどうしの形を 3D で重ねる)。版の見比べの窓をファイルどうしに広げる必要がある。
- フォルダを引いて離して移す(今は右クリックの「移す」から)。
- 縮小図と分類の索引の控え(`.jc/` に再生成できる索引を置いて、開く時に全部を読まない。設計.md 5 節「速さ」)。
