# レンダリング ギャラリー

- 日付: 2026-10-22

## 作った物

前は「レンダリング…」で描いた静止画は選んだファイルに書くだけで、どの版から描いたかは残らなかった。今は描き終えると、書き出したファイルとは別に、文書の版の履歴の横へ「描いた時の版」と一緒に残る。

- 置き場所: 版の履歴のフォルダの `renders/`(`index.json`・`<番号>.png`・`<番号>-small.png`)。crates/jc-session/src/gallery.rs。文書のファイルと保存形式は変えない(版の履歴と同じ付録)。
- 絵は描き始めた時のいちばん新しい版に付く。保存の後に変えてから描いた絵は「版 N +変更」の印。保存していない文書の絵は残さない(知らせの欄にそう出す)。描いている間にタブを替えても、描き始めた文書に残す。
- 画面: レンダリングの作業空間の下の帯(設計のタイムラインの所)に縮小図を並べる。左上の一覧で版を絞る。絵を押すと大きく見る窓(書き出す・描いた版を開く・消す)、右クリックでも同じ操作。
- 版の履歴の窓: 絵のある版に「絵 N 枚」のボタン。押すとレンダリングの作業空間へ移り、その版の絵だけを出す。
- 縮小図は 256×192 に収まるように平均して縮め、透明な所は灰色に置く。PNG の読み手(jc-format の `read_rgba`)は JC が書いた RGB・RGBA の形だけを読む。

## 作らなかった物

- 保存の時に自動で描く(保存が重くなるので作らない)。
- クラウドでのレンダリング。JC は手元だけ。
- 回す動画とアニメーションの動画: JC は静止画だけ。動画は大きいので版の横に写しを置かない。
