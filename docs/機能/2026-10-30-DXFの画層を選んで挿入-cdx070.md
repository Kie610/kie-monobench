# DXF の画層を選んで挿入

- 日付: 2026-10-30
- 意図: 枠・寸法・注記が別の画層に入った図面を挿入すると、輪郭以外の線まで入ってしまい、押し出しや加工に使えない。
- 仕分け: A 作る。既存の DXF の読み込みに画層の一覧と選びを足す。

## 作った物

`cad.sketch.insert_dxf` に `layers` 引数を足す。
画層の名前の並びを渡すと、その画層の形だけをスケッチに入れる。
省くと全部を読み、選ばなかった画層から除いた形の数を操作の結果に出す。
読み込み後の線の掃除は、選んだ画層の形だけに行う。
ファイルに無い画層は、使える画層の名前を添えて断る。

読み取り専用の `cad.sketch.dxf_layers` は、画層の名前とスケッチにできる形の数を名前の順で返す。
ファイルは既存のファイルの指定、または `file` 引数で渡す。
引数はファイルの型で宣言し、許したフォルダの確認を通してから読む。
設計を選んでいなくても使え、文書を変えない。

文字とバイナリは、同じグループコードの読み手で画層を扱う。
ブロックの画層 0 と省略した画層は、配置の画層を受け継ぐ。
入れ子の配置と、同じブロックを別の画層へ置いた場合もそれぞれに数える。
明示した別の画層は保つ。配置から戻ると呼び出し元の画層へ戻す。
宣言だけの空の画層と、対応していない要素だけの画層も、形の数を 0 として一覧に出す。

## 決めたこと

既存の `from_dxf` と `from_dxf_bytes` の戻り値は変えない。
画層を選ぶ純関数の結果に、全画層の一覧と除いた数を分けて持つ。
`Imported` とコアの型・文書の版・依存は変えない。

画面のファイル選択直後のチェックの一覧は保留する。
ファイルの操作は、選んだ後すぐ共通の実行へ進み、複数の値を聞く編集パネルの入口がない。
既存の候補を選ぶ手順は単一の値を選ぶためのもので、画層のチェックの一覧とは違う。
このため画面の手順を広げず、読み込みと操作の共通の口までを作る。

## 試し方

画層が二つある DXF で、`cad.sketch.dxf_layers` を実行して一覧を読む。
`cad.sketch.insert_dxf` に `layers: ["輪郭"]` を渡すと、輪郭だけが入る。
両方を渡すと、指定しない場合と同じ形になる。
知らない名前、入れ子のブロック、空の画層、バイナリ、長さの単位も試験で確かめる。
