# 構成表(寸法違いの部品を 1 つの文書で持ち、行を当てて切り替える)

- 日付: 2026-10-22

## 作った物

ほかの CAD の構成・コンフィギュレーション・ファミリーテーブルに当たる。行ごとの形の作り置きは持たず、行を当てると設計を書き換えて全部を計算し直す。

- 核: crates/jc-core/src/configuration.rs。列はパラメータの式か機能の抑制で、どちらも番号で指す(名前を変えても付いて行く)。行は名前と列ごとの値。当てる行は `activate_ops` で、値の違うパラメータの式と抑制だけを書き換える変更と、当てた行の名前を 1 つの取り消し単位にする。指す物が消えた列は残し、当てる時に「列の指す物が消えています」で断る(黙って飛ばさない)。行 500・列 200 まで。
- 保存: 文書の `configurations`(空なら書かない。古い文書はそのまま読める)。版は上げていない。
- 画面: 「パラメータ」の欄の「全部」の表の下の「構成表」(閉じた見出し。行があれば開いて出る)。「列を追加 ▾」でパラメータか「(機能)の抑制」を列に足し(どの行にも今の値が入る)、「構成を追加」で今の値の行を足す。表の欄で式・抑制・行の名前を直す(当てるまで形は変えない)。左の丸で行を当てる。当てた後にパラメータを直すか当てた行の値を直すと「今の値が構成「…」と違います」と出し、「当て直す」と「「…」に書き込む」を選べる。列の見出しの右クリックで列を外す、行の名前の右クリックで行を消す・今の値を書き込む。
- CLI・MCP: 新しい crate jc-config の操作 `cad.config.add_column`(param か feature)・`remove_column`・`add_row`・`remove_row`・`set`(抑制の列は「抑制」「有効」)・`update_row`・`activate`。`jc status` と MCP の status に `configurations`(列の名前・行・当てた行・今の値と合うか)を出す。操作は画面のツールバーと機能の欄には出さない(画面は構成表の欄から直す)。
- 画面は表をコアの変更(`Op::SetConfigurations`)で直し、操作の名前を書かない(他の層の名前の点検)。

## 直した既存の不具合

最後の機能を抑制すると、ボディが 1 つも無くなっていた(基準部品の「穴の並び」を抑制すると「ボディがありません」)。構成表で抑制の列を当てて見つけた。

- 原因: `visible_bodies_before`(crates/jc-core/src/recompute.rs)は、抑制した機能が後ろへそのまま渡すボディの元を、渡した時点で「使い切った」ことにしていた。後ろに読む機能があればそれが新しいボディになるので困らないが、抑制した機能が最後だと、元のボディを見せる物が無くなる。
- 直し方: 抑制した機能が渡すボディの元を覚えておき(抑制した機能 → 元の機能。抑制が続けばたどる)、後ろの機能が抑制した機能のボディを読んだ時に、元を使い切ったことにする。読む物が無ければ元のボディが残る。
- 試験: crates/jc-solid/src/tests.rs の `suppressing_the_last_feature_leaves_the_body_before_it`。

## 決めたこと

- 行ごとの形を作り置きしない。行を替えるたびに計算し直す(作り置きは文書が大きくなり、行の数だけ計算が要る)。
- 列を外しても、パラメータや抑制は今のまま残す(設計を変えない)。
- 行を消しても、今の形は変えない。当てた行を消したら「当てた行」も消す。
- 当てた行の値を直しても、すぐ形に当てない(当てるのは丸か「当て直す」)。
- 抑制の列は、抑制した機能を読む後ろの機能を誤りにする(今の抑制と同じ)。基準部品で「四隅の穴」を抑制すると「穴の並び」が止まる。

## 足した言葉

用語表に「構成表」「構成を追加・列を追加 ▾」「今の値が構成「…」と違います・当て直す・「…」に書き込む」を足した。

## 試し方

パラメータ(Ctrl+P)→ 下の「構成表」→ 列を追加 ▾ → 構成を追加 → 表の値を直して丸で当てる。e2e apps/jc-app/tests/ui/構成表.jcs(基準部品で幅と穴の並びの抑制を列にし、小・大を当て替える)。試験 crates/jc-core/src/configuration.rs(3 本)、crates/jc-config/src/tests.rs(5 本)、crates/jc-ui/src/design/config_tests.rs(1 本)、crates/jc-solid/src/tests.rs(1 本)。
