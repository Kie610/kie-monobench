# 3点の円を吸い付いた曲線に拘束する

- 意図: 3 点の円で点や線に吸い付けて描いた時に、拘束が付いて円が勝手に動かないでほしい。
- 仕分け: A・作る(点への吸い付きで円周上の拘束が付く道はあり、線・曲線へ吸い付いた時の拘束が無かった)。

- 日付: 2026-11-03

## 作った物

3点の円で曲線に吸い付けた円周の位置に点を残し、円周上と、その曲線の上の拘束を同じ点に付ける。線分に吸い付けば線上の拘束になる。点に吸い付いた時は既存の点を使い、吸い付かなかった位置には拘束用の点を増やさない。

## 決めたこと

- 描いている間に控えた曲線の番号を使い、他の作図と同じ処理で拘束する。
- 曲線に置いた座標と、拘束する点の位置の照合を同じ関数にする。
- 解き方と保存形式は変えない。点に吸い付いた場合と吸い付かなかった場合は、5回再計算しても円が動く症状は起きなかった。線への吸い付きでは線上の拘束が抜けることを試験で再現してから直した。

## 試し方

3点の円の最初の2点を既存の点に、3点目を線の中ほどに吸い付けて描く。円周上の点に線上の拘束が付き、再計算しても描いた位置を保つ。既存の3点に吸い付けた場合と、何にも吸い付けなかった場合も試験で確かめる。
