# レーザーの加工を自分の crate に分け、線の読み方を 1 つにする

- 日付: 2026-10-22

## 作った物

構造のレビューの段 4 のうち E4(1 戦略 1 crate の崩れ)と E5(写し)の一部。

- レーザー(`cam.laser@1`)を kmb-strategy-engrave から新しい crate kmb-strategy-laser に移した(判断 2「crate は加工の種類のまとまり、レーザーは分ける」)。操作と種類の名前、欄、画面は同じ。
- 線のつなぎ `chains` と、スケッチの線を作業座標系の折れ線にする読み方が、彫刻の crate と kmb-cam-setup に 2 つずつあった。kmb-cam-setup の `chains`・`lines_of`・`read_lines` の 1 つにし、彫刻・スロット・レーザー・輪郭・投影が同じ物を使う。`Chain` に `reversed`(初めの線を逆にたどったか)を足した。
- 不具合の直し: 輪郭加工(スケッチの線)・3D の投影・加工の操作の輪郭の選びが使う `chains_of` は、セットアップの裏返しだけを当て、上から見て回した向き(`rot`)を当てていなかった。回したセットアップでは線が部品とずれた場所に経路を作っていた(彫刻の側は回していた)。`SetupInfo::place` を当てる形にそろえた。試験 `lines_follow_the_turn_of_the_setup` は直す前に落ち(線が X 方向のまま)、直した後に通る。

## 決めたこと

- 加工でスケッチの線を読む時は kmb-cam-setup の `read_lines`・`lines_of`・`chains_of` を使い、戦略の crate で写さない。

## 試し方

- `cargo test -p kmb-cam-setup lines_follow_the_turn_of_the_setup`
- 画面: セットアップの向きを 90 度回し、スケッチの線で輪郭加工を足すと、経路が線の上に出る(直す前は 90 度ずれた所)。
