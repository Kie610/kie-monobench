# 式の中の単位の無い数の読み方

- 日付: 2026-11-08
- 意図: in の文書で単位を付けずに式を打つと、数だけの時と式の時で違う単位として読まれ、意図と違う寸法になる。
- 仕分け: C・JC に合わせて作る(単位の補いが画面だけにあり、式の中の数は mm と読む。読み方を 1 つに決めて全部の入口で同じにする)

## 作った物

- 長さ・角度の欄とパラメータに打った式のうち、単位も名前も無い数だけの式は、式全体を欄の単位で読む。インチの文書の「10 + 5」は `(10 + 5) in` として入り、15 in になる。角度は `(30 + 15) deg` のように deg を付ける。数 1 つの「10」は今までどおり `10 in` で入る。
- mm でない文書で、単位の無い数を長さと足し引きする式は、入れずに理由を出す。インチの文書の「10 + 5 mm」や、長さのパラメータ `w` を使う「w + 1」は「長さと足し引きする数に単位を付けてください」と断る。mm の文書では mm が文書の単位なので断らない。
- 掛け算・割り算の係数は単位の無い数のまま読む。「2 * 5 mm」は 10 mm、「w * 2」は w の 2 倍になる。
- 規則は `kmb_session::params::read_typed`(機能の欄)と `typed_param_expr`(パラメータ)の 1 か所にあり、編集パネル・値の箱・パラメータの表・構成の表・名前付きの式(`t=10 + 5`)・表のまとめての変更・CLI と MCP とコマンド欄の set_value と set_param が同じ道を通る。CLI・MCP の set_param も、長さのパラメータの「10」を画面と同じく文書の単位で読む。
- 見分けは式の側の `Expr::is_plain_number`(数だけの式か)と `Expr::adds_number_to_length`(単位の無い数を長さと足し引きしているか)が受け持つ。式の計算の決まり(単位の無い数を長さと足すと mm と読む)は変えない。
- 編集パネルの欄で断った時は、欄の横に赤い「単位が要る」を出し、理由を吹き出しに出す。
- 式の候補の一覧は、大文字と小文字だけが違う同じ定数(`pi` と `PI`)を 1 つと数える。「pi」と打った Enter が候補を選ぶのでなく欄を決める。

## 決めたこと

- 単位の無い数の読み方は、打った時に入れる式を書き換えて決める。計算の側は文書の単位を読まない。保存済みの文書の式は開いても書き換えず、値も変えない。打ち直した時だけ新しい規則が働く。
- ファイルの中身や機能のデータを直に渡す道(add_feature のデータ、set_feature_data)は、打った式でなく保存の中身として扱い、書き換えない。

## 試し方

- インチの文書で押し出しの距離に「10 + 5」と打ち Enter を押すと、距離が `(10 + 5) in` になる。「10 + 5 mm」と打つと距離は前のまま、欄の横に「単位が要る」が出る。
- 試験: `kmb-session` の `headless::unitless_number_tests`、`kmb-ui` の `unitless_number_tests`、`kmb-expr` の `unitless_numbers_are_told_apart_by_how_they_are_used`。
