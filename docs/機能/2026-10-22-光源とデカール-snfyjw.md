# 光源とデカール

- 日付: 2026-10-22

## 作った物

前は、レンダリングの光は環境の光(スタジオ・屋外など)だけで、面に絵を貼ることもできなかった。今はレンダリングの作業空間の「設定」に「光源」と「デカール…」があり、点光源・スポットライトを置き、面に絵(PNG・JPEG・BMP)を貼れる。Kie の決定(2026-10-22): デカールの絵は文書の中へ写し、3D のビューとレンダリングの両方に出す。光源は点光源とスポットライトの 2 種類だけ。

- 置き方: どちらもタイムラインの機能(新しい crate `kmb-scene`、層 cad)。文書の新しい欄・Op・Role は足さず、機能の出力の型だけを kmb-core に置いた(crates/kmb-core/src/decor.rs の `Lamp`・`Decal`、出力の名前 `lamp`・`decal`)。描く側(レンダリング・3D のビュー)は機能の名前を知らず、出力の名前と型で探す。
- 光源(`render.light@1`、操作 `render.light_insert`、引数 `kind` = point / spot): 欄は種類・位置 X/Y/Z・照らす点 X/Y/Z(スポットだけ)・色・明るさ(lm)・広がりの角・縁のぼかし・大きさ(半径。影の縁のぼけ)。置くとボディの箱の手前左上に置き、中心へ向け、中心が約 1000 lx になる明るさにする。
  - 明るさの物差し: 光度 I = lm / 4π(cd)、照度 = I / d²(lx)。環境の光は 1000 lx で既定の明るさになる決まりなので、同じ物差しで足す(800 lm を 30 cm 離すと約 700 lx)。露出(EV)は効き、環境の明るさ(lx)は効かない(環境を暗くして電球だけで照らせる)。
  - 描き方: CPU の描画・キャンバス内レンダリング・光線追跡(光源の球から点を選び、影を見る)・GPU のシェーダー(8 個まで)。3D のビューで照らすのはレンダリングの作業空間だけ。印(十字と輪、スポットは向きと円すいの縁)は線の役割 `kmb_interchange::ink::line::SURROUND` で重ね描く。
- デカール(`render.decal@1`、操作 `render.decal_insert`、引数 `path`・`face`): 絵のファイルを base64 で機能の値に写す(4 MB・4096 画素まで)。欄は面・ファイル・ずらす X/Y(面の中心からのずれ)・回転・幅(縦は絵の縦横比)・不透明度・水平方向に反転・垂直方向に反転。貼った面が後の変更で無くなったら、別の面に付け替えずに誤りにする(「デカールを貼った面 … がボディにありません」)。
  - 貼り方: 面の平面へまっすぐ投影する(面の網の面積で重みを付けた中心と法線。絵の上は世界の Z を面へ写した向き、上か下を向いた面は世界の Y)。裏を向いた所には貼らない。絵は隣の 4 画素を混ぜ、透明はアルファの前掛けで混ぜる。
  - 印刷は金属でない扱いで、覆う割合だけ金属らしさを下げる(鋼の板に貼ると、前は鋼の映り込みの色で暗く濁った)。
  - GPU は 512×512 の 8 枚の絵の束に縮めて載せ、古い物から入れ替える。CPU は覚えた絵を 16 枚まで使い回す。
- 面ごとの外観がキャンバス内レンダリングに出ていなかった所も、同じ所を直す時に直した(3D のビューの場面に面の材質を渡す)。

## 作らなかった物

- 面に沿って曲げて貼る(円柱へ巻くなど): 平面への投影だけ。後で足すなら、描く側の `DecalFrame` に巻き方を足す。
- エリアライト・IES の配光・光源の色温度: Kie の決定で 2 種類だけ。
- 3D のビューで光源の印を引いて動かす: 欄で数を打つ(画面の決まり「押したまま動かす操作で形を作らない」)。
- デカールの絵を文書の外へ参照する形: 決定 a で文書へ写す。

## 試し方

e2e apps/kmb-app/tests/ui/光源とデカール.jcs(レンダリングの作業空間で面を選んでデカールを貼る、10° 回す、光源を置いてスポットライトにし 3000 lm、キャンバス内レンダリング)。試験 crates/kmb-render/src/lamp.rs(lm から照度、スポットの円すい)、crates/kmb-render/src/decal.rs(面の中心・向き・裏・反転・不透明度・回転)、crates/kmb-render/src/tests.rs の `a_spot_lamp_lights_the_plate_and_its_exposure_follows_the_camera` と `a_decal_shows_on_its_face_in_both_drawings`、crates/kmb-scene/src/lib.rs(欄の確かめ、無くなった面、置き方)、crates/kmb-core/src/decor.rs(絵を写さずに読む)。GPU のシェーダーは naga で確かめ、lavapipe の GPU の描き方(`JC_VIEW3D=gpu`)で撮って CPU と同じ見た目を見た。写真は開発の記録(リポジトリの外)。
