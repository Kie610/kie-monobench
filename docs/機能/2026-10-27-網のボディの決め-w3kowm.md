# 網のボディの決め(STL・3MF の読み込みと輪郭の辺)

- 日付: 2026-10-27

## 作った物

コードはまだ無い。STL・3MF のファイルを、三角形の網だけを持つボディ(網のボディ)として読み込み、表示・計測・加工・STL/3MF/OBJ の書き出しに使えるようにする作り方を決めた。作る本は 2 つに分ける: 読み込み(機能 `solid.import_mesh@1`、操作 `cad.import_mesh`、`kmb-cad-import-step` の crate、読み手は `kmb-format`)と、網の輪郭の辺(同じ機能の中で作る)。網をソリッドに直すことはしない。

## 決めたこと

- 網のボディは、ソリッド・面のボディと同じく機能の出力 `body` の `Value::Shape` で持ち、網はカーネルに預ける(`Kernel::import_mesh`)。種類はカーネルに問い、`BodyKind::Mesh` と答える。STEP を立体に組めずに網で読んだ形も網のボディとして答える。`Value` と保存の形、`FORMAT_VERSION` は変えない。
- 網の中身は、頂点と三角形の番号を決まった並びのバイト列にし、deflate して base64 の文字で機能のデータに入れる(元のファイルが無くても開ける)。頂点の値はファイルの単位のまま持ち、単位は欄で後から直せる。三角形は 5,000,000 までにする。
- 網が閉じている時だけ体積と重さを求める(閉じているかは頂点の番号でなく位置で見る)。開いた網の体積と重さは理由つきの誤りにし、0 にしない。足し引き・シェル・丸めなどは網のボディを理由つきで断る。STEP の書き出しには入れず警告を出し、STL・3MF・OBJ には入れる。
- 頂点は同じ値の物だけをまとめ、許容差ではまとめない(薄い所を潰さない)。面積 0 の三角形は除き、数を注記に出す。閉じた網の向きが裏返っていれば返し、注記に出す。
- 3MF は build の item ごとに 1 つのボディにし、物の名前をボディの名前にする。物が 2 つ以上なら、ファイルの名前の部品にまとめる。色・材質・独自の拡張は読まず、読まなかった種類を注記に出す。
- 表示の法線と輪郭の辺は、同じ「折れ目の角度」(既定 30°)で決める。隣り合う 2 つの三角形の法線の角度がそれ以上の辺、片側にしか三角形の無い縁、3 つ以上の三角形が使う辺を辺にする。辺は読み込みの機能が網に入れてカーネルへ渡し、ビューは今の稜線の描き方のまま使う。辺を出すかと角度は網ごとの欄に置き、窓全体の設定にしない。
- 部品に入れずに、足した機能のボディに名前だけ付ける文書の変更(`Edit::NameBodies`)をコアに足す。

## 足した言葉

STL・3MF を読み込む・網の読み込み・網のボディ・折れ目の角度(用語表.md の「設計」)。
