# 長方形の縦 2 辺の図形の対称

- 日付: 2026-10-26

## 作った物

- 寸法付きの長方形の縦 2 辺と離れた縦の軸に「対称(図形)」を付けても、過剰と断られない。長方形は軸の真ん中へ寄る。
- 原因: 図形の対称を点の対称 2 つ(中点が軸の上・結ぶ線が軸に直角)で付けていた。長方形の水平・垂直が「結ぶ線が軸に直角」と「左右の x がそろう」を既に決めているので、4 つの式のうち 3 つが重なり、1 つでも重なれば余分とする判定で断っていた。
- スケッチの拘束に `SymmetricPairs`(点 a1 と b1、a2 と b2 がそれぞれ軸 line について対称)を足し、図形の対称はこれ 1 つで付ける。保存の形は `{"type": "symmetric_pairs", "a1": …, "b1": …, "a2": …, "b2": …, "line": …}`。
- 余分の判定: 対称(点の対称と `SymmetricPairs`)は、式の一部がほかの拘束で決まっていても、新しく決める式が 1 つでもあれば受ける。全部が決まっている時(同じ対称を重ねた時)は今どおり余分、斜めの軸のように解けない時は今どおり矛盾。点の対称 1 つ(長方形の上の 2 隅だけ)も同じ判定で受ける。
- 印は点の対称と同じ印を軸に出す。

## 試し方

- `kmb-sketch` の `symmetric_tests`(幅 40 の長方形+縦の軸で受けて軸の真ん中へ寄る、点の対称を 2 つ別々に付けると 2 つ目は余分、上の 2 隅だけを受ける、同じ対称を重ねると余分、斜めの軸は矛盾、保存の形の往復と点を消すと拘束も消える)。
- `kmb-ui-sketch` の `a_rectangle_takes_symmetry_of_its_two_sides`(長方形を描き、縦の線を引き、「対称」で左の辺・右の辺・軸を押す。直す前は「ほかの拘束と重なるので付けません」で落ちた)。
