# コマンドの途中で迷わない(隠れたスケッチ・作業平面の傾き・値の欄の入力)

- 日付: 2026-10-26
- 意図: 形を直している途中に、使い終わって隠れたスケッチが見えずほかの輪郭を選べない、傾ける角度を打っても平面がどう傾くか分からない、3D で面を選ぶと打っていた欄から入力が外れて押し直しになる。
- 仕分け: A・作る(使ったスケッチを自動で隠す作り、打ちかけの値で形を付いて来させる作り、作り始めに欄へ入力を移す作りがあり、前提は同じ。作業平面の角度は今の作りで付いて来たので試験だけ)

## 作った物

- 押し出し・回転などスケッチを使う機能を直している間は、その機能より前の「使ったので自動で隠した」スケッチを 3D のビューに出す(`crates/kmb-ui/src/workspace/scene.rs` の `sketches_shown_while_editing`)。出るので、領域の選び直しの候補にも入る。直す機能が替わったら描くたびに隠す物を決め直す(`follow_editing_for_hidden`)。
- 値の欄に入力がある時に 3D のビューをクリックして欄から外れたら、すぐ後の描画で同じ欄へ入力を戻す(`crates/kmb-ui/src/design/feature_ui.rs` の `keep_focus_over_view_clicks`・`take_refocus`)。
- 試験: `crates/kmb-ui/src/screen_fixes_tests.rs` の 3 つ(使ったスケッチが直す間だけ見える、傾けた作業平面が打ちかけの角度で付いて来る、ビューをクリックしても欄に入力が戻る)。

## 決めたこと

- 行の目(保存する隠し)は変えない。直し終えると元どおり隠れる。
- 目で隠したスケッチ、まとまりの目で隠したスケッチ、直している機能より後のスケッチは出さない。
- 新しく作っている途中(作るパネルが開いている間)も、スケッチを使う機能なら同じに出す。
- 欄へ戻すのは 3D のビューのクリックで外れた時だけ。パネルのほかの部品を押して外れた時は戻さない。戻した欄は全体を選んだ状態にし、打った数で置き換わる。
