# 画面と AI の不具合が JC で起きないかを試験で確かめる

- 日付: 2026-10-25
- 元の項目: 他のソフトの更新 2026-10-16 E5、2026-10-20 u7、2026-10-24 u9・u10・m3
- 意図: 機能を消した後で丸めが赤くなって驚く(u7)。重い形を直すたびに画面が固まる(E5)。欄に数を打った後にスライダを引くと、欄を離れた時に打った数へ戻される(u9)。部品のタブを形の上で引くと下の形が選ばれそうに光る(u10)。壊れた AI の接続から大きすぎる送り物が来ると記憶を食い尽くす(m3)。
- 仕分け: C・試験だけ(症状を人の操作の順で試験にし、起きた物だけ直す)

## 作った物

- `crates/kmb-ui/src/design/find_tests.rs` u7: 基準部品のポケットの底と壁の辺に丸めを付け、ポケットを消そうとすると確かめに丸めが出る。ポケットだけ消すと丸めは計算できない(確かめの通り)。通った(直し無し)
- `crates/kmb-ui/src/tests.rs` E5: 穴を 16 個に増やした基準部品で、編集パネルからポケットの深さを直す。値はすぐ文書に入り、形は裏で計算し、直す呼び出しはその場で計算する時の 4 分の 1 より短い。通った(直し無し)
- `crates/kmb-ui/src/assembly/joint_range_tests.rs` u9: 角度の欄に -12 deg と打ち(Enter なし)、欄の下のスライダを引いて離し、欄の外を押す。直す前は欄の外を押した時に -12 deg へ戻された(打ちかけの字が欄に残ったまま、スライダを引いても欄から外れていなかった)。スライダを引き始めた時に打ちかけの字を捨て、欄から外すようにした(`crates/kmb-ui/src/design/feature_ui.rs` の `slider_ui`)
- `crates/kmb-ui/src/dock_tests.rs` u10: タイムラインのタブを 3D のビューの形の真ん中まで引く間、指した面の印が付かない(引かずに指すと付く)。通った(直し無し)
- `apps/kmb-mcp/src/line_cap.rs` m3: MCP の部品(rmcp)は改行まで際限なく溜めるので、改行の無い送り物を流すと読み続けた(試験で 60 秒を超えて止まらなかった)。1 行 16 MB(動いている画面への接続と同じ)を超えたら読み取りを誤りにして接続を終える読み手を、標準入力の前に挟んだ。試験は上限 4096 バイトで、上限を超えると接続が終わる

## 作らなかった物

- 10-20 u11(なめらかさを切った時の細い線と格子): GPU の描画を試験で回す土台が無い(クラウドには GPU も Vulkan のソフトの描き手も無い)。GPU が無い時に飛ばす試験にするのは承認が要るので書いていない

# ジョイントの原点に違う物を渡した時に何を渡すかを示す

- 元の項目: 他のソフトの更新 2026-10-24 m5
- 意図: AI や台本がジョイントを作る時、原点の欄に違う物(面など)を渡すと、分かりにくい誤りの文しか出ず直し方が分からない。
- 仕分け: D・意図だけ取り込む(元の「名前付きの原点」は作らない。誤りの文で何を渡すかを示す)

## 作った物

- `crates/kmb-asm/src/lib.rs` の `snap_pick_problem`: 合わせるジョイント(`asm.snap_joint`)の原点に面(`{"feature", "face"}`)を渡すと、その面の上の原点の候補の名前とそのまま渡せる値を並べて断る。ほかの読めない値なら、渡す形と取り方(面の中心・円の中心・頂点・辺の中点・2 面の間・2 辺の交点)を示す。直す前は「部品 1の原点の値が読めません: missing field `frame`」だけだった(試験で失敗を確かめた)
- 位置のままのジョイント(`asm.joint`)の軸の欄も、読めない時に渡す形を示す(同じ意図の兄弟)
- 試験 `crates/kmb-solid/src/asm_tests.rs` の `a_face_given_as_a_snap_origin_is_refused_with_the_origins_on_it`
