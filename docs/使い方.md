# 使い方(画面の操作の流れ)

画面で設計してから G-code を書き出すまでの流れを説明します。CAD か CAM のソフトを使ったことがある人に向けて書いています。

初めての時は「始める」から「加工」までを順に読んでください。「書き出し」と「困った時」は、必要な時に引いてください。ここで解決しない時は、[Issue](https://github.com/Kie610/kie-monobench/issues) で知らせてください。

ボタンとメニューの名前は、画面の表示どおりに書いています。言葉の一覧は [用語表.md](用語表.md)、操作と引数の全部の一覧は [入出力.md](入出力.md) にあります。コマンド(`kmb`)と AI(MCP)からの使い方は [README](../README.md) にあります。

## 始める: 引数なしで起動すると開始画面が出る

- 引数なしで起動すると開始画面が出ます。開始画面の「はじめての手順」で、見本を開いてから G-code を書き出すまでを順に試せます。
- `--sample` を付けて起動すると、見本の部品と加工が開きます。
- 保存は Ctrl+S です。直前の版は `.bak` に、保存のたびの版は文書の横の `.jc/history` に残ります。
- ホームのタブで文書と版の履歴を見られます。前の版と見比べて、その版に戻せます。

## 画面の配置: 上にツールバー、左にブラウザ、下にタイムライン、右に編集パネル

- 上には、作業空間(設計・加工・レンダリング・アニメーション・解析)ごとのタブ付きツールバーがあります。
- 左にブラウザ、下にタイムライン、右に編集パネルがあります。各部品はタブを引いて並べ替え、重ね、外の窓に出せます。
- 加工の作業空間ではタイムラインを隠し、セットアップの木で加工を管理します。中身は設計と同じ履歴です。
- 3D のビューでは、右ドラッグで回転、中ドラッグで移動、ホイールで拡大と縮小、左ドラッグで範囲の選択をします。中ドラッグは設定で回転に替えられ、Shift を押すと回転と移動が入れ替わります。
- よく使うキーは次のとおりです。

| 操作 | キー |
|---|---|
| 取り消し | Ctrl+Z |
| やり直し | Ctrl+Y |
| 保存 | Ctrl+S |
| コマンド検索 | Ctrl+K。名前のほか、「おしだし」のような読みでも探せます |
| 作っている途中の操作を 1 段戻す | Esc。内側の操作から順に戻します |

- タイムラインの機能と 3D のビューの面を右クリックすると、その場で使える操作が出ます。抑制、ここまで戻す、削除などです。

## スケッチ: 描いてから拘束と寸法で決める

- スケッチを始めるには、「作成」の「スケッチを作成」で平面を選びます。面に描く時は、面を選んで「面にスケッチ」を押します。
- 線分はクリックを続けるとつながり、近くの点に吸着します。ほぼ水平・垂直の線分には、水平・垂直の拘束が自動で付きます。
- 描いている途中に数を打って Enter を押すと、その長さや直径で決まり、寸法の拘束が付きます。決めるのは OK か Enter です。
- 道具には、線分・長方形・円・円弧(3 点・接線)・長穴・多角形・楕円・スプライン・円錐曲線・点・文字・ミラー・トリム・オフセットなどがあります。長方形・円・長穴・多角形には、決め方の違う種類があります。
- 要素を選ぶと、選んだ組み合わせで使える拘束と寸法が出ます。点を引くと、拘束を保ったまま形が解き直されます。
- 寸法とパラメータは、単位つきの式で書けます。パラメータの表で式を変えると、形もツールパスも作り直されます。

## 形を作る: 閉じた輪郭を押し出すか回転する

- 閉じた輪郭のあるスケッチを選んで、「押し出し」か「回転」を押します。距離・向き・演算(新しいボディ・結合・切り取り・交差)は編集パネルで変えます。
- 「修正」には、プレス/プル・フィレット・面取り・シェル・ブーリアン・ボディを分割・移動/コピー・面をオフセットがあります。
- 「パターン」には、矩形状・円形状のパターンとミラーがあります。穴とねじは「作成」の「穴」で作ります。
- 形の機能を抑制すると、その面を参照していたスケッチや加工はタイムラインで ✖ になり、理由が出ます。参照は別の面へ自動では付け替えません。3D のビューで別の面を選び、編集パネルで付け替えてください。

## 加工: セットアップを足してから加工を足す

1. 加工の作業空間で「セットアップ」を足します。編集パネルで、機械、ストックの材料と決め方、原点、固定具を決めます。ストックの決め方は「部品+余白」か「決まった大きさ」です。機械の既定は「管理」の「機械の設定」で決めます。3D のビューには、ストック・原点・機械の作業範囲が出ます。
2. 「2D」「3D」「穴」から加工を足します。加工によっては、底の面や縁を 3D のビューで選んでから押します。工具は「管理」の「工具ライブラリ」から選び、ストックの材料に合う切削条件を使います。合う条件が無い時は既定の条件で削り、「注意」を出します。
3. 前の工具が届かなかった隅や細い溝は、加工を右クリックして「取残し加工」を足し、細い工具で削ります。
4. 「確かめる」の「シミュレーション」で、食い込み・削り残し・シャンクとホルダーの当たりを調べます。「G-code で確かめる」では、書き出す G-code を読み直して同じように削ります。
5. 「出力」の「G-code を書き出す」で G-code を書き出します。段取りの表は「加工指示書を書き出す」で書き出します。

実機で削る前に、必ずシミュレーション、Z を浮かせた空運転、ワックスや MDF での試し削りの順に確かめてください。工具を交換した後には、工具長を測り直す命令(`M491`)を出しています。

## 書き出し: 作業空間ごとに書き出せる物が違う

| 作業空間 | 読み込み・書き出し |
|---|---|
| 設計 | 「挿入」で STEP・DXF・SVG・下絵を読み込みます。「書き出し」で STEP・STL・3MF・DXF・SVG を書き出します |
| レンダリング | 静止画・回転する動画・glTF を書き出します |
| アニメーション | 分解とジョイントの動きの動画を書き出します |

## 困った時

### 起動しない → `--safe-mode` を付けて起動する

`--safe-mode` を付けると、利用者の設定と画面の配置を読まずに起動します。読めない設定ファイルがあった時は、そのファイルを使わずに既定の設定で起動します。

### 原因を調べたい → ログを見る

ログは起動ごとに、データフォルダの `logs` に残ります。Windows では `%APPDATA%\kie-monobench\logs` です。環境変数 `JC_LOG=debug` を付けて起動すると、ログが細かくなります。

### 異常終了した → 次の起動で知らせが出る

異常終了した時の報告は PC の中にだけ残り、外へは送りません。次に起動した時に知らせが出ます。

### 日本語の字体を替えたい → `JC_FONT` で指定する

日本語の字体は、OS の字体(游ゴシック・メイリオなど)を使います。環境変数 `JC_FONT` で字体のファイルを指定できます。

### 描画がおかしい → `JC_RENDERER=cpu` で起動する

環境変数 `JC_RENDERER=cpu` を付けて起動すると、ソフトウェアだけで描画します。
