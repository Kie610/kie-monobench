# できないことと今後の予定

使う人向けに、今の版でできないこと・気を付けることと、これから作る予定を短くまとめた。開発の段階と設計は [plan.md](plan.md)、作った機能ごとの記録は [機能/](機能/)。予定は変わることがあり、時期は決めていない。

## 今できないこと・気を付けること

- 画面の言葉は日本語だけ。
- 配る版は Windows 10・11(x64)と Linux(x86_64)だけ。ほかの OS はソースから組み立てる。
- 配る版に署名がまだ無い。Windows では初回に確認の窓が出ることがある。
- 加工は 3 軸まで。回転軸(4 軸)で削ることはできない。
- 図面(寸法と注記を入れた 2D の図)は作れない。今の視点の線を DXF・SVG に書き出すことはできる。
- 加工の戦略を自分で足すプラグインはまだ読めない(足せるのは G-code のポストだけ)。
- 工具ライブラリの既定の工具と切削条件は、木材・樹脂向けの控えめな仮の値。手持ちの工具と材料に合わせて直す。
- 輪郭加工のタブ(削り落とさずに残す橋)と、ポケットのらせん・ランプでの入りは、固定のしかたに合わせて使うかをまだ決めていない。
- 流れと空力の解析は CPU で解く。GPU で解くこと、結果を動画に書き出すこと、ファンの計算、翼型の抗力はまだ。
- 実機で削る前に、必ずシミュレーション、Z を浮かせた空運転、ワックスや MDF での試し削りの順に確かめる。

## 今後の予定

- 図面
- 4 軸で削る
- 加工の戦略のプラグイン
- 工具が届かない所を色で見る
- 木工向けの機能(画像から浮き彫り、板への配置、区切って削る、はめ込みの枠)
- 設計の残り(曲面まで止める、平歯車、3D プリント用のざぐりの段差など)
- スピーカーの箱の計算
- 流れと空力の続き(GPU で解く、動画の書き出し)

困ったことや欲しい機能は Issue で知らせてほしい([CONTRIBUTING.md](../CONTRIBUTING.md))。
