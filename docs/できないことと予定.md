# できないことと今後の予定

今の版でできないこと、気を付けることと、これから作る予定を説明します。予定は変わることがあり、時期は決まっていません。開発の段階と設計は [plan.md](plan.md)、作った機能ごとの記録は [機能/](機能/) にあります。

## 今できないこと・気を付けること

- 画面の言葉は日本語だけです。
- 配っているアプリは、Windows 10・11(x64)と Linux(x86_64)向けだけです。ほかの OS では、ソースからビルドしてください。
- アプリにはまだ署名がありません。Windows では、初めて起動した時に警告のダイアログが出ることがあります。
- 加工は 3 軸までです。回転軸(4 軸)を使って削ることはできません。
- 寸法と注記を入れた 2D の図面は、まだ作れません。今の視点の線を DXF・SVG に書き出すことはできます。
- 加工の戦略を足すプラグインは、まだ読めません。プラグインで足せるのは G-code のポストだけです。
- 工具ライブラリの既定の工具と切削条件は、木材と樹脂向けの控えめな仮の値です。手持ちの工具と材料に合わせて直してください。
- 輪郭加工のタブ(削り落とさずに残す橋)と、ポケットへのらせん・ランプでの切り込みは、材料の固定のしかたに合わせて、加工ごとに使うかを決めてください。
- 流れと空力の解析は CPU で解きます。GPU で解くこと、結果を動画に書き出すこと、ファンの計算、翼型の抗力はまだできません。
- 実機で削る前に、必ずシミュレーション、Z を浮かせた空運転、ワックスや MDF での試し削りの順に確かめてください。

## 今後の予定

- 図面
- 4 軸で削る
- 加工の戦略のプラグイン
- 工具が届かない所を色で見る
- 木工向けの機能(画像から浮き彫り、板への配置、区切って削る、はめ込みの枠)
- 設計の残り(曲面まで止める、平歯車、3D プリント用のざぐりの段差など)
- スピーカーの箱の計算
- 流れと空力の続き(GPU で解く、動画の書き出し)

困ったことや欲しい機能は、Issue で知らせてください。出し方は [CONTRIBUTING.md](../CONTRIBUTING.md) にあります。
