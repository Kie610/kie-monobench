# 入出力の一覧(生成)

`cargo xtask io` が組み立ての登録と MCP の道具から作る。手で直さない(古いと kmb-mcp の試験が
落ちる)。決まりは AGENTS.md「4. 入出力の約束」。

## 操作と引数(164 個)

長さは mm、角度は deg で読む。単位つきの式も受ける。宣言に無い鍵は誤り。
