# 行動規範 / Code of Conduct

## 約束 / Our promise

ここは、ものを作る道具を一緒によくする場です。経験・国・言葉・性別・年齢・体・考え方にかかわらず、誰もが嫌な思いをせずに加われるようにします。

This is a place to improve a tool for making things, together. Everyone should be able to take part without harassment, whatever their experience, country, language, gender, age, body or beliefs.

## してほしいこと / Expected behaviour

- 相手を敬い、意見の違いは中身で話す / Be respectful and discuss the substance when you disagree
- 使う人の困り事を先に考える / Think about the people who use the software first
- 間違いを認め、指摘をありがたく受ける / Admit mistakes and accept feedback gracefully
- 言葉が違う人には、短く平らな言い回しで書く / Write short, plain sentences for people whose first language differs from yours

## しないこと / Unacceptable behaviour

- 人への攻撃・侮辱・嫌がらせ・脅し / Personal attacks, insults, harassment or threats
- 性的な言葉や画像 / Sexual language or imagery
- 他人の個人情報を許しなく出す / Publishing others' private information without permission
- 議論をわざと荒らす / Deliberately derailing discussions

## 守らせ方 / Enforcement

維持する人は、この規範に合わない書き込み・コミット・Issue・PR を消し、直し、断ることができ、繰り返す人を一時または永く締め出せます。困った時は、GitHub の非公開の報告([SECURITY.md](SECURITY.md) と同じ窓口)で維持する人に知らせてください。知らせた人の名前は守ります。

Maintainers may remove, edit or reject comments, commits, issues and pull requests that do not follow this code, and may ban repeat offenders temporarily or permanently. To report a problem, contact the maintainers through GitHub's private reporting (the same channel as [SECURITY.md](SECURITY.md)). We will keep the reporter's identity private.

この規範は、リポジトリ・Issue・PR と、このプロジェクトを代表する場のすべてに当てはまります。

This code applies to the repository, issues, pull requests and any space where someone represents the project.
