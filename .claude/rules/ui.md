# 画面を触る時の決まり

正本: policy.md「決めたこと」の画面の構成・マウス・作る・直す、`docs/用語表.md`、見た目の値は `crates/kmb-ui/src/theme.rs`。

- 配置と階層は広く使われるパラメトリック CAD にそろえ(AGENTS.md 5 節の配置)、アイコン・配色・部品の見た目は独自。ほかのソフトの絵を写さない。
- ツールバーは上から「上の帯 → タブ → グループの帯」。左端に作業空間の箱、右端に「選択」。グループは作業の流れの順で固定(並べ替えない。利用者のピンとタブの移動は残す)。大きなボタンで出す物は画板で決めた物だけにし、残りは ▾ の一覧へ。決めた並びは画板「JC の画面」から起こしたデータ(`crates/kmb-ui/board/toolbar.json`)にあり、試験が実物と比べる。並びを変える時は画板とデータを一緒に直す。まだ入っていない物は `crates/kmb-ui/board/known-diffs.txt` に理由と書き、この表は減らすだけ(点検: 画板の並び)。
- マウス: 左=選ぶ、右クリック=メニュー、右ドラッグ=回す、ホイール押し=動かす。視点の立方体は作らずボタン。
- 1280 と 1920 の幅で見る。1280 でもツールバーが全部押せること。字の倍率 250 % で崩れないこと。
- 色は `Palette` の役割の名前で使う: 地 `chrome`・`chrome2`・`panel`・入力欄 `paper`、字 `ink`・補足 `ink2`・使えない物だけ `ink3`、区切り `edge`。作業空間の色(`design`・`cam`・`render`・`anim`・`sim`・`sketch`、淡い地は `design_soft` など)は作業空間の箱・使っているタブの下線・使っている道具・パネルの見出しだけ。`err`・`warn`・`ok` は失敗・注意・済みにだけ使う。道具のアイコンは土台の線 `icon_base` と、変わる部分だけに差す役の色(`role_make` 作る・`role_modify` 変える・`role_repeat` 増やす・`role_define` 決める)の 2 層で描く(`icons::paint_inks`・`Palette::icon_inks`)。役の色は見出し・縁・帯に使わない。調べる・出す・取り込むなど役の無い道具の絵は 1 層の表 `icons::ONE_LAYER` に書き、ツールバーの道具(▾ の一覧も)はどちらか 1 つに入れる(試験 `board::layer_gaps`)。
- アイコンは 24×24 の線画(塗らない、端と角は丸)。道具と 1 対 1 で、違う道具に同じ絵を使わない。使えない時は 1 色。14px でも見分けられる形。今の絵は `crates/kmb-ui/src/icons.rs`。
- ボタン・ラベルは一言。説明は文脈の無い人にも何が起こるか分かるよう短く、「何が起きたか」と「どうすればよいか」を書く。英語の略語は一般に通じる物(G-code・STEP・DXF)だけ。
- 設計のキー: M は移動/コピー、計測は I だけ(Kie 2026-10-22)(点検: キーの割り当て)。
- ビューで面・辺・頂点を選んだら、タイムラインとブラウザの機能の選びを外す。続く Delete などは見えている選びにだけ効かせる。作る・直す・手順の途中は選びが欄に入るので外さない(Kie 2026-10-22)(点検: 選びの切替)。
- スケッチの道具は前回使った種類(2 点の長方形・中心の長方形など)を覚えて出さず、毎回同じ既定の種類で始める(Kie 2026-10-22)。
- 新しい画面の状態は `Workspace` に欄を足さず、自分の struct に持つ。文書の操作は画面で直に書かず、操作(`Action`)を通す。
- 外観・物理材料の無いボディは鋼に見せる。加工のストック材料の既定は替えない。
- 変えたら撮って前と並べる(`scripts/ui-shot/README.md`)。e2e は `ui_*` の道具の台本で書く。
- 裏で読む物を待つ試験は、次に使う部品を条件にし時間切れで止める(点検: 待ちの時間切れ)。
