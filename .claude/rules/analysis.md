# 解析を触る時の決まり

正本: policy.md「決めたこと」の解析と解析(流れと空力)、verify.md「10. 解析の確かめ方」「11. 流れと空力の確かめ方」。

- 解き方は自前(kmb-fea・kmb-flow・kmb-wave)。GPL の解き方や網の部品を使わない。形はコアの網とカーネルの trait だけで読み、CAD・CAM を知らない。
- 正しさは全体の数値だけで判断しない。教科書の答えに加え、局所の誤差の分布と実際の画面の見た目(格子状の上下・ギザギザが無いか)で確かめる。
- 手法を採る前に先行製品の手法を複数並べて比べ、いちばん起きやすい失敗を小さな例で作って、その方法で消えるかを見てから推奨する。
- 力・応力・温度などの欄は単位を付けない数で、単位は欄の名前に書く。解析の既定の材料は鋼。
- 解き方と見せ方の間は kmb-study の結果の形で受け渡す。
- 避ける形(加工の制約つきの軽い形、面要素の壁・VLES・多孔質の音響など)は docs/避ける形.md を見る。
